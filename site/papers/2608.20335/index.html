Card 02 论文概述

论文概述

Card 03 核心贡献

核心贡献

  • 提出从单目视频生成重建级多视角一致4D人类视频的4DAnyone框架
  • 提出参考上下文打包（Reference Context Packing, RCP），将参考上下文复杂度从O(N)压缩到O(1)，同时保持跨视角外观指导
  • 提出目标上下文路由（Target Context Routing, TCR），在去噪过程中动态重组目标视角分组，实现跨组上下文共享并减少跨组结构漂移
  • 采用3D感知骨架条件（3D-aware skeleton conditioning），利用稀疏可靠的3D骨架作为几何引导，解决2D姿态歧义
  • 构建了MVGameHuman数据集，并结合多视角和单目野外视频数据集进行训练，实现稳健的野外泛化能力
Card 04 方法描述

方法描述

  • 基于Wan2.2-TI2V-5B DiT视频扩散模型，使用HMR模型GVHMR估计3D骨架序列并渲染为深度缓冲骨架视频作为几何引导
  • 通过骨架编码器将骨架条件作为残差注入噪声潜变量，以实现稳定的训练
  • RCP使用多尺度patchify层将增长的参考视角集压缩为固定长度的上下文，提供可扩展的外观指导
  • TCR将去噪分为高噪声和低噪声阶段：高噪声阶段循环重组视角分组传播全局结构，低噪声阶段固定相邻分组细化局部细节
  • 采用三阶段训练课程：前景视频训练、多视角全图训练和单目野外数据泛化训练，结合潜空间流匹配损失和LPIPS感知损失
Card 05 数据集与资源

数据集与资源

  • 训练数据集：MVGameHuman、SynCamVideo、DNA-Rendering、TedTalk、Pexels
  • 基础模型规模：5B参数的DiT视频扩散模型
  • 训练资源：128 H20-3E GPUs
  • 4D重建工具：使用FreeTimeGS进行4DGS重建
Card 06 评估与结果

评估与结果

  • 评估环境：在DNA-Rendering和DyMVHumans数据集上对比MV-Performer、TrajectoryCrafter和ReCamMaster
  • 主要评估指标：PSNR、SSIM和LPIPS
  • 关键实验结果：在4DGS重建、生成视频一致性和生成视频重建三个评估维度上均优于所有基线方法，且在野外视频中表现出鲁棒的泛化性
  • 消融实验证明RCP和TCR对提升多视角一致性具有互补作用，深度缓冲骨架渲染有效解决了前后姿态歧义
