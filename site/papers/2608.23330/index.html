Card 02 论文概述

论文概述

  • 提出新任务 IntentQA：视频意图问答，要求 AI 理解动作背后的心理目标与意图，而非仅识别视觉事实
  • 构建大规模 IntentQA 数据集（4,303 视频、16,297 QA 对），并引入五类 Contrast Set 与新指标 "Contrast Performance Decline" 评估模型鲁棒性
  • 提出 X-CaVIR（eXplainable Context-aware Video Intent Reasoning）框架，融合情境、对比、常识三类认知上下文，并通过 LLM 透明管线实现可解释推理
Card 03 核心贡献

核心贡献

  • 首次定义视频意图问答任务 IntentQA，聚焦"社会智能暗物质"——人类行为背后的不可观测心智状态
  • 构建大规模 IntentQA 数据集（基于 NExT-QA 筛选注释，四类意图 QA：Causal Why / Causal How / Temporal Previous / Temporal Next），三者交叉验证保证注释质量
  • 利用 LLM 生成五种 Contrast Set（性别、动词短语 HS/LS、名词短语 HS/LS），提出 "Contrast Performance Decline" 鲁棒性评估指标
  • 提出 X-CaVIR 模型，融合 Situational Context（VQL 模块）、Contrastive Context（对比学习模块）与 Commonsense Context（常识推理模块）
  • 从黑盒升级到可解释推理：提出 Confidence Prompting 透明管线，将 VQA 置信度与视频描述输入 LLM，显式输出推理过程
Card 04 方法描述

方法描述

  • 基线采用简化版 VGT 模型：帧特征与区域特征经 DGT 构建区域图，BERT 编码问题-答案语言特征
  • VQL（Video Query Language）：用区域图查询 QA 特征，计算相似度矩阵并得到跨模态图，即情境上下文
  • 对比学习：根据动作一致性（动作/词形/ID 三级）与 WUPS 答案相似度构建正负样本三元组，对齐 top-k 注意力节点后计算三元组损失
  • 常识推理：测试阶段将候选答案及其置信度分数、Qwen 7B 生成的视频描述、问题一起送入 LLM（InstructGPT/ChatGPT/GPT-4），要求输出选项 ID、选项文本与 Chain of Thought 推理过程
Card 05 数据集与资源

数据集与资源

  • 基于 NExT-QA 构建 IntentQA 主集：4,303 视频、16,297 QA 对，含 624 个动作、193 个 lemmatized verbs、162 个动作 ID
  • 数据划分：训练 12,119 / 验证 2,044 / 测试 2,134 QA；类型分布：CW 9,424、CH 2,633、TP&TN 4,240
  • 对比集：由 LLM 生成的 Gender、Verb Phrase HS/LS、Noun Phrase HS/LS 五类对抗扰动集
  • 视频描述模型采用 Qwen 7B；LLM 推理后端采用 InstructGPT（GPT-3）、ChatGPT、GPT-4
  • 数据集与代码开源：https://github.com/JoseponLee/IntentQA
Card 06 评估与结果

评估与结果

  • 评估基准：IntentQA 测试集上的多选题准确率，以及五类 Contrast Set 上的性能保持（Contrast Performance Decline 指标）
  • 消融实验：完整 X-CaVIR 取得最佳性能；LLM 常识集成带来最大提升 +3.98%，Caption 信息带来 +2.25% 提升
  • 融合策略对比：Confidence Prompting（Model 6，58.48%）优于会议版 Late Fusion（Model 5，57.64%），证明性能提升来自推理结构本身
  • TP&TN 类型 QA 最具挑战性（意图隐含在时序动作中），CW 与 CH 相对更易
  • 多个 Contrast Set 实验表明 X-CaVIR 对扰动保持稳定，优于 SOTA 基线
