Card 02 论文概述

论文概述

  • 本文是一篇关于视频大语言模型（VideoLLMs）推理效率的全面综述，系统性地梳理了从2022年底至今的视觉及视听 VideoLLM 的效率优化机制
  • 论文旨在回答“为什么视频理解仍然计算成本高昂”的问题，并深入分析了在实时、移动及资源受限场景下部署 VideoLLM 所面临的瓶颈
  • 核心目标是为研究人员提供一个结构化的效率机制分类法，涵盖从输入采样到大型语言模型（LLM）解码的完整管线，并指出当前评估不统一和视听效率优化不足的空白
Card 03 核心贡献

核心贡献

  • 提出了一个按推理管线阶段组织的效率机制分类法，覆盖帧采样、编码器计算、表征压缩和 LLM 执行与状态管理等环节
  • 系统整理了超过170 篇相关文献，不仅包含 VideoLLM 效率工作，还纳入了早期可复用于当前管线的帧采样和视觉编码器优化技术
  • 明确强调了视听 VideoLLM 的效率问题，填补了现有综述多关注纯视觉而忽视音频模态的空白
  • 在相同主机模型和输入协议下，汇编并区分了文献中报告的准确率-成本对比，指出了跨论文对比证据的异质性和标准化需求
  • 维护了一个公开的论文与代码仓库（https://github.com/momentslab/awesome-efficient-videollm），以促进社区研究和比较
Card 04 方法描述

方法描述

  • 采用阶段性分类法，将 VideoLLM 的效率优化技术按处理阶段进行分解，包括输入构建与选择、编码器计算、编码表征与连接器、LLM 执行与状态
  • 在输入构建阶段，系统划分了固定间隔采样、基于内容的选择、查询无关/相关的学习式选择器等子类，并讨论了分块与分辨率策略
  • 在编码器计算阶段，分析了高效架构（如状态空间模型）、稀疏算子、内部令牌归并以及计算复用与替换等方法
  • 在表征处理阶段，梳理了令牌合并、网格池化、潜在重采样和记忆库压缩等减少输入 LLM 令牌数量的技术
  • 在LLM 执行阶段，涵盖了令牌剪枝、稀疏注意力、摘要令牌生成、KV-Cache 压缩与卸载等直接降低解码开销的方法
Card 05 数据集与资源

数据集与资源

  • 论文本身是综述，不涉及特定数据集或模型的单一训练，但整合了多个评估基准上的结果，包括视频问答、文本检索、时间定位等任务
  • 所讨论的模型涵盖了多种代表性 VideoLLM 架构（如 Video-LLaMA, BLIP-3-Video 等）及其变体，其参数规模和训练资源因模型而异
  • 效率指标被归结为参数数量、每输入 FLOPs、延迟、内存占用和视觉/音频令牌数等，并整理了不同模型在标准 GPU 上的推理性能数据
Card 06 评估与结果

评估与结果

  • 评估基于多个公开的视频理解基准，论文通过收集和对比不同文献报告的推理成本（如延迟、GFLOPS）与准确率（如问答得分）来揭示效率机制的效果
  • 主要评估指标包括准确率-效率权衡，具体表现为在保持较小性能损失下的令牌压缩比、延迟降低倍数、内存节省等
  • 关键实验结果显示，不同效率机制在降本与保性能之间普遍存在权衡，且当前标准化评估的缺失使得跨工作公平对比困难，同时视听模型的效率优化研究明显不足
