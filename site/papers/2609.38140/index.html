Breaking the Uniformity Trap: Scaling Video Diffusion Model via SplitMoE

2026-09-29 · 原文 · 翻译 · 2609.38140

论文提出 SplitMoE，一种面向视频扩散模型扩展的分角色稀疏架构，旨在解决传统 MoE 在视频生成中陷入的"均匀性陷阱"（Uniformity Trap）。 传统 token-wise MoE 在异构专家池中独立路由 token，并用均匀化正则约束专家使用率，这与视频数据时空冗余、语义长尾分布的特性不匹配，导致局部路径碎裂（spatiotemporal fragmentation）和结构失真。 SplitMoE 将专家池显式划分为语义专家和通用专家，结合原型引导路由与推-拉正则化，使 token 按语义属性自然聚类，从而在相同激活参数预算下提升视频生成质量。

Card 03 核心贡献

核心贡献

  • 提出 SplitMoE 稀疏架构，将视觉建模解耦为语义专家（Semantic Experts）与通用专家（Generic Experts），缓解视频 token 的时空碎裂与时间闪烁问题。
  • 引入 原型引导语义路由（Prototype-Guided Semantic Routing），利用可学习原型桥接重建性 VAE 特征与 DiT 视觉 token，实现语义感知的专家分配，减少专家同质化并促进有意义的分工。
  • 在激活参数预算匹配的条件下，SplitMoE 超越标准 MoE 基线，并与其他同量级激活参数模型表现相当。
  • 提供关于 Video-MoE 路由动态与时间步分析的经验洞见，揭示与去噪过程一致的由粗到细（coarse-to-fine）路由模式。
Card 04 方法描述

方法描述

  • 将标准专家池划分为不相交的语义专家集合（E^sem）与通用专家集合（E^gen），语义专家负责高层语义抽象，通用专家保留残差视觉信息与灵活生成能力。
  • 路由器对每个 token 计算独立 sigmoid 亲和度分数（而非全局 softmax），实现语义与通用分支的独立 Top-K 选择（K_s 个语义专家 + K_g 个通用专家），并保持总激活专家数 K 与标准 MoE 一致。
  • 引入路由器对齐损失（L_align），通过 KL 散度将路由器预测分布与 VAE 特征-原型余弦相似度得到的软标签对齐。
  • 设计原型优化损失（L_proto），包含 pull 项（吸引原型贴近当前和历史 VAE 特征，使用循环 token 银行）与 push 项（推动原型间分离、避免冗余，防止死模式）。
  • 采用 DeepSeek-V3 风格的无损失组感知负载均衡（仅用于通用专家），语义专家通过语义对齐自适应平衡，不引入辅助优化损失。
Card 05 数据集与资源

数据集与资源

  • 基于 Wan 2.2 低噪声检查点进行 MoE upcycling，将第 15 至 35 层偶数层的密集 FFN 替换为稀疏 MoE 层。
  • 每个 MoE 层包含 1 个持续激活的共享专家和 100 个路由专家（20 个语义专家 + 80 个通用专家）。
  • 采用 Top-8 路由（K_s=2，K_g=6），模型总参数量 27B，每轮前向激活 14B 参数，与密集基线计算量持平。
  • 所有模型在相同 80k 步优化设置下训练。
  • 评估使用 VBench-2.0 和 T2V-CompBench 基准。
Card 06 评估与结果

评估与结果

  • 对比基线包括 CogVideoX-1.5、Mochi、HunyuanVideo、LongCat-Video、LTX-2、Wan2.2、OmniWeaving (think) 等 SOTA 模型，以及同源消融基线（Dense Wan2.2-FT、Wan2.2-MoE、SplitMoE w/o PG 等）。
  • 评估指标：VBench-2.0 五项能力（Creativity、Commonsense、Controllability、Human Fidelity、Physics），T2V-CompBench 三个维度（Consistent Attribute、Interaction、Numeracy）。
  • 与 Wan2.2 相比，SplitMoE 在 Creativity 和 Human Fidelity 上获得提升，并在 T2V-CompBench 上取得有竞争力的组合对齐结果。
  • 消融研究覆盖计算开销分析、MoE Upcycling 有效性、结构化语义路由效果、pull-push 原型引导的耦合效应、视频 MoE 路由病态现象以及时间步感知的路由动态。
  • 论文亮点：SplitMoE 展现出涌现的时间专化（Emergent Temporal Specialization），在早期高噪声结构阶段自动路由更多容量到语义专家，在最终去噪阶段转向通用专家，无需显式时间步约束。
