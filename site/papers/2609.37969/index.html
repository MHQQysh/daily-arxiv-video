SoL-Refiner: Speed-of-Light One-Step Refinement for High-Resolution Video

2026-09-29 · 原文 · 翻译 · 2609.37969

提出 SoL-Refiner，一个单步（one-step）视频精修器，用一次去噪步骤将低分辨率视频生成结果提升为高质量 2K/4K 视频，同时修复合成伪影、增强局部细节。 解决的核心问题：高分辨率视频生成成本随时空 token 数量急剧增长；传统的两阶段生成中，多步精修器会引入“第二次采样瓶颈”，且多数精修器只针对特定基础生成器，跨生成器迁移能力未被充分评估。 目标是在保持内容与运动一致性的前提下，以“光速级”延迟完成视频超分与精修，并兼容多种基础生成器。

Card 02 论文概述

论文概述

  • 提出 SoL-Refiner，一个单步（one-step）视频精修器，用一次去噪步骤将低分辨率视频生成结果提升为高质量 2K/4K 视频，同时修复合成伪影、增强局部细节。
  • 解决的核心问题：高分辨率视频生成成本随时空 token 数量急剧增长；传统的两阶段生成中，多步精修器会引入“第二次采样瓶颈”，且多数精修器只针对特定基础生成器，跨生成器迁移能力未被充分评估。
  • 目标是在保持内容与运动一致性的前提下，以“光速级”延迟完成视频超分与精修，并兼容多种基础生成器。
Card 03 核心贡献

核心贡献

  • 提出 SoL-Refiner，可在单个去噪步骤内对多个基础生成器的低分辨率输出进行上采样与精修，无需修改或重训基础模型。
  • 设计三阶段训练流程：高分辨率持续训练（continual training）、基于帧级奖励模型的强化学习（RL）后训练、以及最终的单步蒸馏（one-step distillation）。
  • 提出 Refiner-Bench 视频精修基准，基于多个视频生成器的输出构建，并采用共享输入（shared-input）协议公平比较不同精修器。
  • 结合 TAE 轻量自编码器与 Sol-Engine 推理引擎，在精修阶段实现相对于三步 LTX-2.3 Refiner 的 8.91× 加速；与四步 MiniMax H3 基础生成器配合时，完整两阶段管线相比直接全分辨率 H3 生成快 27×。
  • 在 2K 分辨率下，单步 SoL-Refiner 在 VBench 与 UniPercept 平均分上超过所有外部精修器；在 3840×2176 分辨率下，两项指标均优于三步骤 LTX-2.3 Refiner。
Card 04 方法描述

方法描述

  • Stage I（持续训练）：使用配对的低质量/高质量视频数据，采用截断-σ 流匹配（truncated-σ flow matching）训练精修器，起点为带噪的低保真潜变量（σ_start=0.91），路径终止于干净的高保真目标潜变量；条件信号包括文本与参考图像 token。
  • Stage II（RL 后训练）：使用 Reward Feedback Learning (ReFL)，在含 12 步截断去噪调度的后期步骤上计算可微奖励；从视频前/中/后三个时间段各采样一帧，用 HPSv3++（提示条件偏好）与 DeQA（退化感知质量）加权组合作为奖励。
  • Stage III（蒸馏加速）：先进行少步蒸馏（DMD，3 步学生 + fake-score 模型），再进行单步蒸馏（DMD-GAN），引入投影 DiT 判别器与对抗监督，将多步教师压缩为单步学生。
  • 推理优化：使用 TAE 轻量自编码器降低编解码成本；通过潜变量上采样和噪声初始化实现单步精修；由 Sol-Engine 执行单个精修 NFE。
Card 05 数据集与资源

数据集与资源

  • 训练数据主要来自内部真实视频数据集：以真实视频为高质量目标，通过下采样再上采样构造低质量条件视频。
  • 使用少量合成配对数据进行初始化预热：基础生成器生成低分辨率视频，LTX-2.3 Refiner 生成对应高保真目标。
  • 精修器初始化为预训练的 LTX-2.3 checkpoint。
  • 基准 Refiner-Bench 由不同视频生成器（如 MiniMax H3 等）的输出构建，评估输出分辨率约 2K。
  • 延迟测试环境包含 NVIDIA GB200，并额外评估 DGX Spark 部署场景。
Card 06 评估与结果

评估与结果

  • 评估基准：Refiner-Bench、VBench 与 UniPercept；采用共享输入协议对比外部精修器。
  • 主要指标：VBench 平均分、UniPercept 平均分、精修延迟（latency）。
  • 在 2K 分辨率下，单步 SoL-Refiner 的 VBench 与 UniPercept 平均分超过所有外部精修器；在 3840×2176 下，进一步优于三步骤 LTX-2.3 Refiner。
  • 精修阶段完整加速栈相比三步骤 LTX-2.3 Refiner 实现 8.91× 加速（2K 延迟设置）。
  • 端到端示例：5 秒、1344×768、24fps 视频，50 步 SGLang MiniMax H3 全分辨率生成需 152.3 秒（单 GB200），而四步 896×512 H3 生成 + 单步 SoL-Refiner 仅需 5.64 秒（两阶段各用一张 GPU），整体加速 27.03×。
  • 消融实验覆盖训练配方、奖励学习、蒸馏策略、延迟分析和 DGX Spark 部署。
