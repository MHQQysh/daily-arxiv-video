Card 02 论文概述

论文概述

  • 论文提出 Dream4ACT，一种面向多具身（multi-embodiment）视频-动作建模的共享视觉动作世界模型。
  • 核心问题：关节空间动作向量缺乏显式图像空间结构，且在不同具身间维度与语义不一致，难以直接利用视频生成模型（VGM）的时空先验；末端执行器可视化又无法表达完整关节配置。
  • 关键思路：将目标关节配置渲染为动作视图（action views），使异构关节空间共享统一的视觉建模接口，同时保留具身特定的关节几何信息。
Card 03 核心贡献

核心贡献

  • 提出 action views：通过 URDF 前向运动学从四个固定虚拟相机渲染目标关节配置，形成固定形状的多视图视觉动作表示，支持跨具身共享 tokenization 与视频建模。
  • 提出训练无关、URDF 约束的多视图动作恢复机制，无需学习式具身专属动作解码器，即可将预测的动作视图映射为可执行的关节目标。
  • 通过掩码流匹配（masked flow matching），在单一联合训练模型中统一支持前向动力学、逆动力学、联合生成三种模式。
  • 在RoboTwin 2.0 与 TriWorldBench 等基准以及多种真实机器人平台上验证了方法的有效性和泛化能力。
  • 通过消融实验对比 action-view 渲染与相机对齐骨架条件，验证了生成视觉质量的优越性。
Card 04 方法描述

方法描述

  • 使用 URDF 前向运动学将关节配置 \(S_t=(q_t,g_t)\) 渲染为四路 action views，虚拟相机参数跨具身共享，避免物理相机外参标定。
  • 采用 Qwen3.5-VL 9B 作为冻结视觉语言模型，通过可训练的语义适配器提取指令接地特征；使用可学习 query 压缩视觉特征并与语言 token 联合自注意力。
  • 共享 Wan2.2 视频 VAE 分别编码 RGB 观测与 action views，并添加模态嵌入（modality embedding）和视角嵌入（view embedding），通过 RoPE 空间偏移避免多序列位置冲突。
  • 使用扩散 Transformer（DiT） 对多序列潜变量进行联合建模，每个 block 执行跨序列联合自注意力与语义条件交叉注意力。
  • 扩展条件流匹配，支持按模态独立噪声级别与掩码调度，实现多模式预测；动作恢复采用 URDF 约束的 Gauss–Newton 多视图匹配优化。

Card 06 评估与结果

评估与结果

  • 模拟评估：RoboTwin 2.0 上平均成功率达到 88.98%；TriWorldBench 上使用单独训练 checkpoint 取得 65.66 分。
  • 闭环操控评估覆盖五个模拟具身和四个真实机器人平台。
  • 支持正向动力学（条件动作预测未来观测）、逆动力学（由未来观测恢复动作）以及联合生成（同时生成观测与动作）。
  • 消融实验表明，action-view 视觉条件相比相机对齐骨架条件具有更优的生成视觉质量与任务执行表现。
