Where to Look Matters: On-Policy Self-Distillation for Long-Video Understanding

2026-08-26 · 原文 · 翻译 · 2608.25356

论文聚焦长视频理解任务中的关键问题：当视频变长时，全视频上下文中包含大量与问题无关的时间内容，会干扰模型定位回答问题所需的关键证据。 论文通过实证发现，将视觉输入聚焦于包含问题相关证据的短线索区间（clue interval），在不同规模模型上均一致优于使用完整视频输入，且所需帧数更少。 基于该发现，论文提出 Clue-OPSD，一种基于线索特权（clue-privileged）的在线策略自蒸馏（On-Policy Self-Distillation）框架，在不依赖地面真值答案标签的情况下提升长视频理解能力。

Card 03 核心贡献

核心贡献

  • 系统性验证了聚焦于问题相关线索区间可显著优于全视频输入：在 CG-Bench 1000 个问题上，Qwen3.5-2B/4B/9B 分别提升 +13.30、+13.60、+14.96 个百分点，同时平均输入帧数从 1024 帧降至 68 帧。
  • 提出 Clue-OPSD 框架，利用线索区间作为特权的视觉监督信号，训练全视频学生模型，且不使用地面真值答案标签，也不依赖外部或更大规模的教师模型。
  • 采用 EMA 自教师机制，教师参数通过学生参数的指数移动平均更新，提供稳定的蒸馏目标，无需额外预训练模型。
  • 在推理阶段完全移除线索注释和教师模块，学生模型沿用标准全视频 VLM 推理流程，无需额外的时间定位或推理时模块。
  • 在多个长视频理解基准和 Qwen3.5 多个模型规模上展现一致的性能提升，并优于 SFT、GRPO 等监督式后训练基线。
Card 04 方法描述

方法描述

  • 不对称视觉上下文：学生模型接收全视频采样帧 V，EMA 教师模型接收同一问题对应的线索区间采样帧 V\*，两者共享相同的文本输入（问题与选项），仅视觉输入不同。
  • 在线策略分布对齐：学生先从全视频输入生成在线策略轨迹 ŷ，随后学生和教师沿同一学生生成前缀分别计算下一 token 分布，使用广义 Jensen-Shannon 散度（JSD）进行逐 token 对齐，梯度仅通过学生分支传播。
  • Top-K 对数蒸馏：借鉴 Vision-OPD，采用 top-K logit 蒸馏（K=100），仅保留学生分布中 top-K token 及对应教师 logits 和尾部概率，降低全词表分布匹配的内存和计算开销。
  • EMA 自教师：教师参数通过 θ_T ← (1−α)·θ_T + α·θ_S 更新（α=0.05），教师不作为可优化参数，仅作为缓慢变化的稳定蒸馏参考。
  • 训练流程：学生权重每步优化后与 vLLM 回滚引擎同步以保证在线策略采样，线索注释和教师仅用于训练，推理时完全移除。
Card 05 数据集与资源

数据集与资源

  • 训练数据：从 CG-Bench（提供问题-答案对及时间线索区间标注）构建，保留有效线索标注的多选题，随机采样 5,000 个问答实例，覆盖 1,206 个不同长视频，并验证训练视频与评估基准无重叠以避免数据泄露。
  • 模型规模：Qwen3.5-2B、Qwen3.5-4B、Qwen3.5-9B，均采用全参数微调。
  • 训练资源：8 张 NVIDIA B200 GPU，学习率 2×10⁻⁶，有效 batch size 32，最多 300 步优化，余弦学习率调度（warmup 比例 0.03）。
  • 蒸馏配置：JSD 中 β=0.5，top-K=100，蒸馏温度 1.0，EMA 系数 α=0.05，rollout 采样温度 1.0，top-p=0.95，top-k=20。
Card 06 评估与结果

评估与结果

  • 评估设置：在 CG-Bench 1,000 个采样多选题上初步验证线索区间的效果；训练后在多个长视频理解基准上评估，与 vanilla Qwen3.5、SFT、GRPO、标准 OPSD 等基线对比。
  • 线索区间 vs 全视频对比：Qwen3.5-2B 准确率从 45.33% 提升至 58.63%（+13.30）；Qwen3.5-4B 从 50.50% 提升至 64.10%（+13.60）；Qwen3.5-9B 从 53.47% 提升至 68.43%（+14.96），平均输入帧数从 1,024 降至 68.15。
  • 主要结果：Clue-OPSD 在 Qwen3.5 各模型规模上均一致优于对应骨干模型，并在多个长视频理解基准上达到与 SFT、GRPO 等监督式后训练基线相当或更强的性能。
  • 消融研究：论文针对蒸馏目标（发散目标的选择）和特权线索利用方式进行了消融实验，验证了 JSD 目标和线索区间特权监督各自的有效性。
