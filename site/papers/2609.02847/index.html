RoGe: Novel View Synthesis via End-to-End Implicit Reconstruction and Generation

2026-09-02 · 原文 · 翻译 · 2609.02847

论文提出 RoGe，一个用于稀疏视角新视角合成（NVS）的端到端统一重建与生成框架。 任务定义为“由稀疏视角锚定的场景内漫游”：给定少量带位姿的图像和一条用户指定相机轨迹，生成沿该轨迹的、时间上连贯且与输入场景一致的新视角视频。 现有混合方法通常通过渲染图像或显式 3D 表示（点图、3D 高斯）来桥接重建与生成，导致生成过程继承重建误差，且重建无法从生成中得到矫正信号；RoGe 直接移除这种显式桥接。

Card 02 论文概述

论文概述

  • 论文提出 RoGe，一个用于稀疏视角新视角合成（NVS）的端到端统一重建与生成框架。
  • 任务定义为“由稀疏视角锚定的场景内漫游”：给定少量带位姿的图像和一条用户指定相机轨迹，生成沿该轨迹的、时间上连贯且与输入场景一致的新视角视频。

Card 03 核心贡献

核心贡献

  • 提出 RoGe，将前馈重建网络与视频扩散模型端到端连接，使生成模型可以直接消费其依赖的几何表征。
  • 使用相机条件化的 VGGT 构建隐式场景表示，不生成深度图、点云或 3D 高斯等显式 3D 中间量。
  • 通过相机光线查询隐式场景表示，得到逐视角几何特征并注入视频扩散模型作为条件；消融实验证明该方式优于使用原始重建 token 或渲染 RGB 作为条件。
  • 重建模块与生成模块联合训练，让生成目标直接塑造自身的几何条件，避免两阶段方法中的误差传播。
  • 在 DL3DV 数据集上超过基于重建、基于生成以及混合方法的基线，在图像级指标和视频级时间一致性上均取得更优结果。
Card 04 方法描述

方法描述

  • 输入为稀疏观测集合 S（M 张带位姿图像）和目标轨迹 T（N 个相机位姿），使用 Plücker ray map 统一表示相机光线。
  • 隐式重建：采用相机条件化 VGGT 作为前馈重建网络，聚合多视角信息后输出 2048 维场景 token；通过 ray-scene cross-attention 让目标光线 token 查询场景 token，得到逐视角几何特征图 F_r。
  • 混合 VAE 表示：上下文图像按单帧独立编码，目标视频按时序联合编码，保留稀疏观测的置换不变性同时保持因果视频 VAE 的时间先验。
  • Latent-Aligned Geometry Adapter：将重建几何特征投影并重采样到 VAE 潜在空间分辨率，再通过 Pack_4 操作进行时间对齐，得到隐式几何条件。
  • Geometry-Grounded Diffusion Transformer：将 packed 的 Plücker 光线、上下文图像潜在特征和隐式几何特征共同注入预训练的视频扩散 DiT 中。
  • 训练使用潜空间流匹配（Latent Flow Matching）目标，重建与生成模块端到端联合优化，无需逐场景优化。

Card 06 评估与结果

评估与结果

  • 在 DL3DV 上与重建类、生成类及混合类基线进行对比。
  • 评估指标涵盖图像级质量指标和视频级时间一致性指标。
  • RoGe 在视觉质量、几何一致性和相机可控性上均优于现有基线。
  • 消融实验表明：光线查询的隐式特征优于原始重建 token 和渲染 RGB 作为生成条件；端到端联合训练能带来进一步的性能提升。
