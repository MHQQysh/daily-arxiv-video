Card 02 论文概述

论文概述

  • 提出 WorldCrafter，一个带隐式 3D 感知记忆的视频世界模型，用于实现长视界、跨视角一致的交互式场景探索
  • 核心思想：让请求的目标视角决定如何将多视角历史证据压缩进视频生成器有限的 token 预算中，从而在不依赖显式深度对应的情况下保持场景外观与结构一致性
  • 解决现有视频世界模型在长期生成中无法忠实回忆先前观察内容、且相机控制精度不足的问题
Card 03 核心贡献

核心贡献

  • 引入隐式 3D 感知记忆机制：记忆编码器将历史潜在帧编码为紧凑的 3D 感知表示，并在固定 token 预算内完成高效记忆写入与读取
  • 将记忆机制集成到相机可控的自回归视频生成中，实现领先的重访一致性（相对最强基线提升 47.6%）和相机控制精度
  • 通过少步蒸馏构建实时交互系统，在分钟级探索中保持流式推理能力与视觉质量
  • 采用姿态引导的读出模块，实验证明其优于无姿态读出，能更有效分配记忆预算给目标相关信息
  • 提出最大覆盖历史帧检索策略，相比传统的成对 FoV 相似度检索，覆盖更广、鲁棒性更强
Card 04 方法描述

方法描述

  • 基于 条件流匹配（Conditional Flow Matching） 训练潜空间视频扩散模型，使用视频 VAE 将视频映射为潜变量，再通过 Diffusion Transformer（DiT）去噪
  • 记忆编码器初始化自 LagerNVS 的编码器（丢弃浅层图像处理层，新增 patch embedding 层），将历史潜帧及其相机姿态编码为紧凑表示
  • 记忆读出（Readout）模块：对比姿态无关与姿态引导两种读出方式，后者使用从目标轨迹采样的查询姿态，初始化为 LagerNVS 解码器浅层并加投影层
  • 相机条件使用 PRoPE 风格编码，采用 UCPE 的并行相机注意力分支，仅作用于噪声部分
  • 推理时选择互补历史帧（最大联合视场覆盖），并将记忆 token 与近期上下文拼接进 DiT 的 token 序列
  • 结合自回归分块生成与少步蒸馏，实现实时流式推理

Card 06 评估与结果

评估与结果

  • 评估任务包括：长视界重访一致性、相机控制精度、视觉质量
  • 使用指标：MEt3R（越低越好）、LPIPS（越低越好）、PSNR（越高越好）、SSIM（越高越好）
  • 长视界重访一致性测试基于 725 个生成的视频，匹配首次访问与重访帧计算指标
  • 与基线对比（部分数据）：

- DreamX-World：MEt3R 0.548，LPIPS 0.627，PSNR 12.898，SSIM 0.243

- Alaya-EVOKE：MEt3R 0.414，LPIPS 0.565，PSNR 12.332，SSIM 0.290

- HY-WorldPlay：MEt3R 0.394，LPIPS 0.515，PSNR 12.983，SSIM 0.252

- Lyra 2.0（次优）：MEt3R 0.334，LPIPS 0.487，PSNR 14.050，SSIM 0.390

  • 定性实验展示模型在静态和动态场景中均能保持重访一致性，并支持从单张图像或文本提示开始探索
  • 消融研究用于验证姿态引导读出、记忆编码器初始化、历史帧检索策略等的有效性（详细消融结果未在已提供部分完整展示）
