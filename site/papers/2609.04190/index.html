Card 03 核心贡献

核心贡献

  • 提出 EditVid，一个统一的训练-free框架，同时支持指令引导和主体引导的视频编辑，覆盖风格迁移、属性修改、物体插入、部件级编辑和主体替换等多种任务
  • 识别了 MM-DiT 中时间上下文对表征复用的关键作用，设计了 RoPE 感知的局部-全局分解机制：相邻帧 KV 记忆用于短程连贯性，置信度与循环一致性过滤的 token 转移用于长程身份保持
  • 引入稀疏因果记忆（Sparse Causal Memory），仅使用前一帧的 KV 状态，保持时间上下文有界且计算开销不随视频长度增长
  • 提出基于对应关系的注意力后 token 注入（Correspondence-based Post-Attention Token Injection），避免远距离 token 通过 RoPE 调制注意力带来的几何不匹配
  • 提出软潜变量混合（Soft Latent Blending），根据源轨迹与编辑轨迹的差异自适应地保留无关内容，提升编辑局部性；并通过全面的定量、用户研究、鲁棒性和跨骨干评估验证了效果
Card 04 方法描述

方法描述

  • 基于 MM-DiT（Multimodal Diffusion Transformer）图像编辑模型作为强先验，在视觉潜变量流形中进行视频编辑，条件 token（文本/参考图）保持不变
  • 局部时间连贯性：为每帧构造前一帧的视觉潜 token 上下文，并通过注意力拼接前一帧的键值（KV）状态，形成因果马尔可夫依赖（帧间条件概率分解）
  • 长程身份保持：在 anchor 帧与后续帧之间建立高置信度、循环一致性（cycle-consistent）的对应关系，将匹配的视觉表征在注意力之后注入，避免跨帧 RoPE 位置编码引起的不匹配
  • 编辑局部性：从源视频和编辑视频的轨迹差异计算连续、时间步依赖的保留权重，在需要保留的区域保留源内容，在需要编辑的区域让目标提示/参考主导
  • 创新点在于将时间信息仅注入视觉 token 流，不改变条件流的位置分配，从而实现无需视频训练的即插即用视频编辑

Card 06 评估与结果

评估与结果

  • 评估基准：FiVE 和 IVEBench，并辅以 VLM 评估和用户研究
  • 在 FiVE 上，EditVid 达到 78.16 FiVE-Acc，而最强训练-free基线仅为 58.95，大幅超越
  • 在 IVEBench 上获得有竞争力的结果，同时保持良好的视频保真度
  • 用户研究中，EditVid 在 7 个对比方法中获得 51.8% 的总体偏好率
  • 消融实验表明：仅使用前一帧作为记忆优于保留更长的时间历史；对应关系过滤能提升对挑战性时间变化的鲁棒性；跨骨干（cross-backbone）实验证明方法具有泛化能力
