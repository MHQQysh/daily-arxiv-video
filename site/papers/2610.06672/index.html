VideoTapestry: Query-Adaptive Memory Refinement for Multi-Agent Long-Video Understanding

2026-10-05 · 原文 · 翻译 · 2610.06672

论文提出 VideoTapestry，一个无需训练的多智能体框架，用于长视频理解。 核心目标是将预构建的查询无关分层视频记忆，通过粗到细的查询驱动精炼，转换为复合查询自适应记忆，在保留全局上下文的同时获取问题相关的细节证据。 解决现有两大范式的缺陷：查询驱动探索对定位误差敏感；查询无关记忆构建可能遗漏特定问题所需的细节。

Card 03 核心贡献

核心贡献

  • 提出查询自适应记忆策略：将新观察到的证据整合到记忆的选定分支中，同时保留全局上下文和原始层次结构。
  • 设计 VideoTapestry 框架：尺度对齐的多智能体（Overview、Skim、Focus）分别对应记忆的三个语义层级，通过分支选择和检查目标传递协同精炼。
  • 采用层式工具增强的记忆精炼：每个智能体遵循 Plan→Observe→Update→Decide 协议，使用视觉观察工具和 ASR/转录工具获取针对性多模态证据。
  • 实现复合记忆组装：将精炼后的层级记忆按原始父子关系组装，并附带简洁的交接轨迹，供独立答案智能体生成最终预测。
  • 在 LVBench、LongVideoBench (Long)、Video-MME (Long)、EgoSchema 四个基准上取得一致提升，达到最先进结果。
Card 04 方法描述

方法描述

  • 预构建记忆包含三个层级：SuperEvents（全局叙事阶段）、MacroEvents（局部事件结构）、Subgraphs（细粒度实体/事件/OCR关系证据）。
  • Overview Agent 精炼 Super 级脚手架，保护与证据相关的节点及其邻居，压缩其余节点以保持全局覆盖，并选择相关阶段。
  • Skim Agent 在选定 SuperEvents 的子节点（MacroEvents）上进行观察和重写，缩小候选区域。
  • Focus Agent 检查选定 MacroEvents 对应的 Subgraphs，进行细粒度验证和描述重写。
  • 所有精炼操作仅修改临时文本表示，不改变静态层次图；最后通过 Assemble 合并为复合查询自适应记忆，由独立 Answer Agent 给出答案。
  • 创新点：将查询无关的广泛覆盖与查询驱动的定向证据获取相结合，通过尺度对齐的多智能体协作实现分层精炼，无需任何训练。
Card 05 数据集与资源

数据集与资源

  • 评估数据集：LVBench、LongVideoBench (Long)、Video-MME (Long)、EgoSchema。
  • 基础模型：使用 GPT-5.5 作为视觉语言骨干，另进行跨骨干泛化评估（结果见论文实验部分）。
  • 模型规模与参数量：未额外引入可训练参数，依赖现成 VLM 和预构建记忆。
  • 训练资源：无需训练，仅在推理阶段进行多智能体工具调用和文本精炼。
Card 06 评估与结果

评估与结果

  • 评估环境：四个主流长视频理解基准，对比直接 VLM 推理和多种 agentic 方法。
  • 主要指标：准确率（Accuracy）。
  • 关键结果：相比直接 GPT-5.5 推理，VideoTapestry 在 LVBench 上提升 17.2%，在 LongVideoBench (Long) 上提升 14.9%，在 Video-MME (Long) 上提升 9.8%，在 EgoSchema 上提升 7.0%，均达到对比方法中的最好成绩。
  • 消融实验验证了查询时记忆精炼和复合记忆组装的有效性，以及尺度对齐多智能体协作的贡献。
