Card 02 论文概述

论文概述

  • 提出 Probe-VAD，一种训练自由（training-free） 的视频异常检测（VAD）框架，旨在将冻结视觉语言模型（VLM）的视觉理解转化为连续、对排序敏感的异常分数。
  • 论文指出现有训练自由VAD方法存在两个关键瓶颈：字幕压缩造成表示瓶颈（caption-mediated pipelines）和直接数字生成造成解码瓶颈（autoregressive numerical generation），导致异常严重性区分度不足。
  • Probe-VAD 通过直接以视觉片段为条件、提取解码前的 YES/NO 似然偏好，并用有序严重度阈值组织这些偏好，从而绕过上述瓶颈，实现精细的异常排序。
Card 03 核心贡献

核心贡献

  • 识别出训练自由 VLM 基 VAD 中分数提取接口（score-extraction interface）这一被忽视的问题，明确揭示字幕中介和自回归数字解码两种信息损失瓶颈。
  • 提出 Probe-VAD，一种序数似然探测框架，直接访问视觉证据、保留解码前的似然级偏好，并通过有序严重度阈值构造连续异常分数。
  • 引入累积序数建模与PAVA单调投影（pool-adjacent-violators algorithm），确保异常严重性剖面的序数一致性，并利用尾部积分聚合证据。
  • 在三个主流 VAD 基准上取得优越检测性能，同时将端到端推理时间降低 59.0%、中间产物存储量降低 87.3%，验证了计算与存储效率优势。
Card 04 方法描述

方法描述

  • 框架包含四个阶段：构造重叠时间片段 → 用冻结 VideoLLaMA3-7B 直接编码视觉片段（不经过字幕）→ 提取累积序数证据 → 将片段级分数重建为帧级异常预测。
  • 使用 \(K=10\) 个均匀有序严重度阈值（\(\{0.1,0.2,\ldots,1.0\}\)），对每个阈值构造受限 YES/NO 二元查询，计算候选续写 token 的条件对数似然，并通过 softmax 归一化得到 YES 偏好概率 \(p_{i,k}\)，作为尾部证据代理 \(\widehat{P}(S_i \ge \tau_k \mid X_i)\)。
  • 为强制满足序数单调性 \(p_{i,1}\ge\cdots\ge p_{i,K}\)，采用 PAVA 求解带约束的最小二乘单调投影；随后基于尾部积分恒等式，用右黎曼和对投影后的累积剖面加权求和，得到连续片段级异常分数。
  • 创新点在于不使用训练、不学习预测头，而是直接利用冻结 VLM 的似然偏好完成分数提取，避免了字幕压缩和单一解码值的信息丢失。

Card 06 评估与结果

评估与结果

  • 评估环境：三个主流 VAD 公开基准，采用标准的帧级异常检测评估协议（AP/AUC 类指标）
  • 主要结果：相比代表性训练自由方法（如 LAVAD、CoReVAD 等），Probe-VAD 在三个数据集上均取得更优的检测性能
  • 消融实验验证各设计选择：直接视觉条件优于字幕条件；似然级打分显著优于直接数字生成；序数建模进一步优于扁平似然打分
  • 效率分析：端到端墙钟时间降低 59.0%，中间产物（artifact）大小降低 87.3%，显示良好的实际部署潜力
