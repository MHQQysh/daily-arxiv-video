Card 03 核心贡献

核心贡献

  • 首次探索将通用 MLLM 训练为任务定制的工具使用专家检测器，用于 AI 生成视频检测。
  • 提出基于影响力的教师知识指导策略（influence-based teacher-knowledge guidance strategy），用于第一阶段训练，实现高质量的工具使用与证据推理学习。
  • 提出工具使用经验引导的工具进化策略（tool-use experience-guided tool evolution strategy），在第二阶段联合优化检测器与工具集。
  • 设计了渐进式两阶段训练流程，先固定启发式工具集构建基础工具使用能力，再交替优化模型与工具集，使二者相互适应。
  • 在多个评估基准上取得了优于现有方法的性能。
Card 04 方法描述

方法描述

  • 阶段一：构建包含 13 个工具的初始启发式工具集（Python 可调用接口，整合预训练分割、跟踪、OCR、频谱/频率、时序及帧级分析后端）；使用 API 可访问 MLLM 作为噪声教师生成"工具增强推理轨迹"，通过真实/虚假标签过滤，再以掩码 token 级交叉熵损失训练模型。
  • 阶段一创新：采用岭回归形式的 RRInf 影响力函数估计每条轨迹的效用分数，并据此为轨迹赋予自适应权重，每 γ 轮迭代重计算权重，避免直接构造和求逆大模型的 Hessian 矩阵。
  • 阶段二：采用强化学习（GRPO 框架）优化模型，奖励函数由最终结果奖励（二元正确性）与轨迹质量奖励（多维度评估工具使用轨迹）共同组成。
  • 阶段二创新：采用交替优化策略，先优化模型，再基于更新后模型收集的工具使用经验演化工具集，使模型与工具集逐步协同适应。
  • 关键技术细节：掩码损失仅优化主动推理与工具调用 token，避免模型记忆工具观测结果；教师轨迹经标签过滤后用影响力加权，而非等权使用。
