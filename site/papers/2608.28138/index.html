Token-Budget Distillation: Transferring Full-Token Semantics to Compressed Video Vision-Language Models

2026-08-28 · 原文 · 翻译 · 2608.28138

论文提出 Token-Budget Distillation (TBD)，一个参数高效的微调框架，用于在固定 token 预算下适配视频视觉语言模型（Video VLM）。 核心问题是：视觉 token 压缩虽能大幅降低计算开销，但直接在压缩输入上微调会导致 语义漂移（semantic drift） 和明显性能下降。 解决思路是采用双路径教师-学生蒸馏设计，将全 token 教师模型的完整语义可靠地迁移到压缩学生模型中，同时保持推理高效。

Card 02 论文概述

论文概述

  • 论文提出 Token-Budget Distillation (TBD)，一个参数高效的微调框架，用于在固定 token 预算下适配视频视觉语言模型（Video VLM）。
  • 核心问题是：视觉 token 压缩虽能大幅降低计算开销，但直接在压缩输入上微调会导致 语义漂移（semantic drift） 和明显性能下降。
  • 解决思路是采用双路径教师-学生蒸馏设计，将全 token 教师模型的完整语义可靠地迁移到压缩学生模型中，同时保持推理高效。
Card 03 核心贡献

核心贡献

  • 识别并形式化了语义漂移问题：揭示直接对压缩视觉 token 微调时，空间稀释导致模型视觉注意力从精确判别性行为（如"骑自行车"）漂移到模糊概念（如"移动物体"），将高效适配重新定义为语义保持问题。
  • 提出 Token-Budget Distillation (TBD) 框架：整合答案区域 KL 对齐、GT 锚定边界监督（GT-anchored margin supervision）和可靠性感知 KD 控制，在冻结主干、仅更新 LoRA 的设定下安全传递全 token 语义。
  • 深度机制分析与实证成功：在三个主流视频 VLM 骨干上实现一致的 SOTA 精度-效率权衡；分析表明 TBD 能修复输出分布错位、重建稳健决策边界、阻止视觉注意力漂移。
Card 04 方法描述

方法描述

  • 双路径架构：教师分支处理全 token 序列（冻结、无梯度、LoRA 关闭），学生分支经 FlashVID 压缩后处理 token（LoRA 开启、可训练）；训练后仅保留学生分支用于推理。
  • Compression-Aware LoRA Adaptation：冻结预训练主干，仅更新低秩适配器（LoRA），结合 FlashVID 视频路径 token 压缩。
  • 可靠蒸馏损失：

- 任务损失：标准交叉熵（student 输出与 GT 答案）

- 答案区域 KL 蒸馏：仅对齐教师最自信和相关的 token 分布，过滤噪声

- GT 锚定边界蒸馏：用 Huber 损失约束学生与教师的 logit margin 差距

- 可靠性感知 KD 控制：教师正确且高置信的位置（Ω掩码）才参与蒸馏，避免错误监督

  • 动态 KD warmup：训练早期弱化蒸馏权重，避免学生尚未适应时被教师噪声干扰。
Card 05 数据集与资源

数据集与资源

  • 训练数据：视频指令微调数据（VLM 标准指令数据）
  • 模型骨干：LLaVA-Video、LLaVA-OneVision、Qwen3-VL-8B-Instruct（8B 参数级别）
  • 评估基准：MVBench、VideoMME、EgoSchema、LongVideoBench 四个视频理解基准。
  • 压缩模块：FlashVID 式时空 token 压缩；保留比率 R = 20%（中等压缩）和 R = 10%（激进压缩）。
Card 06 评估与结果

评估与结果

  • 评估协议：在四种基准上比较 TBD 与压缩-only 基线，覆盖中等（R=20%）和激进（R=10%）压缩两种设置。
  • 关键结果 1：在 LLaVA-Video 上，R=10% 时 TBD 保持 97.0% 的全 token 模型平均准确率。
  • 关键结果 2：在 LLaVA-OneVision 上，R=10% 时 TBD 达到平均分 58.4，相对准确率达到 100.0%，完全匹配全 token 模型。
  • 消融与分析：验证了答案区域 KL、GT 锚定 margin、可靠性 KD 控制、动态 warmup 各自的有效性；通过 logit 分布对齐、决策边界、注意力漂移三类分析证实 TBD 从机制层面修复压缩模型的内部表征。
Card 07 结论与局限性

结论与局限性

  • 结论：TBD 成功将全 token 语义迁移到压缩视频 VLM 中，在激进压缩下仍保持接近甚至匹配全 token 模型的性能，同时显著降低计算开销。
  • 局限性：蒸馏依赖全 token 教师的前向计算，训练阶段开销较高；压缩模块固定为 FlashVID，未探索其他压缩算子的迁移性；实验集中在 8B 规模模型，更大规模模型上的表现有待验证。
