PROVIA: Procedure State Tracking for Online Mistake Detection in Egocentric Videos

2026-09-17 · 原文 · 翻译 · 2609.20638

论文研究第一人称（egocentric）视频中的在线错误检测问题：助手需在下一步开始前仅凭过去帧发现操作错误，并在操作者恢复后继续工作。 论文指出当前在线方法采用"首次错误协议"（first-mistake protocol）存在严重缺陷——仅凭固定时间规则（不读取任何帧）即可在基准上取得完美 F1，导致评测失真。 PROVIA 将错误检测建模为对流程状态（procedure state）的在线贝叶斯推断，在完整试验（含错误与修复）上、在验证集误报预算约束下、对照"仅使用时间信息"的基线进行评估。

Card 02 论文概述

论文概述

  • 论文研究第一人称（egocentric）视频中的在线错误检测问题：助手需在下一步开始前仅凭过去帧发现操作错误，并在操作者恢复后继续工作。

Card 03 核心贡献

核心贡献

  • 揭示当前在线错误检测评测协议存在免感知（perception-free）完美 F1 解，并提出在完整试验上、在既定误报预算下、对照无感知控制基线的评测方案。
  • 提出在线模型将"实际操作执行"与"被接受的流程进展"分离：事实状态（factual state）记录每个执行者已完成的步骤（含错误与纠正），精确后验覆盖流程自动机状态与各执行者执行状态。
  • 通过贝叶斯状态合并（Bayesian state merging）从正确演示中自动归纳流程自动机，无需人工设定状态数、相似度阈值或编辑代价。
  • 在 CaptainCook4D、IndustReal、HoloAssist、IMPACT-ego 四个跨领域基准上，以单一滤波器和单一优化规则取得最高的步骤级 AP 与 AUROC；消融实验证明推理时移除"已执行记录"会损害三个单执行者基准的精度。
Card 04 方法描述

方法描述

  • 在线步骤分割（Online Step Segmentation）：采用因果标记点过程（causal marked point process），以软plus强度输出事件强度与步骤因子（动词/名词/工具），训练用点过程负对数似然，解码用因果后验中位数作为事件判决规则。
  • 流程自动机归纳（Procedure Automaton Induction）：将正确演示解码后按完成时间交错为执行者标记的步骤序列，构建前缀树，再用贝叶斯状态合并（Jeffreys 先验的 Beta-Bernoulli 与 Dirichlet 证据）贪心合并等价状态。
  • 贝叶斯滤波（Bayesian Filtering）：每个步骤段维护 GRU 状态构成事实状态，按段更新；分类器以流程状态统计量（后继支持、终止概率、续行熵）为键，产生各执行状态（正确/错误/纠正/插入）的对数软max得分。
  • 顺序检测规则（Sequential Detection Rule）：将逐帧错误概率经顺序检验转化为告警，在规定的误报预算下运行；流程状态转移只在"正确"分支发生，错误与纠正分支保留源状态。
Card 05 数据集与资源

数据集与资源

  • 评估基准：CaptainCook4D（烹饪）、IndustReal（工业装配）、HoloAssist（真实任务）、IMPACT-ego（双手工业操作），涵盖单执行者与双手（K=2）标注。
  • 文中还分析了 Assembly101、Assembly101-O、EPIC-Tent-O 作为被批判的既有协议基准。
  • 实验设置：共享步骤分割特征流，训练/验证/测试划分，验证集上选择满足误报预算的最高召回阈值，再对测试集评分。
  • 推理速度：58–70 帧/秒（FPS）；源码公开于 https://github.com/Kratos-Wen/PROVIA
Card 06 评估与结果

评估与结果

  • 评测协议：告警级协议——整段录音（含正确执行）评分，每个注释步骤拥有其完成单元，告警在错误单元内（或下一个判决）计为命中；误报按"正确操作分钟数"计数（0.1、0.5、1 次/分钟三档预算）。
  • 步骤级指标：在注释步骤段上计算 AP（平均精度） 与 AUROC，短于 0.5 秒的段不参与评分。
  • 关键结果：在 0.1 次/分钟误报预算下，CaptainCook4D 上召回 .154 vs .128；HoloAssist 上召回 .034 vs .015，并在所有预算档位上领先。
  • 与仅使用索引、已用时间、训练步骤错误频率的三种无感知控制基线对比，PROVIA 仅在超过全部控制基线的基准上记为检测成功。
