Card 02 论文概述

论文概述

  • 论文提出 E-AVI 框架，用于自动化视频面试的多模态评估，通过提取带时间戳的结构化多模态证据（文本、声学、视觉信号）来支撑评分

Card 03 核心贡献

核心贡献

  • 提出证据接地的多模态面试评估框架，提取结构化、带时间戳的多模态证据
  • 在公开和私有面试数据集上评估，预测性能持续优于微调的多模态基线
  • 设计维度条件化评分机制，结合证据注意力和源级嵌入进行预测
  • 进行了证据接地、预测贡献、统计不确定性、困难案例和 QA 质量的全面分析
Card 04 方法描述

方法描述

  • 证据提取：训练 MiniCPM-o 4.5 作为统一证据提取器，使用教师生成的监督；Qwen3-VL-32B-Instruct、Qwen3.5 和 Qwen3.5-Omni 分别作为视觉、文本和声学证据的模态特定教师
  • 维度条件评分：证据项序列化后映射为嵌入，与源级多模态嵌入（视觉、声学、文本）通过注意力机制联合参与评分，使用维度特定查询注意力
  • 弱注意力监督：使用基于模态约束和事件类型映射的规则派生相关性目标进行训练
  • 后续 QA 支持：训练提取器在问题条件重检查模式下工作，通过 Mask-and-Ask 和 Second-Pass Mining 两种方法自动构造重检查监督数据
Card 05 数据集与资源

数据集与资源

  • 使用 RecruitView 公开数据集
  • 使用私有酒店面试数据集，来自真实面试场景
  • 证据提取器模型：MiniCPM-o 4.5（经过 LoRA 适配）
  • 教师模型：Qwen3-VL-32B-Instruct、Qwen3.5、Qwen3.5-Omni
  • 论文中未明确提及具体训练资源（GPU/TPU）和模型参数量
Card 06 评估与结果

评估与结果

  • 评估在 RecruitView 和私有酒店数据集上进行，设置三种场景：Zero-shot、Few-shot、Fine-tuned
  • 主要评估指标：MAE（↓）、MSE（↓）、ρ（↑）、τ（↑）、C（↑）、r（↑）
  • 在 RecruitView Fine-tuned 设置下，E-AVI 达到 MAE 0.607、MSE 0.895、ρ 0.541、τ 0.385、C 0.693、r 0.492，全面优于所有基线（包括 GPT-4o、Q3-VL、VL2-AV、MCPM-o）
  • 在私有酒店数据集 Fine-tuned 设置下，E-AVI 同样在排名相关性等指标上优于所有基线
  • 还进行了消融分析、证据删除、bootstrap 不确定性、人工证据审计和 QA 质量评估，验证证据路径的预测贡献和实用性
