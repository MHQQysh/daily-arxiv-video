论文概述

Card 03 核心贡献

核心贡献

  • 新任务与数据集：首次研究T2V-FNVD问题并定义为三元分类任务；构建首个纯合成假新闻视频数据集PS-FNVD（6,636个视频），通过Type 1（虚构事件对齐欺骗）和Type 2（真实事件虚假视觉来源）的系统化设计，防止模型利用单模态捷径
  • 推理引导检测框架：提出 R-T2V 框架，基于七维推理拓扑同时评估语义逻辑与物理生成痕迹；通过条件化理性生成（conditioned rationale generation）利用真实标签约束GPT-4o生成CoT推理轨迹，避免教师模型自身错误进入训练数据
  • 显式解耦：通过监督微调（SFT）训练结构化推理轨迹，R-T2V在输出最终标签前先分别评判语义逻辑层面与物理生成层面的证据，实现"廉价造假"与"纯合成造假"的行为级解耦
  • SOTA性能：在10个主流基线上取得最优表现，准确率超过第二名12.20个百分点，macro F1超过8.46个百分点
Card 04 方法描述

方法描述

  • 数据集构建：基于公开FakeSV数据集和SOTA T2V生成模型 Hunyuan Video，引入两个专用LLM提示作者（P₁和P₂）生成高描述性T2V提示
  • Type 1生成：以廉价假新闻视频文本为输入，扩展为视觉丰富的提示后由T2V模型生成与虚构叙事完美对齐的合成视频，制造模态对齐陷阱
  • Type 2生成：保留真实事件文本，由P₂构思夸大、煽情或情境错位的视觉场景（如小地震配海啸画面），T2V模型据此合成虚假视觉证据
  • 安全绕过策略：采用上下文操控（context manipulation）、客观视觉聚焦、适度实体泛化（moderated entity generalization）等方法克服商业模型拒绝生成敏感灾害内容的限制
  • R-T2V框架：数据中心的七维推理拓扑，横跨FNVD语义逻辑和物理生成痕迹两个类别；使用GPT-4o生成条件化CoT轨迹，再通过SFT微调实现推理与分类的联合学习
  • 量化对齐评估：使用CLIP文本与视频帧嵌入的 Jensen-Shannon（JS）散度验证模态对齐陷阱的存在
Card 05 数据集与资源

数据集与资源

  • PS-FNVD数据集：共6,636个新闻视频——真实（Label 0）1,687个、廉价造假（Label 1）1,631个、纯合成造假（Label 2）3,318个（其中Type 1共1,631个基于廉价假叙述生成，Type 2共1,687个基于真实新闻文本生成）
  • 数据集采用一对一映射策略，使同一语义上下文下同时存在不同真实性和视觉来源的配对视频，防止模型利用文本类先验偏差
  • 使用 Hunyuan Video 作为T2V生成模型，GPT-4o 作为MLLM教师模型生成CoT推理语料
  • 每段视频均匀采样16帧作为视觉输入
  • 代码已开源：https://github.com/TrustworthyComp/PS-FNVD
Card 06 评估与结果

评估与结果

  • 评估设置：涵盖零样本MLLM、基于智能体的推理和监督训练范式共10个主流基线
  • 主要指标：准确率（Accuracy）和宏平均F1（macro F₁）
  • R-T2V 取得SOTA：准确率较第二名基线提升12.20个百分点，macro F₁提升8.46个百分点
  • 量化验证：JS散度均值显示Type 1纯合成（0.057）与真实新闻（0.056）的对齐度高度接近，而廉价造假（0.060）存在明显跨模态不一致；两样本KS检验确认廉价造假与真实新闻的分布差距（D=0.265）是Type 1纯合成差距（D=0.114）的两倍以上，实证验证了模态对齐陷阱
  • 消融研究验证了显式解耦和七维推理拓扑的有效性；附录还包含跨T2V生成器评估、FakeSV向后兼容性验证及FakeTT极端域转移下的错误分析
