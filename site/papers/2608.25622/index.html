Card 02 论文概述

论文概述

  • 论文研究可执行视频编辑规划（executable video-editing planning）问题：给定编辑意图（brief）、素材片段池、音乐元数据和硬性约束，规划器必须输出一个可被下游工具链执行的结构化编辑计划（clip 选择、修剪、排序、转场、时长与音乐对齐等）。
  • 与依赖提示词封装前端模型的工作流系统（如 DIRECT、LVAS-Agent、GLANCE 等）不同，RefineCut 训练一个紧凑的开源权重（open-weight）8B 规划器，让编辑决策可以被学习、验证和迭代优化，而非仅仅被提示。
  • 核心思路在于利用确定性验证器（deterministic verifier）：每个编辑补丁可由验证器实际应用并对照约束台账（constraint ledger）逐条核查，使编辑规划层具备可验证性，从而支持执行级监督和自改进。
Card 03 核心贡献

核心贡献

  • 形式化定义可执行视频编辑规划任务，并发布 RefineCut-Bench 基准：包含 3,578 个任务、7,971 个带字幕片段、499 个音乐曲目、显式约束台账和多教师轨迹。
  • 提出验证器回放轨迹蒸馏（verifier-replayed trajectory distillation）：对多教师分支进行规范化后，用确定性验证器逐一回放，仅保留验证器最优分支作为 SFT 目标和混合粒度偏好对，避免直接模仿噪声教师轨迹。
  • 提出 RefineCut-Evo：受 EvoLM 启发的验证器中心、评分标准结构化自改进阶段，学生用验证器和任务评分标准（ER1–ER7）给自己的修复候选打分，并在高置信偏好对上用 DPO 训练。
  • 跨三个开源骨干（Qwen3-8B、Llama-3.1-8B、GLM-4-9B）验证：验证器回放一致优于原始模仿；最终 8B 规划器在相同闭环中匹配或超越其前沿教师模型。
Card 04 方法描述

方法描述

  • 任务实例为五元组 x=(b, C, M, s₀, L)：自然语言 brief、带字幕和视觉元数据的片段池、可选音乐元数据（节拍与能量）、初始时间线状态、显式约束台账。
  • 规划器通过 RefinePatch（RFC 6902 风格的 JSON Patch）在类型化时间线上执行编辑，补丁覆盖片段选择、修剪、排序、转场、音乐同步和占位符生成；验证器执行 Apply 和 Verify，推进状态并重算台账。
  • 约束台账涵盖七个字段级约束族：duration、transition、music_sync、clip inclusion、clip exclusion、repeat limit、pacing；硬约束通过确定性通过/失败测试（HardPass），软约束提供分级得分评估。
  • 蒸馏阶段使用三个前沿 API 教师（GPT-5.4、Qwen3-Max、DeepSeek-V4-Pro）生成轨迹，经规范化、验证器回放和分支仲裁后用于 SFT 与 DPO 训练。
  • RefineCut-Evo 在推理时采用闭环部署（closed-loop deployment）：规划器与验证器一起运行，无需任何教师调用，学生可自行生成候选、用验证器+评分标准评分并以高间隔偏好对自训练。
Card 05 数据集与资源

数据集与资源

  • RefineCut-Bench：3,578 个任务、7,971 个带字幕片段（23,913 条字幕来源）、499 个音乐曲目，分词为训练/开发/测试集（含 canonical IDs 和 human-written brief 验证集）。
  • 骨干模型：Qwen3-8B（主模型）、Llama-3.1-8B、GLM-4-9B（跨骨干迁移实验）。
  • 训练方法：SFT、Traj-Pref DPO、Mixed-Pref DPO、RefineCut-Evo DPO，使用 LoRA 微调；教师轨迹来自 GPT-5.4、Qwen3-Max、DeepSeek-V4-Pro。
  • 训练资源配置细节见论文附录（LoRA、计算预算与成本）；代码和 RefineCut-Bench 已公开发布。
Card 06 评估与结果

评估与结果

  • 评估采用三层协议：执行门（Execution Gate）（schema 有效性、补丁可应用性、时间线合法性）、规划质量（Planning Quality）（约束满足、片段接地、时长、节奏、收敛性）、人工渲染偏好（指令贴合、内容相关、时序连贯、镜头连续性、节奏、音视频律动等）。
  • 核心指标为 VES（Video-Editing Score） 综合分数；验证器完全决定前两层指标，确保每个分数都是台账的可核查结果。
  • 验证器回放蒸馏将规划器 VES 从 0.620 提升至 0.858；RefineCut-Evo 进一步达到 0.924。
  • 增益成功迁移至 Llama-3.1-8B 和 GLM-4-9B；在相同闭环设置下，8B 规划器匹配或超过其前沿教师（GPT-5.4、Qwen3-Max、DeepSeek-V4-Pro）。
  • 额外分析包括：教师回放诊断（RQ2）、Evo 自改进归因（RQ4）、跨骨干迁移（RQ5a）、与前沿策略同环对比（RQ5b）、未训练骨干上的提示/反馈/搜索（RQ5c）、canonical-clean 与人工撰写 brief 的鲁棒性、失败构成分析、LLM-judge 一致性、语义输入干预以及最终渲染预览的盲测偏好。
