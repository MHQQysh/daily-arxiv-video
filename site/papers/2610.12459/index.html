WorldGuide: Goal-Directed Video World Model for Procedural Task Execution

2026-10-08 · 原文 · 翻译 · 2610.12459

论文聚焦于长时程程序性任务的视频生成问题，指出现有视频生成模型虽能合成视觉上合理的轨迹，但无法根据已生成的结果自适应地决定下一步动作，也无法判断任务是否完成。 论文提出将程序性视频生成建模为视觉世界空间中的闭环任务执行，并引入 WorldGuide 模型：仅给定初始图像和任务目标，模型循环执行"预测原子动作 → 生成对应视频片段 → 依据生成结果选择下一步或终止"的过程。 现有闭环系统（如 ORCA、CollabVR、NovaPlan 等）通常依赖预训练执行器或间接验证，存在"规划与执行脱节"的问题——规划正确但执行器无法可靠实现动作；WorldGuide 通过让规划器（ContextPlanner）与执行器（Executor）在同一演示数据上联合训练来解决该问题。

Card 03 核心贡献

核心贡献

  • 提出闭环任务执行的视频世界模型公式化：将程序性视频生成定义为视觉世界空间中的闭环任务执行，规划器从生成的视觉状态中预测下一步原子动作或完成标记，执行器在直接监督下实现预测的动作，二者在同一演示数据上训练。
  • 构建 WorldGuide Bench 数据集：由于缺乏步骤级动作-视频监督数据，论文构建了约 59K 个带步骤标注的视频，覆盖 245 个任务和 27 个程序性类别，每个片段具有时间定位的原子动作标注和显式的完成信号。
  • 设计分层视觉记忆机制：执行器维护分层压缩的视觉记忆，较老的历史以逐步粗糙的空间分辨率表示，在 rollout 增长时限定 token 成本，支持长时程执行的状态连续性。
  • 实现规划与执行的联合训练范式：ContextPlanner 首先训练并冻结，其动作嵌入用于执行器的微调，确保执行器学会渲染规划器被训练去提议的同一批原子动作。
  • 在多个基准上验证有效性：在 WorldGuide-Bench 上达到 33.33% 任务成功率（对比 MiniMax-H3 的 29.90%），在 VideoCraft-Bench 上达到 47.69%（对比 MiniMax-H3 的 32.73%）。
Card 04 方法描述

方法描述

  • 整体架构：WorldGuide 由两个组件构成——ContextPlanner（π_θ）和 Executor（f_φ）；给定初始图像 x₀ 和目标 g，规划器预测下一步原子动作 a_t 或完成标记 <\|Task Completed\|>（DONE），执行器以 a_t、当前视觉状态 x_t 和视觉记忆 M_t 为条件生成下一段视频片段 x_{t+1}；循环直到预测出 DONE 或达到步数预算。
  • ContextPlanner：基于 Qwen2.5-VL-7B 模型，通过监督微调训练；输入为任务目标、当前视觉状态以及最近的 K=3 个片段-动作对历史 h_t，输出为自然语言动作指令或完成标记；训练使用掩码交叉熵损失，仅对响应 token 计算，无架构修改或辅助目标。
  • Executor：基于 HunyuanVideo-1.5 扩散 Transformer；文本条件包括来自冻结 ContextPlanner 的动作嵌入，参考图像以潜在张量形式通道堆叠到含噪潜在变量上，并伴随有效性掩码；使用流匹配参数化，训练损失为掩码均方误差，监督限制在有效区域。
  • 分层记忆压缩：执行器的视觉记忆采用层次化压缩策略，较老的帧以更粗的空间分辨率表示，从而以有界的历史 token 成本维持长时间执行的状态连续性。
  • 两阶段训练：先训练 ContextPlanner，冻结后将其动作嵌入用于 Executor 的微调；推理时动作预测和终止决策依赖执行器生成的结果。
Card 05 数据集与资源

数据集与资源

  • WorldGuide Bench：约 59K 个步骤级标注视频，覆盖 245 个任务和 27 个程序性类别；每个视频被分割为时间定位的原子动作片段，含显式完成信号。
  • 规划器初始化自 Qwen2.5-VL-7B（约 70 亿参数），执行器初始化自 HunyuanVideo-1.5。
  • 训练采用两阶段顺序训练：先训练 ContextPlanner，冻结后用其嵌入微调 Executor；具体 GPU 资源未在摘要与正文中明确说明。
Card 06 评估与结果

评估与结果

  • 基准与对比：在 WorldGuide-Bench 上比较 WorldGuide 与强基线 MiniMax-H3；在 VideoCraft-Bench 上同样以 MiniMax-H3 为基线；评估设置包含目标条件（goal-only）与提供参考动作计划（reference action plans）两种条件。
  • 主要指标：包括 Task Success（任务成功率）、Plan Accuracy（规划准确率）、Order Score（顺序评分）、Repeat/Skip（重复/跳过率）、Aesthetic Quality（美学质量） 和 Overall Consistency（整体一致性），另有 VBench 视频质量指标、成对对齐指标等。
  • 关键结果：

- 在 WorldGuide-Bench 上达到 33.33% 任务成功率，超过接收参考动作计划的 MiniMax-H3（29.90%）。

- 在 VideoCraft-Bench 的仅目标条件设置下达到 47.69%，对比 MiniMax-H3 的 32.73%。

- 闭环执行相比开环变体在任务成功率上提升 21.62%；视觉反馈使任务成功率提升 18.61%、计划成功率提升 5.34%，并降低重复/跳过率 4.46%；分层记忆带来 5.77%（WorldGuide Bench）和 17.91%（VideoCraft-Bench）的提升。

- 在 WorldGuide-Bench 上取得最高的美学质量和整体一致性。
