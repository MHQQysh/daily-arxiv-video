Card 02 论文概述

论文概述

  • 论文提出 LeVJEPA，首个在 LeJEPA 的无坍塌目标下训练的视频编码器，完全摒弃了目标编码器（target encoder）、预测器（predictor）和 stop-gradient 等防止表示坍塌的传统机制。
  • 核心目标是将视频自监督预训练大幅简化并提升效率，解决现有视频联合嵌入方法计算开销大、设计复杂、依赖启发式技巧的问题。
  • 方法仅需一个编码器和一个投影头，训练目标仅由不变性损失（MSE）和 SIGReg 正则化组成，并证明该配方在精度和效率上均优于现有视频预训练方法。
Card 03 核心贡献

核心贡献

  • 计算效率显著提升：在相同 epoch 和相同数据下，LeVJEPA 在 ViT-S/B/L 上以 5.6× 到 20.8× 更少的预训练计算量达到或超越 V-JEPA 2 的精度；在匹配总 FLOPs 时，ImageNet-1K 上比最强视频基线高出 7.6 个点。
  • 简化训练配方：可训练架构仅包含编码器和投影器，无预测网络、目标编码器或 stop-gradient；目标函数只有一个超参数（λ=0.02），并在所有实验中固定。
  • 随机 token dropping：均匀随机丢弃 95% token 作为增强手段，而非近似重建任务，同时提升下游精度（ImageNet 从 33.9% 提升到 47.6%）并大幅降低计算成本。
  • 块因果注意力（block-causal attention）：在不损失精度的前提下实现因果帧表示，使每个帧表示仅依赖过去观测，可流式扩展而无需重新编码，适合自回归世界模型。
  • 涌现的 token 级语义结构：仅监督 clip 级 [cls] token，却自然产生类似 V-JEPA 2.1 的、有语义组织的 patch 级表示，无需额外的 patch 级损失。
Card 04 方法描述

方法描述

  • 采用单一共享编码器处理一个全局视图和 V 个局部视图（同一时间窗口，空间裁剪和光度增强），局部视图向全局视图对齐，损失为均方误差（MSE）。
  • 使用 SIGReg 正则化：将嵌入批次投影到随机方向，通过正态性检验惩罚偏离标准高斯的分布，将嵌入约束为各向同性高斯，从而理论上排除坍塌。
  • 视图内随机均匀丢弃 95% patch token，仅保留少量 token 输入编码器，大幅降低预训练 FLOPs。
  • 编码器采用 V-JEPA 风格的视频 Transformer，支持块因果注意力（帧内双向、帧间因果），token 化按帧进行，无需时间维度的 patch 聚合。
  • 投影器在小维度空间施加损失，预训练后丢弃投影器，下游任务直接使用编码器表示。
Card 05 数据集与资源

数据集与资源

  • 预训练数据：Kinetics-710（K710）的 20% 子集，用于 epoch-matched 和 FLOP-matched 对比实验。
  • 模型规模：ViT-S、ViT-B、ViT-L，以及实验用的 ViT-Tiny。
  • 训练资源：ViT-Tiny 可在单张消费级 GPU 上预训练 12 小时（未标注行走视频）即获得非平凡 ImageNet 精度；大规模实验使用多 GPU 集群，具体未详述。
Card 06 评估与结果

评估与结果

  • 评估基准：ImageNet-1K（attentive probing）、Kinetics-400（线性探测）、Something-Something-v2（运动中心基准），并对比 DINOv2 图像预训练基线和 V-JEPA 2 视频基线。
  • 主要指标：冻结特征 probing 精度（attentive probing / linear probing）。
  • 关键结果：

- 在相同 epoch、相同数据下，LeVJEPA 在 ViT-S/B/L 上匹配或超越 V-JEPA 2，同时预训练计算量减少 5.6×–20.8×。

- 在匹配总 FLOPs 时，ImageNet-1K 上比最强视频基线高 7.6 点，Kinetics-400 取得最高准确率，并在 Something-Something-v2 上保持竞争力。

- 对比 compute-matched DINOv2（帧级图像预训练），LeVJEPA 在 appearance-centric 评估上接近 DINOv2，在 motion-centric 准确率上几乎翻倍。

- 随机 token dropping 比例从 0% 到 95% 单调提升 ImageNet 精度（33.9% → 47.6%）。

- 块因果注意力与完全双向注意力的冻结 probing 精度相当，无精度损失。
