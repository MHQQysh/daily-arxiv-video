Visual Token Coding for Video Multimodal Large Language Models

2026-08-28 · 原文 · 翻译 · 2608.28008

提出一种面向视频多模态大语言模型（Video MLLMs）的新型 token 压缩范式——视觉令牌编码（Visual Token Coding, VTC），借鉴 HEVC 等经典视频编码原理。 通过预测视频的 I/P 帧并计算帧间残差来估计 token 冗余，从而实现对视觉 token 的结构化压缩，降低视频 MLLM 的计算和内存开销。 针对现有 token 压缩方法仅依赖 token 重要性或相似度、缺乏参考-残差建模的问题，VTC 将视频编码的结构化压缩策略迁移到视觉特征空间，并实现即插即用、无需额外微调。

Card 03 核心贡献

核心贡献

  • 首次提出基于视频编码原理的视觉令牌编码（VTC）范式，验证了结构压缩策略用于 token 剪枝的可行性。
  • 在基线 VTC 之上提出增强版本 VTC_Dy，包含动态分辨率输入（DyRSO）、动态令牌分配（DyTA）和空间覆盖 Top-K（SC-TopK）三种动态设计。
  • VTC 具有查询无关性、时序建模能力和空间完整性，可作为即插即用模块直接应用于现有 MLLM，无需修改架构或额外训练。
  • 在多种视频理解基准上验证了 VTC 对不同 MLLM 的通用性，并在与 SOTA 压缩方法的对比中取得竞争性或更优性能。
Card 04 方法描述

方法描述

  • 基线 VTC：将视频特征序列划分为连续块（chunk），首帧作为语义 I 帧，后续帧通过身份预测（identity prediction）得到残差 R_t = F_t - F_ref，按残差能量 E_{t,i} = \|\|R_t(i)\|\|_2 衡量 token 的新增信息量，保留残差能量最高的 Top-K token。
  • 语义 I/P 帧分类：当帧平均残差能量超过历史均值的 τ 倍时，将该帧判定为语义 I 帧，否则为 P 帧，并对每个 chunk 内 I 帧数量设置上限 M_I^{max}。
  • 动态分辨率输入（DyRSO）：通过动态分辨率的 GOP 扩展时序覆盖范围，使有限的 token 预算覆盖更丰富的视频内容。
  • 动态令牌分配（DyTA）：利用 HEVC 码流 bitcost 作为非学习的时序复杂度信号，按帧的时间复杂度重新分配 P 帧的 token 预算。
  • 空间覆盖 Top-K（SC-TopK）：结合区域级与全局级 token 选择，在保持空间完整性的同时优先保留高残差能量的 token。

Card 06 评估与结果

评估与结果

  • 在 Qwen3-VL-8B 上，VTC_Dy 在 50% token 预算下达到平均 100.1% 的性能保持率；在 25% token 预算下仍保持 97.8% 的平均性能。
  • 在 LLaVA-OneVision-7B 上，VTC 和 VTC_Dy 在 50% token 保留率下分别保持 100.3% 和 101.6% 的性能。
  • 与 SOTA 方法对比：VTC_Dy 在 Qwen3-VL 上平均性能比 FlashVID 高 1.4 个百分点。
  • 消融研究验证了 DyRSO、DyTA、SC-TopK 各组件的有效性，以及 VTC 在不同 MLLM 上的泛化能力和效率优势。
