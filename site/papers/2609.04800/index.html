Intrinsic Temporal Adaptation of CLIP for Partially Relevant Video Retrieval

Card 02 论文概述

论文概述

  • 论文聚焦于部分相关视频检索（Partially Relevant Video Retrieval, PRVR）任务，即从未剪辑视频中检索包含与文本查询相关时刻的视频片段
  • 现有方法通常依赖冻结的 CLIP 帧级特征，缺乏时间理解能力；即使进行了参数高效的 CLIP 适配，视频级预测仍可能基于不精确的帧级证据
  • 论文提出 Intrinsic Temporal Adaptation (ITA) 框架，在 CLIP 骨干内部注入时间交互能力，并通过亲和力加权的梯度传播缓解弱监督问题
Card 03 核心贡献

核心贡献

  • 提出 Backbone-Internal Temporal Adaptation：允许 CLIP 视觉编码器最后几层对相邻帧分组进行注意力计算，使帧嵌入具备时间感知能力，同时保持骨干冻结、仅训练适配参数
  • 引入 Affinity-Weighted Gradient Propagation (AWGP)：基于文本-帧亲和力选择 top-k 帧并软性聚合，将对比学习信号传播到多个与查询相关的帧，解决 PRVR 弱监督问题
  • 在 TVR、ActivityNet Captions、Charades-STA 三个 PRVR 基准上达到最先进的检索性能，同时保持高效的参数和计算开销
  • 验证了方法的跨数据集泛化能力和帧级时间理解能力，能检索到更准确的查询相关时刻帧级证据
Card 04 方法描述

方法描述

  • Grouped Temporal Attention：将连续帧的视觉 token（含 class token 和 patch token）拼接为分组序列，在 CLIP 最后几层执行组内自注意力，输出再拆分回各帧表示；分组大小 gℓ ∈ {2, 4}
  • Temporal Bias：加入可学习的帧级时间位置编码，以及扩展自 Swin Transformer 的相对时间偏置，使注意力能够区分帧的时间顺序
  • Parameter-Efficient Adaptation：冻结预训练 CLIP 骨干，仅对视觉和文本编码器的 QKV 投影层应用 LoRA，并训练时间位置编码、相对时间偏置和轻量全局帧注意力
  • Affinity-Weighted Gradient Propagation：计算文本-帧亲和力，选择 top-k 帧并按 softmax 权重聚合为视频嵌入，使用双向 InfoNCE 损失训练；top-k 选择逐查询自适应，软权重可调节各帧贡献
  • Inference：与训练使用相同评分函数，额外计算开销可忽略
Card 05 数据集与资源

数据集与资源

  • 评估数据集：TVR、ActivityNet Captions、Charades-STA
  • 视觉编码器：CLIP（冻结骨干 + LoRA 适配）
  • 训练方式：参数高效适配，仅训练 LoRA 参数、时间位置嵌入、相对时间偏置和轻量全局帧注意力层
Card 06 评估与结果

评估与结果

  • 评估指标：R@1、R@5、R@10、R@100、SumR（Recall@K 总和）
  • 在 TVR、ActivityNet Captions、Charades-STA 三个基准上均达到最先进的 PRVR 性能
  • 相较 ProPy 等方法，在严格帧级 top-k 检索（所有 top-k 帧必须来自真实相关视频）上表现显著更稳健，随 k 增大性能下降更缓慢
  • 帧过渡分析显示，ITA 产生的帧间相似度模式更具视频特异性，而非位置依赖的通用条纹模式
  • 在参数效率和计算效率方面具有优势，可训练参数和推理 GFLOPs 更低
