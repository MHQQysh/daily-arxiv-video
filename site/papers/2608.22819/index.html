Card 02 论文概述

论文概述

  • 系统比较了三种训练无关（training-free）的多主体图像到视频（Multi-Subject I2V）生成范式：直接生成（Direct）、并行生成（Parallel） 与 顺序生成（Sequential）。
  • 核心问题：在保持多个主体各自外观、赋予不同运动并维持空间与时间交互的同时，如何利用冻结的预训练视频扩散模型完成多主体视频合成。
  • 研究目标：在统一实验协议下量化三种范式在外观保持、运动保真度、时间一致性和主体间连贯性上的权衡，并总结各自独特的失败模式。
Card 03 核心贡献

核心贡献

  • 首次系统性地对三种训练无关的多主体 I2V 生成范式进行对比研究。
  • 提出共享的图像与文本提示分解流程（GPT-4 文本分解 + Grounding DINO/SAM 图像分解），确保并行与顺序范式的差异仅来源于后续生成策略。
  • 在 I2VGen-XL 与 DynamiCrafter 两个预训练骨干上完成全面的定量与定性对比实验。
  • 引入计算成本分析，揭示三种范式在推理时间与峰值显存上的显著差异。
  • 深入分析每种范式独有的失败模式，为设计可控的多主体视频生成系统提供实践洞察。
Card 04 方法描述

方法描述

  • 直接生成：将完整的多主体参考图与文本提示直接输入冻结的预训练 I2V 模型，一步联合合成所有主体及运动，最大程度保留全局场景语义，但对模型联合建模能力要求极高。
  • 文本分解：使用大语言模型 GPT-4 将原始提示拆分为场景级提示 $T_0$ 与 $N$ 个主体级提示 $\{T_i\}_{i=1}^N$。
  • 图像分解：利用 Grounding DINO 检测 + SAM 分割获取主体掩码，再通过 Stable Diffusion-1.5 修复背景，生成纯背景图与单主体裁剪图。
  • 并行生成：对分解后的每个文本-图像对独立调用 I2V 模型生成主体视频，用 Grounded-SAM-2 提取视频掩码、DDIM 反演获取潜变量轨迹，最终采用 MVOC 视频合成模块实现掩码引导的微特征与注意力注入式合成。
  • 顺序生成：采用级联流程——先由直接生成视频提取背景视频与主体轨迹作为全局先验；再通过 TF-ICON 图像合成模型将主体按轨迹逐帧插入；最后用 AnyV2V 视频到视频细化模型进行时间运动细化。
Card 05 数据集与资源

数据集与资源

  • 自建多主体数据集：手工设计 20 个双主体场景自然文本提示，使用 Stable Diffusion 3.5-Large 生成对应 512×512 参考图像。
  • 统一输出规格：512×512 分辨率、16 帧、8 FPS。
  • 预训练骨干模型：I2VGen-XL（默认）与 DynamiCrafter。
  • 硬件资源：单张 NVIDIA RTX 6000 Ada GPU，混合精度（bfloat16/fp16）运行。
Card 06 评估与结果

评估与结果

  • 评估指标：采用 VBench 风格的五个指标——主体一致性（SC）、背景一致性（BC）、运动平滑度（MS）、美学质量（AQ）、成像质量（IQ）。
  • 顺序生成在所有匹配配置下稳定取得最高的 SC 与 BC，体现了渐进式上下文保留的优势。
  • 直接生成在运动平滑度上始终最优（如 I2VGen-XL 下 MS 最高达 98.49%），且推理时间最短（约 29 秒），峰值显存最低（8.98 GB）。
  • 并行生成单次生成复杂度最低，但独立生成缺乏共享时间上下文，后期视频合成难以完全弥补，最终指标未稳定提升（推理时间约 240 秒）。
  • 顺序生成计算开销最大（推理时间约 441 秒，峰值显存 26.42 GB），但对主体与背景一致性提升效果显著。
  • AQ 与 IQ 依赖骨干模型：顺序生成在 DynamiCrafter 上更优，直接生成在 I2VGen-XL 上表现更强。
  • 典型失败模式：直接生成易产生主体遗漏或运动分配不均；并行生成存在跨主体外观混淆与错误累积（如马逐渐呈现蓝色异常）；顺序生成对中间掩码与轨迹误差敏感，可能产生残余伪影或反向运动。
