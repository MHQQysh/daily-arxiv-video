Card 03 核心贡献

核心贡献

  • 提出 JoHan，一种直接从视频观测学习手部运动分布的生成式框架，不依赖预训练的逐帧姿态估计器。
  • 在统一的运动生成过程中联合生成对齐的 2D 与 3D 局部姿态序列，显式建模其时序动态，并通过 2D–3D 对应关系直接恢复相机坐标系下的全局手部位姿。
  • 设计 2D-Guided Fusion 机制，在流匹配的每个时间步用预测的 2D 运动编码为几何引导，辅助 3D 运动生成，增强跨表示的几何一致性。
  • 采用视频特征与检测器掩码相结合的视觉条件，支持无外部姿态估计条件下的端到端生成，并具备条件丢弃机制以应对检测缺失。
  • 在 HO3Dv2、HO3Dv3 和 HOT3D 基准上取得了更高的重建精度、更平滑的运动轨迹和更高的计算效率。
Card 04 方法描述

方法描述

  • 使用 flow matching（流匹配）学习局部 2D 和 3D 手部运动的联合条件分布，从噪声状态插值生成干净的 2D–3D 运动序列。
  • 2D 分支首先从当前噪声状态预测干净的局部 2D 姿态（归一化关键点和可见性概率），该预测同时参数化 2D 速度场，并通过编码器 $G_s=g(\hat{u}_s,\hat{c}_s)$ 作为 3D 分支的引导。
  • 3D 分支以 MANO 参数（姿态 $\theta$ 和形状 $\beta$）为局部 3D 表示，结合视频特征、手侧标签和 2D 引导，预测干净的 3D 运动序列。
  • 视觉条件由 DINOv3 提取的全帧 patch 特征与 CNN 编码的检测器掩码特征相加得到，并采用 classifier-free guidance 的条件丢弃策略增强鲁棒性。
  • 全局运动恢复：将生成的 2D 局部姿态反归一化到图像坐标后，通过 PnP 求解器 对局部 MANO 关节和 2D 对应点进行求解，估计全局旋转和平移，从而将手部置于相机坐标系。

Card 06 评估与结果

评估与结果

  • 在 HO3Dv3 上，JoHan 达到 PA-MPJPE 7.0 mm、2D 关节误差 4.19 像素、MPJPE 32.8 mm（对比方法中最低）。
  • 在 HOT3D 上，JoHan 达到 PA-MPJPE 4.75 mm、加速度误差 2.69 m/s²，相比 HaWoR 分别提升 21.5% 和 62.3%。
  • 相比 Dyn-HaMR（世界空间网格序列）和 HaWoR（移动相机场景），JoHan 生成的运动更平滑、时间一致性更好，同时保持较高的逐帧姿态精度。
  • 计算效率显著优于需要迭代测试时优化的方法（如 HMP、Dyn-HaMR），无需逐帧姿态估计作为条件或初始化。
