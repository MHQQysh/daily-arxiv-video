论文概述

Card 03 核心贡献

核心贡献

  • 提出 GALATEA 系统，完整打通“生成视频 → HOI 重建 → 仿真跟踪 RL → 策略蒸馏 → 真实世界执行”的流程。
  • 设计一套实用的 HOI 参考提取管线，结合 MoGe-2 深度估计、SAM2 分割、FoundationPose 物体位姿估计、WiLoR 手部重建以及联合手-物优化，从生成视频中恢复 3D 轨迹。
  • 提出改进的跟踪式 RL 训练配方（包括任务无关跟踪目标、参考增强、SAPG 优化器），能从大量含噪声的视频派生 HOI 参考中学习强鲁棒策略。
  • 在真实世界闭环实验中实现了多种操作行为：功能抓取、推/拉（非抓取操作）、抓取后物体位姿调整，支持训练过的和未见过的视频计划。
Card 04 方法描述

方法描述

  • 两阶段方法：第一阶段生成视频并重建 HOI 轨迹；第二阶段在仿真中用跟踪式 RL 学习统一控制器。
  • 视频生成：使用真实首帧 RGB 图像 + 语言指令作为条件，由 Seedance 2.0 生成三类操作（grasp-and-move、push-and-pull、pose-adjust），并利用立体相机采集首帧深度作为度量锚点。
  • HOI 重建：组合 MoGe-2 度量深度估计、SAM2 掩码、FoundationPose 物体位姿初始估计、WiLoR MANO 手部估计，并通过联合手-物优化（包含轮廓、关键点、接触、时间平滑等损失）得到最终轨迹。
  • 仿真训练：使用 Sharpa Wave Hand 安装在 Franka Research 3 机械臂上，在 Isaac Gym（PhysX）中训练跟踪策略；采用非对称 actor-critic，actor 输入包含关节位置、上一动作、腕部位姿、指尖/物体相对位姿、HOI 误差、参考距离和 BPS 形状编码；critic 使用特权仿真状态。
  • 参考增强：对每条源轨迹采样 5 种扰动（接触前手部接近扰动、接触后共享物体运动扰动）以增加多样性，并通过 IK 筛选可执行轨迹。
  • 策略蒸馏：从 1,500+ 条成功落地的专家轨迹中蒸馏出统一策略。
Card 05 数据集与资源

数据集与资源

  • 使用 Seedance 2.0 生成的视频片段约 2,500 条，重建出约 2,000 条可用 HOI 轨迹，其中 超过 1,500 条 成功在仿真中被专家控制器落地。
  • 无公开数据集名称，使用真实采集的物体网格（metric object mesh）和立体深度。
  • 仿真环境：Isaac Gym + PhysX；机器人：Sharpa Wave Hand 灵巧手 + Franka Research 3 机械臂。
  • 策略为 MLP，输出 29 维动作（机械臂+灵巧手）。
Card 06 评估与结果

评估与结果

  • 仿真评估：与基线相比，成功率提高 超过 25 个百分点，验证了 HOI 重建和 RL 训练配方的有效性。
  • 消融实验：分别对 HOI 重建（基准对比）和 RL 公式/优化（基准对比）进行消融，证实联合优化和增强/SAPG 等设计的作用。
  • 真实世界实验：在闭环控制器下，展示了多样抓取（包括功能抓取）、推/拉、以及抓取后物体姿态跟踪等多种行为，说明生成视频计划可以被物理执行。
  • 测试对象包括训练集内的计划和未见过的视频计划，验证了泛化能力。
