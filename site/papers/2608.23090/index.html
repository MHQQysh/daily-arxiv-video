Card 02 论文概述

论文概述

  • 论文提出 Loopy 框架，用于高质量无缝循环视频（seamless looping video）生成，解决现有视频生成模型无法实现循环边界平滑过渡的问题。
  • 首次系统揭示 DiT（Diffusion Transformer） 中不同注意力层的 RoPE（Rotary Position Embedding） 对时间位置控制能力存在显著差异，其中控制效果最强的层可作为"锚点"（anchor）。
  • 基于该发现提出 Anchored Position Embedding Shifting（锚定位置嵌入偏移） 策略，将 DiT 的时间感知从线性序列转变为环形结构，并支持 RGB 和 RGBA 两种模态的循环视频生成。
Card 03 核心贡献

核心贡献

  • 首次揭示 RoPE 层间差异性：定量分析表明 DiT 中各注意力层的 RoPE 对时间位置控制效果不同，早期层通常控制力更强，其中最强层作为"锚点"提供上下文先验。
  • 提出 Anchored Shifting 策略：基于每层 RoPE 的时间控制效应，设计层特定的偏移量分组方案，使循环边界获得均衡的时间控制累积，将 DiT 时间感知从直线变为均匀圆周。
  • 构建高质量循环视频数据集：利用 Wan 2.2 14B + Anchored Shifting 生成 120 个 RGB 和 120 个 RGBA 循环视频（480×832、53 帧），覆盖动物、人像、视觉特效、物体、风景等多样场景。
  • 开发通用 Loopy 框架：通过 LoRA 最小化微调，支持 RGB、RGBA 及多层循环视频生成，同时兼容身份控制、风格迁移等 AIGC 功能。
Card 04 方法描述

方法描述

  • 基于 Wan 2.2 14B 和 Wan-Alpha 等主流开源视频生成模型（DiT 架构），在自注意力层中对 RoPE 进行时间维度的循环偏移（模 T' 长度）。
  • 提出 锚点层确定机制：通过归一化 MSE 指标 α_l 量化每层 RoPE 的时间控制效应，锚点层 α_l 最大，该层保持不移位以减少伪影、保持语义一致性。
  • 设计 分组偏移策略：将相邻层按 α_l 分组，使各组时间控制效应近似均衡，组内共享偏移量，组间偏移量单调递增，从而在循环边界获得均匀的时间控制累积。
  • 采用 LoRA 微调（rank=4）在自构建数据集上训练，训练和推理均使用 Anchored Shifting，消除 VAE 解码器线性时间偏差导致的亮度/颜色抖动。
Card 05 数据集与资源

数据集与资源

  • 自构建循环视频数据集：120 个 RGB + 120 个 RGBA 循环视频，分辨率 480×832，帧数 53 帧，帧率 16 FPS，使用 LightX2V 加速采样（仅 4 步）。
  • 基础模型：Wan2.2-T2V-A14B、Wan2.1-T2V-1.3B/14B、HunyuanVideo 1.5、Wan-Alpha（RGBA 视频生成）。
  • 训练资源：8 张 NVIDIA H20 GPU；Wan 系列微调 240 步（batch size 8），HunyuanVideo 1.5 微调 4,800 步（batch size 1）。
Card 06 评估与结果

评估与结果

  • 评估基准：VBench（美学质量、运动流畅度、循环平滑度）+ GPT-4o（文本对齐、自然度、动态分数）；将视频后半段与前半段拼接评估循环平滑度。
  • 主要指标：Cyclic Smoothness（循环平滑度）和 Dynamic Score（动态分数），越高越好。
  • 关键实验结果：完整 Loopy 在 Wan2.2 14B 骨干上达到 Cyclic Smoothness 0.9925，显著优于 LatentMix（0.9834）、Mobius（0.9892）和 FLF2V 基线（0.9753）。
  • 在 Wan2.1 1.3B/14B、HunyuanVideo 1.5 等多个骨干上均全面超越对比方法（如 HunyuanVideo 1.5 上 0.9914 vs. LatentMix 0.9752、Mobius 0.9872）。
  • RGBA 视频生成中，Loopy 在 Wan-Alpha 骨干上所有指标均优于 LatentMix 和 Mobius；消融实验验证了锚点层、分组偏移和微调三组件各自的重要贡献。
