Card 02 论文概述

论文概述

  • 论文提出 ReGround-Surg，一个轻量级的可靠性引导锚定接地（reliability-guided anchor grounding）框架，用于提升基于 SAM2 的指代性手术视频分割（Referring Surgical Video Segmentation）性能
  • 现有 SAM2 两阶段方法（如 ReSurgSAM2）先在第一阶段（Stage I）进行指代目标接地并选择锚定帧，再在第二阶段（Stage II）通过 SAM2 的跟踪记忆将掩码传播到其余帧；其性能高度依赖初始锚定掩码的质量，一旦锚定错误，错误将被传播到整个视频
  • 手术视频中器械外观相似、存在遮挡和复杂组织-器械交互，导致初始接地极易出错；论文通过定性和定量证据证实"强跟踪无法弥补错误初始接地"这一关键瓶颈
Card 03 核心贡献

核心贡献

  • 分析了当前 SAM2 两阶段手术视频分割中的初始接地瓶颈，并通过定量和定性实验证明不准确的锚定掩码选择会引发持续的跟踪失败
  • 提出 ReGround-Surg 框架，通过共享的文本条件空间可靠性图（reliability map）来增强与指代表达一致的区域、抑制干扰物
  • 设计 Gated Side Adapter (GSA) 模块：在文本到视觉（T2V）注意力之前调制视觉特征，使模型聚焦于与指代表达一致的区域
  • 设计 Reliability-Weighted Vision-to-Text Attention (RW-V2T) 模块：将可靠性图作为乘性权重作用于视觉 key，在 prompt token 聚合时抑制离目标或不可靠的视觉证据
  • 在 Ref-EndoVis17 和 Ref-EndoVis18 三个评测分割上取得一致改进（相对 ReSurgSAM2 分别提升 +3.77、+3.09、+0.94 J&F），仅增加 0.5M 参数且速度开销可忽略
Card 04 方法描述

方法描述

  • 整体架构基于 ReSurgSAM2 的两阶段框架，核心改进集中在 Stage I 的 CSTMamba 跨模态融合模块
  • Text-Guided Reliability Gate：从文本 token 序列中经元素级最大池化提取判别性名词特征，与当前帧视觉特征投影到 64 维瓶颈后计算空间可靠性图 G∈[0,1]^(H×W)，每个 CSTMamba 层独立计算以适应渐进细化的表示
  • GSA：在 T2V 跨注意力前对视觉特征进行软残差调制（floor α=0.3，经网格搜索确定），采用零初始化保证训练初期与基线功能一致，仅调制当前帧特征而保持 CIFS 选择的参考帧特征不变
  • RW-V2T：将可靠性图展平后作为乘性权重施加于视觉 key，残差连接到原始 K 以保证信息无损；W_v 初始化为单位矩阵
  • 训练时冻结 SAM2 图像编码器、CLIP 文本编码器和跟踪记忆模块，仅更新 CrossModalFusionModule；损失函数与 ReSurgSAM2 保持一致（mask BCE + dice + IoU + cls）
  • 推理时新模块仅用于 Stage I，锚定掩码传给原始 SAM2 跟踪阶段，对 Stage II 完全即插即用
Card 05 数据集与资源

数据集与资源

  • 数据集：Ref-EndoVis17（工具分割）和 Ref-EndoVis18（工具分割和组织分割），均基于 EndoVis17/EndoVis18 重新标注实例级标签
  • 模型规模：新增参数约 0.5M，使用 Hiera-Small 骨干作为 SAM2 图像编码器
  • 输入分辨率：512×512
  • 训练资源：8 块 GPU（每 GPU 2 个 batch，总 batch size 16），NVIDIA A100-SXM4-80GB
  • 优化器：AdamW，CSTMamba 参数学习率 5×10⁻⁵，新增 adapter 参数学习率 3×10⁻⁴，线性预热 30% + 余弦衰减，梯度裁剪 ℓ₂ 范数 0.1，训练 60 epochs
Card 06 评估与结果

评估与结果

  • 评估基准：Ref-EndoVis17 和 Ref-EndoVis18 三个分割（EV17 tool、EV18 tool、EV18 tissue），遵循 RVOS 评估协议
  • 主要指标：区域相似度 J、轮廓精度 F 及均值 J&F；额外提出 AnchorAcc（锚定掩码 IoU>0.5 的比例）和 Initial Grounding 指标用于衡量 Stage I 检测质量
  • 关键结果：相对 SOTA 方法 ReSurgSAM2，在三个分割上分别取得 +3.77、+3.09、+0.94 的 J&F 提升
  • 额外分析表明方法有效提升了初始锚定帧的接地质量（AnchorAcc），验证了改进初始接地而非跟踪模块的设计思路的正确性
