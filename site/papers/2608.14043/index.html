Card 03 核心贡献

核心贡献

  • 首次对 MLLM-DiT 视频生成融合进行全面、公平的三维度系统研究：中间表示形式、MLLM 生成机制、DiT 融合策略。
  • 发现 EMA-based tokenizer 产生的离散语义视觉令牌是最稳定且富有表现力的中间接口，优于 embedding-based 更新、辅助监督及层级 token 等变体。
  • 发现 自回归因果注意力 比双向注意力、扩散目标等机制更适合生成语义视觉令牌。
  • 发现 显式视觉令牌条件 显著优于 prompt refinement 和 latent bridging，其中多层 cross-attention 注入效果最佳。
  • 提出 BiVidGen 完整框架：EMA tokenizer + MLLM 语义生成器 + DiT 渲染器，训练阶段分离、推理阶段串联。
Card 04 方法描述

方法描述

  • 中间表示：将 MLLM 视觉编码器提取的连续特征通过 EMA 更新的码本量化为离散语义视觉令牌；对比了梯度更新、MLLM 理解损失、像素重建损失及层级 EMA 等 5 种量化变体，EMA 方案最优。
  • MLLM 生成机制：采用因果注意力将文本与视觉令牌统一为自回归序列；加入分辨率–帧数前缀及 / 标记进行控制；使用 next-token prediction + teacher forcing 训练。
  • DiT 渲染器融合：将 MLLM 生成的视觉令牌投影到 DiT 隐藏维度，并在每个 DiT block 通过 cross-attention 注入；微调时冻结 DiT 主干，仅训练新增的 cross-attention 模块和投影层，以保留预训练扩散先验。
  • 推理流程：MLLM 自回归生成视觉令牌序列，DiT 在文本与视觉令牌双重条件下渲染视频，并使用 3D RoPE 保持时空位置编码。
Card 05 数据集与资源

数据集与资源

  • 基础模型：Qwen3-VL-2B 作为 MLLM，Wan-2.2-T2V-5B 作为 DiT 扩散主干。
  • 视频预训练数据：Sekai、FineVideo、Mira、OpenVid、InternVid、Panda、Koala 等来源，共 10M 视频。
  • 图像预训练数据：LAION，共 20M 图像。
  • 高质量子集：从中筛选出 2M 视频子集 用于 MLLM SFT、视频 DiT 训练及所有消融实验。
  • 训练配置：EMA tokenizer 在全量图文数据上训练；MLLM 分三阶段训练（图像预训练 → 视频预训练 → 2M 子集 SFT）；视频 DiT 在 2M 子集训练，图像 DiT 在 5M LAION 图像上训练。
Card 06 评估与结果

评估与结果

  • 评估基准：视频生成使用 VBench-Long，视频重建使用 DAVIS 数据集。
  • 基线设置：DiT-only（Wan2.2-FT 微调）、+ Prompt Refinement、+ Latent Bridging（含/不含 learnable token）、+ Visual Tokens。
  • VBench-Long 总体得分（Total Score）：DiT-only 74.88，Prompt Refinement 76.36，Latent Bridging 67.43/68.68，BiVidGen（Visual Tokens）取得最佳总分。
  • 语义分数（Semantic）：DiT-only 55.16，Prompt Refinement 60.74，Latent Bridging 32.58/35.23，BiVidGen 显著最高。
  • 消融结论：EMA 离散视觉令牌 + 因果注意力 MLLM + 显式视觉令牌多层 cross-attention 的组合最佳，显著提升视频的时序一致性、因果过渡和语义对齐。
