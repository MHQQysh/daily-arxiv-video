LongVU-TTT: Causal Test-Time Training for Visual Resampling in Long Video Understanding

2026-08-26 · 原文 · 翻译 · 2608.25729

论文提出 LongVU-TTT，一种用于长视频理解的新型视觉重采样方法，在视觉编码器和 LLM 之间插入卷积测试时训练（TTT）重采样器，通过因果快速权重更新实现视觉特征的时间上下文建模。 核心要解决的问题是：长视频 MLLM 在有限的视觉 token 预算下，传统方法在压缩帧特征前未显式建模时间变化，导致关键视觉证据丢失；现有递归模型（如 SSM）采用扁平序列操作，缺乏 2D 局部邻域交互。 论文通过受控实验对比多种时序算子（Temporal Transformer、Gated DeltaNet、Mamba2、TTT-MLP），验证了 TTT-Conv 在投影器阶段的优势，并揭示了快速权重更适合作为时间聚合器而非长期情节记忆。

Card 03 核心贡献

核心贡献

  • 提出 卷积 TTT 重采样器（TTT-Conv），采用分组的 2D 快速权重，在时间传播过程中保持视觉特征网格的空间结构，同时适应时序变化。
  • 设计 因果快速权重更新规则：每帧仅由先前帧的更新进行上下文化，通过并行因果物化（Parallel Causal Materialization）保持因果顺序并实现 GPU 并行计算。
  • 提出 显著性驱动的混合帧采样：利用 TTT 内循环的梯度方向偏移和对齐损失增量，无需辅助学习评分器即可保留场景转换和场景内视觉变化。
  • 提供 受控时序算子对比研究：在相同基线上系统比较 TTT-Conv、TTT-MLP、Mamba2、Gated DeltaNet 等，并给出保持诊断（retention diagnostics）表明快速权重提供时间聚合而非可靠情节存储。
  • 实现 长视频训练系统优化：通过批量分块 ViT 处理和异步 CPU 激活卸载，支持在 A100 40GB GPU 上训练多达 512 帧的视频。
Card 04 方法描述

方法描述

  • 整体架构：视频帧经预训练 ViT 编码后，输入 TTT-Conv 层（残差块 + RMSNorm），通过分组卷积快速权重递归处理帧序列，再经空间池化和帧选择压缩至 LLM 的视觉 token 预算。
  • 快速权重参数化：使用两组卷积核（$W_1 \in \mathbb{R}^{(N_g D_{int})\times d\times K\times K}$ 和 $W_2 \in \mathbb{R}^{C\times D_{int}\times K\times K}$），通过分组卷积实现通道分组和参数高效。
  • 内循环更新：每帧自监督对齐损失 $\mathcal{L}(k_t,v_t)=-\langle f_W(k_t), v_t\rangle$，利用 torch.vmap 和前缀和并行物化所有帧的权重状态。
  • 并行应用操作：查询 $q_t$ 通过对应权重状态 $(W_{1,t}, W_{2,t})$ 进行卷积变换，输出 $z_t=\sigma(\text{Conv2d}(q_t, W_{1,t}))$，再经 $W_{2,t}$ 卷积得到时间上下文化的 $\hat{x}_t$。
  • 帧选择：结合梯度方向偏移 $G_t$（场景级变化）和正对齐损失增量 $R_t$（事件级变化），归一化后加权融合为重要性分数，最终采用高亮集合+均匀集合的混合下采样。

Card 06 评估与结果

评估与结果

  • 受控条件下，TTT-Conv 在 MLVU 上优于 TTT-MLP 最高 +2.12，优于双向 Mamba2 最高 +3.04。
  • 在三个基准上，TTT-Conv 强于基于注意力和固定状态递归的重采样器。
  • 与无时间传播的均匀下采样基线相比，MLVU 提升 +6.4。
  • 保留诊断显示：快速权重的优势随证据距离增加而减弱，验证了显式帧保留（混合采样）的必要性。
  • 系统效率：在受限 A100 40GB GPU 上成功训练 512 帧长视频，推理时支持长序列压缩（512→128 帧），且在五个视频理解基准上取得有竞争力的性能。
  • 论文强调不做异构训练数据下的 SOTA 宣称，而是提供同基线、同规模下的受控对比研究。
