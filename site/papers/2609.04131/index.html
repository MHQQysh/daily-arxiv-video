Beyond Retrieval: Progressive Latent Memory Evolution for Streaming Video Understanding

2026-09-03 · 原文 · 翻译 · 2609.04131

论文提出 LatentStream，一种渐进式潜在工作记忆框架，用于流式视频理解任务，解决多模态大语言模型（MLLMs）在处理连续视频输入时面临的严格因果性和有界记忆约束问题。 现有方法遵循 store-and-retrieve（存储-检索）范式，将历史证据作为外部可变长视觉上下文使用，但缺乏能持续引导推理的紧凑、可演化的潜在记忆表示。该论文旨在将这一范式转变为 retrieve-and-internalize（检索-内化），使历史证据被逐步内化为固定长度的潜在记忆。 核心研究问题：外部流式记忆中的历史证据如何被自适应地内化为紧凑、查询条件化且持续演化的潜在记忆，以用于流式视频推理。

Card 03 核心贡献

核心贡献

  • 提出 LatentStream 框架，率先将流式记忆从 store-and-retrieve 范式推进到 retrieve-and-internalize 范式，实现任务相关历史证据向紧凑且演化的潜在记忆的渐进内化。
  • 提出 Hierarchical Latent Memory Evolution (HME)，将 Jenks 引导的分层流式记忆与三组具有递进扩展记忆感受野的潜在记忆令牌（LMTs）耦合，实现迭代的历史证据检索与内化。
  • 提出 Progressive Confidence-guided Latent Memory Optimization (PMO)，利用基于组间预测熵的分层进度奖励，在测试时优化潜在记忆令牌嵌入，鼓励推理置信度随可访问历史范围扩大而逐步提升。
  • 在五个视频理解基准上取得新的 SOTA 或极具竞争力的结果，验证了潜在工作记忆框架在有界记忆预算下对在线和离线视频理解的一致提升。
Card 04 方法描述

方法描述

  • Query-agnostic Hierarchical Streaming Memory (HSM)：在固定令牌预算下，通过 Jenks 自然断点法（Jenks Natural Breaks）进行数据驱动的自适应整合，将输入视觉令牌组织为短期、中期和长期三个记忆层级，实现在线构建且不依赖查询。
  • Hierarchical Latent Memory Evolution (HME)：将潜在记忆令牌分为三组，分别对应递进扩大的记忆感受野（短期、短期∪中期、短期∪中期∪长期），通过潜在引导的历史证据检索（基于最大余弦相似度 TopK 选择）实现查询条件化的迭代记忆检索-更新演化。
  • Progressive Confidence-guided Latent Memory Optimization (PMO)：基于分组预测熵构建分层置信度进度奖励，采用奖励门控机制决定是否接受新检索证据，在冻结的 Video-LLM 中联合优化检索视觉令牌嵌入和潜在记忆令牌嵌入，不修改模型参数。
  • 创新点在于利用模型潜在空间作为桥梁，实现外部记忆访问与潜在记忆演化之间的迭代交互，使记忆具备持续演化能力。

Card 06 评估与结果

评估与结果

  • 在 OVO-Bench 上达到 64.2%，在 StreamingBench 上达到 76.9%，均取得流式评估的最佳表现。
  • 在离线长视频理解中，VideoMME 达到 66.6%，MLVU 达到 74.0%，LongVideoBench 达到 62.1%。
  • 与现有 SOTA 方法对比，LatentStream 在在线和离线两种设定下均实现新 SOTA 或高度竞争性的性能，证明潜在工作记忆可替代外部检索上下文的可行性。
