  • 提出 VideoHarness-RSI，一种在冻结视觉语言模型（VLM）周围递归搜索可执行上下文构造器的方法，用于长视频理解

Card 03 核心贡献

核心贡献

  • 将视频 harness 递归自我改进（RSI）形式化为一个受控的自动化设计设置，优化可执行上下文构造，而 VLM 和回答接口保持不变
  • 提供了一个 propose–execute–evaluate–retain 基线，以及包含候选代码、谱系、执行轨迹、逐题输出和分数的可审计存档
  • 系统研究了递归选择的上下文构造器的有效性、内部机制、直接复用能力以及搜索-评估过程中的失败模式
  • 实验表明，搜索发现的 harness 在多个长视频基准上可无需进一步搜索直接迁移，且性能优于多个手工设计的基线
Card 04 方法描述

方法描述

  • 定义一个 harness 为可执行程序，将视频-问题对映射到有界多模态上下文，内部可分解为 Write（构建可寻址表示）、Read（问题条件检索）和 Pack（排序和格式化）三个阶段
  • 外循环 提议者（Claude Opus 4.6）基于历史 harness 代码、分数和轨迹生成新的候选 harness 突变，经端到端评估后，仅保留严格提升开发集准确率的变体
  • 保持内层 VLM（Qwen3-VL-8B-Instruct）和上下文接口（最终视觉上下文最多 40 帧）完全固定，搜索只改变可执行上下文构造代码
  • 搜索和评估严格分离，保留集不参与提议、选择或提前停止，仅用于最终评估
Card 05 数据集与资源

数据集与资源

  • LVBench：由于部分视频不可用，实际使用 83 个视频的 1,232 个 QA 对，随机打乱后取前 350 条作为开发集（用于搜索），剩余 882 条作为保留集（用于评估）
  • 跨基准评估：在 Video-MME 和 MLVU 的完整评估集上直接测试
  • 冻结模型：Qwen3-VL-8B-Instruct，推理时关闭思考模式，温度设为 0
  • 辅助工具：CLIP ViT-B/32 作为图像-文本评分器，Claude Opus 4.6 作为提议器
  • 主要搜索运行：从 Uniform-40 开始，每代评估 3 个候选，共 5 代，仅当严格提升时晋升
Card 06 评估与结果

评估与结果

  • 评估基准：LVBench 保留集，以及 Video-MME 和 MLVU（跨基准直接复用）
  • 主要指标：准确率（Accuracy），辅以平均输入帧数、输入 token 数、证据可见性等分析
  • 关键实验结果：

- 从 Uniform-40（36.3%）出发，搜索发现的 EmbedNavigate-Hybrid 虽未显式列出具体数值，但显示搜索可以持续改进

- 从较强的 AKS 基线（46.5%）出发，搜索产生的 Timestamped-AKS 在保留集达到 50.3%，为最佳结果

- 搜索发现的 harness 在 Video-MME 和 MLVU 上直接复用仍保持性能优势，表明搜索学到的是可迁移的上下文构造策略，而非过拟合开发集

- 定性分析表明，搜索发现的 harness 能够将检索与推理分离，并有效利用时间戳信息

- 与手工设计的文献启发式 harness 相比，搜索方法持续找到更优的上下文构造策略
