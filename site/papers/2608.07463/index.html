Card 03 核心贡献

核心贡献

  • 识别出视频镜像反射生成中的两个关键挑战：反射内容的选择（what）与反射内容的空间排列（how）。
  • 提出 MirrorWorld 框架，结合 Semantic Relation Distillation (SRD) 与 Geometric Transformation Alignment (GTA)，显式建模可见场景与镜像区域之间的关系。
  • 将视频镜像反射生成构建为反射感知的视频重建任务，并整合四个视频镜像数据集形成统一基准（共 1,242 个视频片段）。
  • 实验表明，MirrorWorld 在反射重建质量上优于代表性的基于图像的方法和强视频修补基线。
Card 04 方法描述

方法描述

  • Semantic Relation Distillation (SRD)：使用冻结的视觉基础模型（VideoMAEv2-Base）提取参考语义特征，通过余弦相似度计算场景与镜像区域之间的关系，并蒸馏到扩散模型的表征中，约束“反射什么”。
  • Geometric Transformation Alignment (GTA)：通过一个共享的仿射变换回归器，从局部时间窗口（K=5）聚合的可见场景特征中预测空间变换，对可见特征进行可微双线性扭曲，使其与镜像区域特征对齐，约束“如何排列”。
  • 基础模型为 Wan2.1-VACE-14B，使用 LoRA（rank=32）微调；总损失为扩散损失 + λ_SRD·L_SRD + λ_GTA·L_GTA。

数据集与资源

  • 数据集：VMD-D、ZOOM、MMD、DVMD-D 四个视频镜像分割/检测数据集，统一为镜像反射重建任务。
  • 数据划分：1,142 个训练片段，100 个测试片段（按源视频级分割，确保无重叠）。
  • 模型规模：基于 Wan2.1-VACE-14B（14B 参数），使用 LoRA 微调（rank=32）。
  • 训练资源：论文未明确说明 GPU 数量，但使用 LoRA 进行高效微调。
Card 06 评估与结果

评估与结果

  • 评估环境：构建的统一基准（100 个测试片段），输入为掩码视频、镜像掩码和文本提示。
  • 主要指标：PSNR、SSIM、LPIPS、FVD、Flow Warping Error (E_warp)。
  • 基准方法：图像级反射生成方法 MirrorFusion、MirrorVerse，视频修补方法 VideoPainter、VACE，以及先进 VDM（如 Veo 3.1）。
  • 关键结果：MirrorWorld 在定量指标上优于所有基线；消融实验证明 SRD 与 GTA 互补，两者结合显著提升反射内容一致性与空间排列准确性；GTA 的时间窗口大小与视觉基础模型选择均影响性能。
