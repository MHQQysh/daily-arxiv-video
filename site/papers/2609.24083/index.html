Card 03 核心贡献

核心贡献

  • 提出 PIVOT 框架，将故事板规划、验证式多模态视频生成与评估驱动的补救教学整合为统一管道，支持 STEM 学习。
  • 引入教学法引导的教学规划，在故事板中融入学习目标、先验知识激活、概念讲解、可视化方案、工作示例和诊断性评测探针，确保内容具备教学脚手架。
  • 设计教学验证装置，覆盖布局一致性、事实一致性和认知清晰性三个维度，通过迭代修复提升视频的视觉质量与教学可靠性。
  • 构建自适应评估与补救机制，依据学习者答题情况生成针对误区的对比式补救视频，实现学习者中心的互动反馈。
  • 通过自动评测、消融分析和 32 位 STEM 教师专家评估验证了框架的有效性。
Card 04 方法描述

方法描述

  • 第一阶段（教学法引导的教学规划）：由大语言模型根据给定主题生成结构化的教学故事板，包含学习目标、先验知识、逐步讲解、视觉表示、工作示例及诊断问题，作为后续 Manim 代码生成、旁白合成和评估构建的语义基础。
  • 第二阶段（带教学验证的视频生成）：将故事板拆分为镜头级单元，生成可执行的 Manim 动画代码；采用教学验证装置从布局一致性、事实一致性、认知清晰性三个维度检测问题，并通过低温度提示结合执行轨迹进行自动代码修复（主要使用 GPT-5.2，持续失败转交 Claude Sonnet 4.6）；随后使用 TTS 合成同步旁白，对补救视频还以学习者错误答案为条件进行生成。
  • 第三阶段（自适应评估与补救）：基于故事板生成不重复视频中例题的测验问题，针对错误回答生成对比正确与错误推理的补救视频，强化概念理解并纠正误区。
  • 创新点在于将教学法显式嵌入故事板生成、视频验证和评估补救的每个阶段，并采用基于代码的可执行视频生成路线以保证符号内容的准确性。
Card 05 数据集与资源

数据集与资源

  • 评估使用 40 个 STEM 教学主题，涵盖数学、物理、化学、计算机科学四个领域，每科 10 个知识点。
  • 基线系统：TheoremExplainAgent、Code2Video。
  • 生成与评估模型：GPT-5.2（主生成/修复）、Claude Sonnet 4.6（辅助调试）、Gemini-2.5-Flash（自动视频评估）、GPT-4o（旁白质量评估）。
  • 视频渲染基于 Manim 动画库；论文未明确说明具体 GPU/TPU 训练资源。
Card 06 评估与结果

评估与结果

  • 自动评估：使用 Gemini-2.5-Flash 对视频帧按 Layout（布局）和 Richness（丰富度）打分（1–10）；PIVOT 在 Layout 上达 9.10，Richness 上达 6.06，综合 7.58，均优于 TheoremExplainAgent（6.62）和 Code2video（6.20）。
  • 旁白质量：使用 GPT-4o 评估 Accuracy & Depth 和 Logical Flow（0–1）；PIVOT 分别达 0.87 和 0.91，综合 0.89，高于两个基线。
  • 消融分析：移除 Layout 验证使 Layout 分从 9.10 降至 7.87；移除事实验证使 Accuracy 从 0.87 降至 0.85；移除认知清晰性验证使 Logical 从 0.91 降至 0.89，表明三个验证组件各有贡献。
  • 专家评估：32 位 STEM 教师（物理 3、数学 12、化学 5、计算机科学 12）在五级 Likert 量表上评估；PIVOT 在所有维度上优于最强基线 TheoremExplainAgent，物理领域平均提升 +1.67 分，计算机科学提升 +0.76 分，尤其在识别和解决误区方面效果显著。
