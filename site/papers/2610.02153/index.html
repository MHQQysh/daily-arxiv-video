MosaiChunk: Compositing Spatio-Temporal Memory for Autoregressive Video Generation

2026-10-01 · 原文 · 翻译 · 2610.02153

论文提出 MosaiChunk，一种用于自回归视频生成的时空记忆机制，通过组合历史键值（KV）条目中的非连续片段，在固定活跃记忆预算下保留长程生成中的细粒度视觉细节。 针对长视频生成中滑窗推理导致的历史内容遗忘问题（如对象离开视线后重新出现时无法保持外观一致），MosaiChunk 在不改动冻结视频生成模型的前提下，训练轻量路由器自动检索并组合相关历史 KV 节。 同时引入 RememBench 基准，包含 prompt 驱动的文本生成视频（T2V）和相机驱动的图像生成视频（I2V）两种长程“回访”场景，用于评估生成模型在对象或场景重新出现时的一致性和记忆能力。

Card 03 核心贡献

核心贡献

  • 提出组成式视觉记忆机制 MosaiChunk：将历史 KV 划分为细粒度节（section），按固定预算选择并拼接来自不同空间和时间位置的 KV 条目，作为额外“远端记忆”输入冻结模型。
  • 验证冻结的自回归视频生成器可以直接消费非连续历史 KV，并据此恢复已丢失的视觉外观（如特定饼干形状）。
  • 设计 自蒸馏（self-distillation） 训练策略：教师使用完整历史 chunk，学生使用路由器组合的小规模 MosaiChunk，通过匹配去噪速度预测来学习节描述符，无需渲染或记录真实目标视频。
  • 构建 RememBench 基准，专门测试长程回访（revisit）一致性，分为 T2V（100 个场景）和 I2V（150 个场景，含旋转与平移轨迹）两个子集。
Card 04 方法描述

方法描述

  • 记忆路由器 采用三阶段架构：编码与存储、历史节评分、提取与组成。

- 将每个 chunk 的 KV 通过平衡 k-means 划分为等尺寸节，并用轻量描述符编码器将节的池化键映射为描述符。

- 给定当前生成 chunk 的查询节，路由器使用余弦相似度对滑动窗口之外的历史节打分，取全局 top-N 节。

- 对选中节按 softmax 权重缩放其值，拼接为 MosaiChunk，与滑窗上下文一同送入冻结的 DiT 模型。

  • 训练目标：学生（路由器 + MosaiChunk）与教师（完整历史 chunk）共享相同冻结骨干、噪声潜变量和滑动窗口，仅远端记忆不同；最小化学生与教师去噪速度预测的均方误差（MSE）。
  • 创新点在于保持生成器完全冻结，仅训练路由器，且通过自监督蒸馏使描述符具有“抗近因偏差”（anti-recency）特性，优先关注语义相关而非时间邻近。
Card 05 数据集与资源

数据集与资源

  • RememBench 基准：T2V 分裂含 100 个样本，采用四段提示（出现-消失-重新出现）设计；I2V 分裂含 150 个场景（50 个室内、100 个室外），初始帧来自 DL3DV 数据集，相机轨迹包含 90°/180°/360° 旋转及旋转+平移组合。
  • 骨干模型：T2V 使用 H3-AR（RAVEN 改编的 MiniMax-H3）；I2V 使用 LingBot-World-Infinity，两者均为冻结的预训练自回归视频生成模型。
  • 训练资源：论文正文未披露具体 GPU/TPU 数量、型号或训练时长；仅说明训练的是轻量描述符编码器和路由器，存储的 KV 与骨干参数保持不变。
Card 06 评估与结果

评估与结果

  • 基准对比：与滑动窗口基线（Base）和整块检索模型 Mixture of Contexts (MoC) 对比，预算以 chunk 等价单位（∥F_c∥=1 或 2）控制。
  • 评估指标：回访一致性使用 CLIP similarity（↑）和 LPIPS（↓）；滚动质量使用 TempSSIM（↑）和 Local Scene Drift（↓），报告中位数。
  • T2V 结果：在固定记忆预算为 2 个 chunk 时，MosaiChunk 实现 CLIP 0.936，显著优于 MoC 的 0.841 和 Base 的 0.751；LPIPS 降至 0.500，优于 MoC（0.569）和 Base（0.652）。
  • I2V 旋转 180° 结果：MosaiChunk 在预算为 2 时 CLIP 从 MoC 的 0.807 提升至 0.863，LPIPS 从 0.642 降至 0.609；旋转+平移场景下 CLIP 达 0.862，优于 MoC 的 0.830。
  • 消融与定性结果支持了节级记忆优于整块检索、以及自蒸馏抗近因偏差的有效性（详见论文附录）。
