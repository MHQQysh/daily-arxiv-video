Card 02 论文概述

论文概述

  • 论文聚焦时空视频定位（STVG）任务，要求模型同时预测查询事件发生的时间区间和该区间内目标实体的空间轨迹（bounding box tube）。
  • 现有多模态大语言模型（MLLM）通常将密集的定位轨迹进行自回归序列化生成，导致解码延迟随管（tube）长度线性增长，且早期定位误差会沿时间轨迹传播。
  • 论文提出Parallel Tube Decoding（PTD），将生成过程分解为“时间块 + 时间条件的并行空间块”，将顺序解码深度降至固定的 1+1 轮，与管长无关，从而实现高效且更准确的生成式 STVG。
Card 03 核心贡献

核心贡献

  • 新的解码公式：系统比较四种解码策略（Unquantized Token、Quantized Token、Sequential Block、Parallel Tube），提出 PTD，将解码深度从 Quantized Token 的 4+7T 和 Sequential Block 的 1+T 降为固定的 1+1。
  • 注意力机制：提出 Decoupled Block Attention，每个空间块可访问共享的视频-查询上下文，但禁止跨块依赖，从而支持所有空间块并行生成。
  • 定位感知优化：引入基于 GRPO 的定位感知策略优化，结合时间 IoU 奖励和空间 IoU/GIoU/L1 奖励，直接优化时间边界和框几何质量。
  • 显著效率提升与泛化能力：PTD 将 Tube Completion Latency 降低 79 倍，空间解码吞吐量提高 92 倍（以 Boxes Per Second 衡量），同时提升定位精度；仅用 4B 骨干模型即达 SOTA/竞争性表现，并零样本泛化到时间定位、证据型 VideoQA 和指代视频目标跟踪。
Card 04 方法描述

方法描述

  • 采用双形式训练：每个样本同时使用标准自回归下一词预测（NTP）和结构化多词预测（MTP）目标，联合优化 L_SFT = L_NTP + L_MTP，保留模型原生自回归能力的同时支持并行块预测。
  • PTD 两阶段生成：第一阶段预测时间块 ；第二阶段根据时间边界直接实例化各时间锚点 ，每个锚点初始化一个包含 的空间块，所有空间块在单轮中并行生成完整盒坐标。
  • Decoupled Block Attention 结合三种注意力：NTP 序列使用标准因果注意力；MTP 块内使用双向注意力；跨空间块禁用注意力但保留对共享前缀和时间块的访问，保证并行性和信息完整性。
  • 使用 Group Relative Policy Optimization（GRPO） 进行策略优化：时间奖励 R_temp = tIoU，空间奖励结合 GIoU 和 L1 距离，分别改善事件边界和框几何。

Card 06 评估与结果

评估与结果

  • 在 VidSTG 上，PTD 相比标准 Unquantized Token Decoding 实现 79× 更低的 Tube Completion Latency（TCL） 和 92× 更高的空间解码吞吐量（BPS），同时改进时空定位精度。
  • 在 VidSTG 和 HC-STVG 上，使用 4B 骨干取得最先进或具有竞争力的性能。
  • 模型可零样本泛化到时间定位（temporal grounding）、证据型视频问答（grounded VideoQA）和指代视频目标跟踪（referring video object tracking）。
  • 消融研究验证了解码范式、注意力机制和定位感知策略优化的有效性，并展示了 PTD 在不同管长下优于其他解码策略的可扩展性。
