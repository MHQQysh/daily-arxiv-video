Less Data, Better Timing: Student-Curriculum Coupling for VLM On-Policy Distillation in Temporal Video Grounding

2026-09-30 · 原文 · 翻译 · 2609.40055

论文研究视觉语言模型（VLM）在时间视频定位（TVG）任务中的在线策略蒸馏（On-Policy Distillation, OPD）后训练方法，旨在通过更少的数据和更短的训练时间提升定位精度。 论文指出现有 OPD 管线存在隐式的“监督价值持久性假设”：即课程选择基于固定教师和初始学生状态，假定被选样本在整个优化过程中始终保持正向监督价值，但这一假设并不成立。 论文提出 Student–Curriculum Coupling (SCC) 框架，将监督可信度（教师目标是否可靠）与监督必要性（当前学生是否仍存在任务缺陷）耦合起来，实现由学生能力动态驱动的自适应监督分配，从而解决监督价值随时间非平稳变化的问题。

Card 02 论文概述

论文概述

  • 论文研究视觉语言模型（VLM）在时间视频定位（TVG）任务中的在线策略蒸馏（On-Policy Distillation, OPD）后训练方法，旨在通过更少的数据和更短的训练时间提升定位精度。
  • 论文指出现有 OPD 管线存在隐式的“监督价值持久性假设”：即课程选择基于固定教师和初始学生状态，假定被选样本在整个优化过程中始终保持正向监督价值，但这一假设并不成立。
  • 论文提出 Student–Curriculum Coupling (SCC) 框架，将监督可信度（教师目标是否可靠）与监督必要性（当前学生是否仍存在任务缺陷）耦合起来，实现由学生能力动态驱动的自适应监督分配，从而解决监督价值随时间非平稳变化的问题。
Card 03 核心贡献

核心贡献

  • 识别并形式化 TVG OPD 中的持久价值假设，提出监督可信度与监督必要性的耦合视角，指出二者共同决定监督价值。
  • 提出 SCC 闭环框架，包含一个紧凑的 Anchor–Frontier (AF) 候选监督空间，结合初始学生已擅长的“锚定”样本与具有学习空间的“前沿”样本。
  • 设计学生依赖的监督实现机制：根据学生当前的任务能力，动态激活、暂停或重新激活监督，实现闭环 OPD 优化。
  • 在三个 TVG 基准上，相比 Video-OPD 在原始 TVDF 课程上，平均召回率相对提升 5.1%，同时训练样本减少 60.0%，训练时间缩短 50.4%，验证了数据与计算效率的显著提升。
Card 04 方法描述

方法描述

  • 使用反向 KL 散度进行 token 级对齐，学生从当前策略生成轨迹，冻结教师模型提供下一 token 分布监督，目标是在学生生成轨迹上最小化学生与教师的分布差异。
  • Anchor–Frontier (AF) 课程设计：候选空间包含两类样本——锚点样本（初始学生得分较高、具备可信教师监督）与前沿样本（初始学生得分低、学习空间大），仅保留教师监督可信（tIoU≥阈值）的样本。
  • 学生依赖实现：在训练中评估学生对候选样本的当前 tIoU，若低于能力阈值则视为“需要监督”，否则“暂停监督”；当学生能力下降时可重新激活锚点样本的监督，实现监督的动态调度。
  • 闭环优化：学生状态更新后反馈到下一批次的监督中，形成“候选空间→学生评估→选择性监督→学生更新”的闭环，并使用重要性权重采样 token 的代理目标以保证梯度一致性。
Card 05 数据集与资源

数据集与资源

  • 使用三个 TVG 基准数据集：Charades-TimeLens、ActivityNet-TimeLens、QVHighlights-TimeLens
  • 使用学生 VLM 与教师 VLM（固定）进行蒸馏，模型规模为 VLM 参数级别（具体参数量未在摘要中给出，原文为大模型）
  • 训练采用 OPD 后训练设置，未详细列出 GPU 数量，但强调显著的训练时间节省（缩短 50.4%）
Card 06 评估与结果

评估与结果

  • 评估指标：平均召回率（mean recall），分别在 IoU 阈值 0.3、0.5、0.7 下计算
  • 主结果：SCC 在三个基准上相较于 Video-OPD 的 TVDF 课程实现 5.1% 相对提升，使用 60.0% 更少样本，减少 50.4% 训练时间
  • 消融实验验证了 AF 课程设计与学生依赖监督机制各自发挥互补作用，训练动态分析进一步展示监督随学生能力演化的激活/暂停/重新激活过程
