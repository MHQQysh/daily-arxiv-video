R2M-Bench: Evaluating Revisit Memory via Relative Consistency in Interactive Video World Models

2026-08-27 · 原文 · 翻译 · 2608.27328

论文提出 R2M-Bench（Relative Revisit Memory Benchmark），用于评估交互式视频世界模型中的“重访记忆”能力，即模型在离开场景后再次回到原位置时，能否恢复一致的场景与状态。 核心问题：传统的绝对重访相似度（如首次访问帧与返回帧的相似度）会被渲染稳定性、重复内容、低运动量或失败的运动所污染，无法真正反映记忆能力。 为此，R2M-Bench 采用同一视频内的相对校准方式，通过将重访帧对与普通时间帧对进行对比，区分“重访特异的记忆”与“通用时间稳定性”。

Card 03 核心贡献

核心贡献

  • 构建了一个包含 100 个参考场景 × 3 条离开-返回轨迹 = 300 个基准实例 的评测基准，覆盖室内、城市、自然和抽象环境。
  • 提出 same-video 相对评估协议：引入 MemoryGain（MG） 衡量重访相对于时间基线的直接优势，以及 Normalized Memory Ratio（NMR） 对优势进行归一化，使其可跨指标比较。
  • 从 五个维度 评估重访一致性：外观保真度、场景身份保持、物体身份、局部几何对应、持久状态推理。
  • 提供多模型实证研究，包括人类验证、客观运动诊断、受控混淆因素分析以及轨迹级别评估。
  • 发布开源基准与代码（GitHub: https://github.com/AMAP-ML/R2MBench）。
Card 04 方法描述

方法描述

  • 数据构建：为每个参考图像生成模型无关的导航脚本，转换为各模型接受的离散动作或相机位姿指令，构建三种轨迹模板（out-and-back、translation-rotation、closed-loop）。
  • 帧对构造：从同一生成视频中挖掘三类帧对——重访对（commanded return）、间隔匹配基线对（gap-matched baseline）、短距离参考对（short-range pair），用于相对校准。
  • 指标计算：MG = 重访对相似度 − 基线对相似度；NMR = MG /（短距离参考 − 基线动态范围），得到无量纲分数，跨指标可聚合。
  • 五维评估指标分别使用不同技术实现：低层感知相似度、场景级语义匹配、物体检测与语义一致性、特征匹配与几何验证、视觉语言模型评估持久状态。
  • 创新点：所有参照对均来自同一个 rollout，因此慢速或几乎静态的生成同时提高基线和重访分数，无法获得选择性优势，有效缓解了“慢动作捷径”问题。
Card 05 数据集与资源

数据集与资源

  • 基准数据：100 个参考场景，每个场景配 3 条轨迹，共 300 个实例。
  • 参考场景分布：24 室内、44 城市、28 自然、4 抽象；87 个场景为对象丰富，76 个为户外。
  • 评估模型：七个动作条件视频世界模型（包括 DreamX-World-Memo、HY-WorldPlay、Matrix-Game 3.0 等），并附带一个 3D 渲染参考。
  • 训练/推理资源：论文未在摘要与主要章节中明确给出具体 GPU/TPU 配置，但基准涉及长视频生成与多模型推理，实际使用大规模算力。
Card 06 评估与结果

评估与结果

  • 评估环境：对 210 个采样 rollout 进行人类一致性判断，并使用独立光流运动诊断、受控运动与质量混淆实验、轨迹级别分析。
  • 主要指标：Overall NMR 与人类一致性判断的 Spearman 相关系数 ρ = 0.547（95% 置信区间 [0.45, 0.63]）。
  • 关键结果：

- NMR 与生成运动的相关性仅为 0.072，而原始重访相似度与运动的相关性为 0.207，说明相对校准显著降低了慢运动捷径。

- DreamX-World-Memo 在七个视频模型中取得最高 Overall NMR，其次是 HY-WorldPlay 和 Matrix-Game 3.0。

- 轨迹级别分析显示，即使最强系统在较长闭环返回任务上也会退化。

- 检索式系统整体表现最佳，但架构、规模、训练和推理差异不能得出因果结论。
