Card 02 论文概述

论文概述

  • 论文提出 Video-HolmesV2，一个专为 Deep Audio-Visual Coupling（深度音视频耦合）设计的长视频推理基准，旨在检验多模态大语言模型（MLLMs）能否利用时空音视频证据进行真正的跨模态推理。
  • 现有基准过度依赖视觉启发式线索而边缘化音频信息，将模型降级为"无声观察者"（silent observers），且标准密集采样导致"证据-上下文权衡"（evidence–context trade-off）：增加帧数以捕获证据必然引发注意力分散与 token 爆炸。
  • 论文引入 Evidence-Based Evaluation（基于证据的评估）范式，要求模型以精确的时空音视频证据来证实答案，有效抑制猜测与幻觉证据的干扰。
Card 03 核心贡献

核心贡献

  • 构建 Video-HolmesV2 基准，包含 784 个长视频（时长 600–7500 秒，平均约 43 分钟）和 4000 个 QA 对，相比现有基准首次同时具备音视频相关性（A-V Corr.）、时空证据（S-T Evid.）和证据链（Evid. Chain）标注。
  • 提出 Multi-Model Cross-Verification 流水线，通过多模型交叉验证与 "Unimodal Trap" 盲过滤机制，剔除仅凭单模态即可解答的题目，确保每个样本严格依赖多模态相互关联。
  • 提出 Spatio-Temporal Evidence-Aware Metric（时空证据感知评估指标），采用高斯软评分取代刚性阈值，将推理正确性严格条件化于有效证据提取，有效区分真实多模态推理与猜测。
  • 提出 Audio-Text Guided Token Compression（音频-文本引导的 token 压缩）框架，融合文本引导的主观意图与音频引导的客观事件，对视觉 token 进行细粒度去重并动态重分配预算，兼顾微观证据与全局上下文。
Card 04 方法描述

方法描述

  • 基准构建采用三层定量筛选管线：（1）Z-Score 归一化消除不同 VLM 的评分偏置；（2）优先级加权聚合与模态否决机制，对 Audio-Visual Complementarity 维度设置否决阈值；(3) 不确定性驱动的数据分层，基于 Divergence Score 将高争议样本路由至专家人工裁决。
  • 多维度可分析性评估涵盖五个核心维度：音视频互补性、跨模态因果复杂度、动态角色弧、叙事连贯性、观众口碑接受度。
  • Token 压缩方法以音频锚点（audio anchors）融合任务意图，对高价值推理线索进行蒸馏，通过差异化去重策略取代朴素 top-K 截断，缓解长上下文噪声干扰。
Card 05 数据集与资源

数据集与资源

  • 数据集初始收集 3704 个 2024 年后的高保真电影级视频（时长 10–150 分钟），排除新闻报道、体育赛事等单模态主导或因果稀疏的题材。
  • 最终基准包含 784 个长视频（平均时长 43 分钟）与 4000 个 QA 对，覆盖多类型生成（causal、counterfactual、thematic 等推理任务，各约 25% 均衡分布）。
  • 评估涉及的模型包括 GPT-4o、Gemini 2.5 Pro、Qwen2.5-Omni、VITA、Video-SALMONN、InteractiveOmni 等专有与开源全模态模型。
  • 数据构建与评测模型包括 Gemini 3 Pro、GPT-5.2、Qwen3-VL-235B-A22B-thinking 等最先进原生多模态模型。
Card 06 评估与结果

评估与结果

  • 评估基准为 Video-HolmesV2，并同时在 Video-MME、LongVideoBench、EgoSchema、LVBench 等既有长视频理解基准上进行验证。
  • 核心指标为引入的 Spatio-Temporal Evidence-Aware Metric，将答案正确性与有效时空证据提取严格绑定，对无依据推测进行惩罚。
  • 关键结果表明：即使是强专有模型在 Video-HolmesV2 上准确率也 低于 60%，说明现有 MLLM 在深度音视频耦合推理上仍有显著不足。
  • 所提出的 Audio-Text Guided Token Compression 方法在 Video-HolmesV2 上超越了可比较的开源全模态模型，并在多个既有视频理解基准上达到最优性能。
