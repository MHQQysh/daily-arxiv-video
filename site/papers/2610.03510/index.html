Card 02 论文概述

论文概述

  • 论文提出 Weave Forcing，一个训练免费（training-free） 的框架，用于交互式长视频生成中的组合式记忆复用（compositional memory reuse）。
  • 解决的问题：当新镜头需要组合来自不同历史镜头中的角色和背景时，现有方法要么引入过多无关内容，要么因全局提示检索而遗漏必要参考，难以实现精细的跨镜头一致性。
  • 核心思路：通过语义槽路由、掩码记忆编织和自适应位置编码，实现“恰到好处”的历史内容选择性复用。
Card 03 核心贡献

核心贡献

  • 提出 Semantic Slot Routing（语义槽路由）：利用 LLM 将用户提示分解为角色和背景槽，并独立匹配到历史来源，支持跨镜头组合参考。
  • 提出 Masked Memory Weaving（掩码记忆编织）：通过对比槽注意力（CSA） 构建语义 KV 掩码，选择性保留历史记忆中的相关 token，抑制无关内容。
  • 提出 Coverage Adaptive RoPE（覆盖自适应旋位编码）：根据参考覆盖程度（无、部分、完整）动态调整时间偏移和记忆保留，平衡历史引导与新内容生成。
  • 在 Self Forcing 骨干上验证了方法有效性，提升跨镜头主体和背景一致性，同时保持视觉质量和文本对齐。
Card 04 方法描述

方法描述

  • 槽提示拆分：LLM 将当前镜头指令拆分为多个角色描述和背景描述，作为语义查询。
  • 跨镜头路由：LLM 将每个槽匹配到前序镜头中的合适来源，并确定目标槽提示；无合适来源时置为 ∅。
  • 记忆压缩：基于查询加权（query weighting）将每个已完成镜头的 KV 状态压缩为紧凑记忆，按镜头索引存储。
  • 对比槽注意力（CSA）：对同一历史记忆分别计算目标提示和其他提示的交叉注意力图，做差并阈值化，再经形态学开闭运算得到语义 KV 掩码。
  • 缓存初始化：将压缩记忆和掩码嵌入 sink/compressed/recent/current 四窗口缓存布局，在自注意力中按槽掩码门控历史引用。
  • Coverage Adaptive RoPE：依据参考完整度调整历史 token 的时间位置偏移，并配合渐进式记忆衰减，平滑过渡到当前镜头上下文。

Card 06 评估与结果

评估与结果

  • 评估基准：以 Self Forcing 作为骨干，进行定量、定性和消融实验。
  • 主要指标：跨镜头主体一致性、背景一致性、视频质量、文本对齐。
  • 关键结果：Weave Forcing 在这些指标上优于 Self Forcing 骨干，显著提升跨镜头一致性和背景一致性，同时保持有竞争力的视觉质量与文本对齐。
