Card 02 论文概述

论文概述

  • 针对稀疏视角下3D高斯泼溅（3DGS）重建易出现浮子、结构模糊、多视角不一致的问题，现有2D/视频扩散先验缺乏3D感知，导致跨视角几何不一致
  • 提出GaussVid框架，将稀疏3DGS重建恢复定义为帧条件重建问题，利用3D感知的视频扩散先验校正伪影，同时保证多视角几何一致性
  • 核心目标是实现高保真、多视角一致的稀疏视角新视角合成，且框架可无缝集成到现有稀疏3DGS方法中
Card 03 核心贡献

核心贡献

  • 首次将稀疏3DGS恢复形式化为首尾帧锚定的帧条件重建问题，并构建大规模配对训练数据集，覆盖不同难度的稀疏视角伪影样本
  • 扩展首尾帧条件的视频扩散模型，提出Plücker射线编码的双流相机注入模块，将已知的相机姿态作为无噪几何先验注入视频生成流程，解决跨视角不一致问题
  • 设计渐进潜空间重建损失与难度感知课程学习策略，稳定视频扩散模型的微调过程，提升恢复性能
  • 实验证明该方法在像素级、结构级保真度上优于现有方法，且恢复的帧可反馈优化底层3DGS重建质量
Card 04 方法描述

方法描述

  • 基础架构：基于开源视频扩散模型Wan2.1-VACE-14B，继承其首尾帧条件生成能力，仅对VACE模块和DiT块的{q,k,v,o,ffn}层进行LoRA微调，VAE编码器解码器保持冻结，Plücker Token Encoder从零开始全参数训练
  • 数据集构建：从DL3DV数据集中选取约5000个场景，通过提前终止3DGS优化（8000轮次）模拟不同稀疏度（间隔n∈{6,8,...,26}）下的伪影，采用首尾干净帧锚定、均匀采样3帧中间 corrupted 帧的策略，构建5帧配对训练片段
  • 3D感知视频恢复模型创新：

1. Plücker Token Encoder：将相机姿态编码为Plücker射线特征，分解为捕捉平移信息的矩流和捕捉旋转/内参信息的方向流，通过轻量级MLP实现交叉门控融合，生成几何感知的相机token

2. 双流相机注入模块：采用噪声不变调制，相机token的时间步调制固定为0（不受扩散噪声影响），通过非对称联合注意力机制，仅允许视频token attend到相机token，避免噪声视频特征污染几何先验

  • 训练策略创新：

1. 渐进潜空间重建损失：额外加入L1损失约束一步重建的潜空间与干净潜空间的差异，随训练步数渐进提升权重

2. 难度感知课程学习：根据稀疏间隔（难度）动态过滤高难度样本、对剩余样本做软权重调整，先让模型学习简单样本的基础重建能力，再逐步接触高难度样本，稳定优化过程

  • 整体训练基于流匹配框架，仅在t∈[0.0, 0.48]的低噪声区间进行训练，匹配3DGS伪影的结构严重程度
Card 05 数据集与资源

数据集与资源

  • 训练数据集：自建GaussVid数据集，从DL3DV的约5000个场景构建，共5000个训练片段（每场景1个5帧片段，分辨率560×1024），500个评估片段；跨数据集评估使用Zip-NeRF的4个大场景，按n∈{6,9,12}三个稀疏度各构建150个片段，分辨率576×1024
  • 模型规模：基于Wan2.1-VACE-14B，对VACE模块应用秩为32的标准LoRA适配器，对DiT块的相关层注入定制LoRA，Plücker Token Encoder从零开始全参数训练
  • 训练资源：8块NVIDIA A800-SXM4-80GB GPU，使用AdamW优化器，学习率1×10⁻⁴
Card 06 评估与结果

评估与结果

  • 评估基准与基线：

1. 同分布评估：DL3DV基准，对比三类基线：优化类稀疏3DGS方法（FSGS、CoR-GS）、2D扩散先验方法（DiFix3D）、视频扩散先验方法（4DSloMo、GSFIXER）

2. 跨分布评估：Zip-NeRF室内场景，验证不同采集轨迹和稀疏度下的泛化能力

  • 评估指标：PSNR（像素级 fidelity，越高越好）、SSIM（结构级 fidelity，越高越好）、LPIPS（感知质量，越低越好）
  • 关键实验结果：

1. 在DL3DV基准上，作为后处理方法集成到不同3DGS基线时，GaussVid在所有视频先验方法中取得最优的PSNR和SSIM，LPIPS保持有竞争力；相比次优的GSFIXER，PSNR最高提升0.45dB，SSIM最高提升0.0135

2. 跨Zip-NeRF场景的泛化实验中，方法在所有稀疏度下均取得最优PSNR，验证了在不同采集 setups 下的鲁棒性

3. 消融实验验证了双锚点设计、均匀中间帧采样、混合难度训练范围、相机注入模块、渐进训练策略的有效性，各组件均带来明确的性能提升

4. 方法可作为通用后处理框架无缝集成到现有稀疏3DGS方法，恢复的干净帧还可反馈重新优化3DGS，进一步提升重建质量
