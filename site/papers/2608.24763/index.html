Card 02 论文概述

论文概述

  • 论文提出 MoTE（Mixture of Task Experts），一种将 LLM 解码器中的共享 FFN 转换为任务特定专家的架构，同时保持多模态视频-语言骨干网络共享
  • 核心解决多任务程序性视频理解中密集解码器共享 FFN 导致任务行为相互纠缠、难以受控扩展的问题；现有稀疏 MoE 的 token 级路由又与任务级目标不对齐
  • 作者将该架构实例化为 VideoLLM-MoTE，在五个 COIN 基准任务上验证其有效性，并进一步将相同原则迁移至文档理解领域（GLM-OCR-MoTE）
Card 03 核心贡献

核心贡献

  • 提出 MoTE 模块化解码器转换方案，将共享 LLM FFN 替换为任务路由的 FFN 专家，同时保留共享注意力和骨干组件
  • 实例化 VideoLLM-MoTE 用于多任务程序性视频理解，五个任务专家模型仅激活约 2B LLM 参数，平均 top-1 准确率超过近期 VideoLLM 基线
  • 验证任务级路由优于同等专家拓扑下的密集全专家激活和学习的稀疏路由控制
  • 跨领域验证：将 GLM-OCR 转换为 GLM-OCR-MoTE，成功分离 OCR 与收据关键信息提取（KIE）任务路由
  • 通过专家添加与移除实验，展示 MoTE 任务专家可作为模块化单元进行能力扩展或撤销，同时保留已学知识
Card 04 方法描述

方法描述

  • 共享骨干：采用视觉编码器（SigLIP 2 ViT-L/16-384）+ 两层 MLP 投影器 + LLM 解码器（Llama-3.2-1B-Instruct），每帧生成 10 个视觉 token（1 个 CLS + 3×3 池化网格）
  • MoTE 解码器块：每个解码器层将原始 FFN 替换为 M 个任务专家和一个始终激活的共享专家；给定任务路由 r，输出为 H_{l+1} = H̃_l + λ_sh·F_sh(LN(H̃_l)) + λ_task·F_r(LN(H̃_l))
  • 专家初始化：路由专家和共享专家均复制预训练稠密 FFN 的权重，遵循 sparse upcycling 的稠密到稀疏初始化原则
  • 任务路由选择：训练时使用任务标签直接提供路由监督；推理时通过冻结文本编码器（MiniLM-L6-v2）将用户 prompt 与专家描述进行余弦相似度匹配，选择 top-1 专家
  • 训练目标：基于 VideoLLM-online 的语言建模损失 + 流式静默（Stream）损失，仅在 COIN 离线任务上退化为标准路由语言建模损失
  • 模块化适应：添加专家时冻结共享专家和旧任务专家，仅训练新专家；移除专家时直接删除对应路由和描述，实现能力撤销
Card 05 数据集与资源

数据集与资源

  • 视频理解：COIN 数据集（五个任务：Step 识别、Next 预测、Task 识别、Proc. 程序预测、Proc.+ 任务条件程序预测）、Ego4D narration stream 用于跨数据集扩展
  • 文档理解：SROIE 与 CORD 数据集用于收据 KIE 与 OCR 任务分离评估
  • 模型规模：VideoLLM-MoTE-1B+5E 总参数 5.3B，每样本激活参数 2.0B；扩展版本 VideoLLM-MoTE-1B+6E；文档模型 GLM-OCR-MoTE-0.9B+2E
  • 训练资源：4× A100-80GB GPU，视频采样率 2 FPS，帧数上限 1200
Card 06 评估与结果

评估与结果

  • COIN 五任务评估：VideoLLM-MoTE-1B+5E 在 Step、Next、Proc.、Task、Proc.+ 上分别取得 65.1%、50.3%、50.5%、94.4%、54.2% 的 top-1 准确率，五任务平均 62.9%，超过最强的 8B VideoLLM 基线（61.8%）及同源 1B/3B VideoLLM-online 基线
  • 效率对比：激活 2B LLM 参数，单请求计算量 28.9 TFLOPs，延迟 1.8s，解码吞吐 37.7 tokens/s，优于 8B 基线（98.7 TFLOPs、2.8s、27.8 tokens/s）
  • 专家添加/移除实验：阶段式添加专家最终平均准确率 61.0%（低于联合训练的 62.9%），但旧任务准确率完全保持；移除专家后其余任务参数与准确率不受影响
  • 跨数据集扩展：在 Ego4D 基础上添加 5 个 COIN 专家，单个模型同时支持在线叙述与 COIN 任务，并取得表格中最高的 Fluency 值
  • Prompt-conditioned 路由：MiniLM-L6-v2 选择器在五个任务意图上达到 100% 测试 F1，选择耗时 4.35ms，保证端到端分数与显式路由一致
