Card 03 核心贡献

核心贡献

  • 统一实时视频生成公式：将生成定义为持久分块潜在流过程，视觉状态跨分块传递，时间索引的指令可在无重启 rollout 的情况下更新，同一因果接口支持文本到视频、图像到视频、视频 continuation 三种生成模式
  • 事件对齐的数据与渐进式流式训练：构建多级数据 curation 管线，涵盖安全过滤、质量过滤、分布重平衡、人类偏好策划、单事件与事件对齐时间 caption，通过双向预训练、流式适配、单/多事件中训练、人类偏好微调的渐进路径提升模型能力
  • 有界多尺度记忆：近期历史保留原生潜在分辨率，旧历史渐进压缩，远期信息 consolidates 到固定容量的 learned 状态，保证小时级 rollout 无明显质量或颜色漂移，且内存和计算开销与 rollout 长度无关
  • 少步流后训练与物理感知对齐：通过分类器 free 指导蒸馏、一致性蒸馏、自强制 DMD 实现 Few-Step 推理，再通过 GRPO 强化学习优化视觉质量、运动质量、文本-视频对齐奖励；同时引入潜在世界模型保证生成的物理合理性
  • 实时控制与推理对齐：通过滚动 prompt 摘要、异步编码、分块边界条件更新等机制，实现 prompt 更新秒级生效，配合内容自适应漂移稳定机制保证长 rollout 的稳定性
  • 流式高分辨率系统协同设计：通过版本化状态复用、编译融合执行、渐进解码与超分辨率的分块 pipeline，实现 4K 24 FPS 的实时渐进视频交付
Card 04 方法描述

方法描述

  • 基于条件潜在视频模型，核心为蒸馏后的分块流式生成器和流式视频超分辨率模型，采用渐进式训练路径：先进行1-5秒视频的双向预训练，再适配为3-10秒视频的分块流式生成模型，随后通过单/多事件中训练、长时长可靠性训练、人类偏好微调提升质量，最后经 Few-Step 蒸馏和 GRPO 强化学习降低推理成本、对齐生成策略，配套专用超分辨率模型输出高分辨率视频
  • 创新点和关键技术：

- 统一实时视频生成公式：将生成定义为持久分块潜在流过程，视觉状态跨分块传递，支持时间索引的指令无重启更新，同一因果接口支持文本到视频、图像到视频、视频 continuation 三种生成模式

- 有界多尺度记忆：近期分块保留原生潜在分辨率，旧分块渐进压缩，通过固定 token 预算和固定容量 learned 状态存储远期信息，保证长时长生成的一致性，且内存和单分块计算开销与 rollout 长度无关

- 少步流后训练与物理感知对齐：先通过分类器 free 指导蒸馏、一致性蒸馏、自强制 DMD 将推理步数降至 Few-Step，再通过 GRPO 强化学习优化视觉质量、运动质量、文本-视频对齐奖励；同时引入潜在世界模型评估候选未来的物理一致性，保证生成内容的物理合理性

- 流式高分辨率协同设计：通过版本化状态复用、编译融合执行、单序列并行、生成-解码-修复-编码-交付重叠的 pipeline，配合专用时间蒸馏超分辨率模型，实现 4K 24 FPS 的实时渐进视频输出

- 推理时实时控制：通过滚动 prompt 摘要、异步 prompt 编码、分块边界条件更新、版本化状态失效、内容自适应漂移稳定机制，保证 prompt 更新平均1秒内生效，且长 rollout 过程中无明显漂移
