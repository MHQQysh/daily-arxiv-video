Card 02 论文概述

论文概述

  • 提出一种严格因果的流式视频异常检测（VAD）方法，其时间核心为带输入/状态依赖衰减门的对角线性状态空间循环，每个输入帧仅需 O(1) 时间和内存更新，无回看（lookahead）、无片段缓冲（clip buffering）

Card 03 核心贡献

核心贡献

  • 提出严格因果流式 VAD 架构，训练与部署共用完全相同的逐帧更新例程，确保报告效率非训练技巧的产物
  • 推导衰减谱与检测延迟、最短可检测异常时长的闭式关系（settling-time bound / 最小可检测事件时长），并实证验证
  • 在消费级边缘芯片 Apple M3 Pro 上实测延迟、内存与吞吐，而非用 GPU 指标模拟
  • 公开代码、训练 checkpoint 和复现全部数据的命令（https://github.com/yogesh-iitj/streaming-vad）
  • 完整公开消融结果，包括与自身设计假设相矛盾的发现（gate 在较小数据集上反而有害）
Card 04 方法描述

方法描述

  • 使用冻结的 ImageNet 预训练 ResNet-18 骨干（D=512）提取逐帧嵌入，另支持更强的 DINOv2 ViT-S/14（D=384）替身
  • 时间核心为多层因果对角线性状态空间循环：状态更新 s_t = a_t ⊙ s_{t-1} + u_t，其中有效衰减 a_t = ā ⊙ g_t
  • 引入事件边界门（event-boundary gate） g_t = σ(MLP([LN(x_t), s_{t-1}]))，可在异常发生时隐式重置状态（快速遗忘），是 Mamba 意义上的"选择性"机制
  • 自监督训练：最小化因果下一嵌入预测损失 L = Σ\|\|ê_{t+1} - e_{t+1}\|\|²；异常分数为预测误差 s_t = \|\|ê_t - e_t\|\|₂
  • 为避免 CUDA-only 的 Mamba 选择扫描核，采用实值对角线性递归，使模型可在非 CUDA 边缘硬件上运行
  • 理论部分假设单通道恒定有效衰减，给出检测延迟 δ(ε) = ⌈ln ε / ln a⌉
Card 05 数据集与资源

数据集与资源

  • 数据集：UCSD Ped2 和 CUHK Avenue（正常片段训练，逐帧 AUC 评估）
  • 骨干：冻结 ResNet-18（D=512）；备选 DINOv2 ViT-S/14（D=384）
  • 训练硬件：消费级硬件即可迭代；边缘实测平台为 Apple M3 Pro
  • 状态大小 N 为可调超参数，论文对 state size 做了消融实验
Card 06 评估与结果

评估与结果

  • 精度指标：frame-level AUC —— Ped2 为 67.9%、Avenue 为 70.2%，落后于先前非因果 SSM 基线（如 VADMamba）
  • 理论验证：由学习到的基衰减预言的 settle 延迟界为 57–59 帧，而实测检测延迟仅为 Ped2 1.6 帧、Avenue 18.4 帧，证明事件边界门（gate）而非基衰减主导反应速度
  • 边缘效率：Apple M3 Pro 上每帧 0.74 ms（Ped2）与 0.77 ms（Avenue），折合 1,300+ FPS
  • 消融结论：decay rate、state size、gate 三者的消融显示 gate 的贡献具有数据规模依赖性——在小训练集 Ped2 上损害精度，在大训练集 Avenue 上有帮助
  • 论文如实报告精度差距与下一步计划（缩小精度差距、扩展第三个更大基准），并给出完整理论与精度图景
