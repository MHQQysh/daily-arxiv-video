Qwen3.8-Omni: Towards Native Omni-Modal Agents

Card 03 核心贡献

核心贡献

  • 原生多模态共训练策略：通过多模态协同训练保留强文本能力，同时将 agentic 能力从文本任务迁移到音频和视频任务。
  • 模型架构升级：基于 Qwen3.8-Next 的混合稀疏 MoE 架构，引入空间音频编码器（Spatial AuT）以捕获空间音频线索，并将上下文窗口扩展至100 万 token。
  • 信息抽象模块：开发了 Omni-Caption、Omni-Video2Note、Omni-Memory 和 Omni-Skill-Creator 等模块，减少长视频处理中的密集 token 消耗。
  • 开源框架：发布 Qwen-MM-Plugins（轻量级多模态应用插件框架）和 Qwen-Live-Harness（实时多模态 agent 构建框架），解决现有 harness 缺乏原生音视频支持的问题。
  • 自动化研究验证：展示 Omni-Autoresearch 能力，模型自主完成了对较小模型四川话识别能力的改进实验。
Card 04 方法描述

方法描述

  • 架构设计：采用 Thinker-Talker 统一多模态架构，Thinker 使用混合稀疏 MoE 语言模型处理多模态输入并生成文本推理、对话和工具调用，Talker 负责实时语音输出。
  • 多模态编码器：使用视觉编码器处理图像和视频帧，AuT 编码器处理一般音频（6.25 Hz 输出），Spatial AuT 编码器处理多声道空间音频（基于一阶 ambisonics 格式和复数 STFT）。
  • 训练流程：预训练分为四个阶段（S1-S4），包括编码器对齐、通用多模态训练（约 2.5 万亿 token）、QSA 索引器预热的稀疏注意力适配。
  • 后训练流水线：采用多教师蒸馏（multi-teacher distillation）+ 强化学习两阶段策略，整合领域专家模型的异构能力并优化交互质量。
  • 稀疏注意力机制：采用 Qwen Sparse Attention (QSA)，通过轻量索引器选择相关上下文块，结合 Gated DeltaNet 的循环状态处理，实现长序列的高效推理。
Card 05 数据集与资源

数据集与资源

  • 预训练数据涵盖文本、图像、视频、音频、视频-音频等多模态数据，总量约 2.5 万亿 token（文本 1.1T、音频 0.7T、图像 0.35T、视频 0.15T、视频-音频 0.3T）。
  • 支持 201 种文本语言、113 种语音输入语言/方言（含 74 种语言和 39 种中文方言）、36 种语音输出语言/方言。
  • 模型预训练使用原生 262,144 token 上下文窗口，后训练扩展至 1M token。
  • 音频编码器 AuT 在超过 20 种语言的音频语料上进行预训练，使用专门的 Qwen ASR 模型生成的转录作为监督信号。
Card 06 评估与结果

评估与结果

  • 文本能力评估：在 DeepSWE 1.1（57.8）、SWE-bench Pro（63.3，最优）、SWE-bench Multilingual（80.5）、NL2Repo-Bench（48.9）等基准上，性能与 Qwen3.8-Flash 等文本模型相当。
  • 多模态性能提升：与上一代 Qwen3.5-Omni-Plus 相比，在 29 项评估中平均分提升超过 25%，涵盖音频推理、视听推理和视听 agent 任务。
  • 成本效率：每小时的音频和视听内容的 API 输入成本分别降低超过 98% 和 93%。
  • Agentic 能力验证：在 Omni-Autoresearch 实验中，模型在 12 小时内自主改进 Qwen2.5-Omni-3B 的四川话识别能力，字符错误率从 25.79% 降至 15.30%（相对降低约 40.7%）。
  • 比较基线：音频与视听任务对比了 Qwen3.5-Omni-Plus、Gemini 3.8 Flash、Seed 2.0 Lite 和 Muse Spark 1.2 等模型。
