Card 03 核心贡献

核心贡献

  • 将 VVT 重新表述为语义条件视频生成，提出UniVVT，一个在推理时无需外部掩码、姿态估计或服装变形的统一端到端框架。
  • 引入隐式引导机制，包括基于 MLLM 的 Scene-Task Perceiver 和轻量级 Semantic Bridge，将原始多模态输入转化为任务感知条件，以实现连贯的试穿生成。
  • 提出三阶段渐进训练策略，稳定异质预训练组件之间的适配，并在多个常用基准上验证框架的有效性和泛化性。
  • 在多个基准上实现最先进性能，证明隐式语义引导可替代脆弱的几何预处理，并简化部署。
Card 04 方法描述

方法描述

  • Scene-Task Perceiver：基于预训练 Qwen3-VL-2B-Instruct，将源视频关键帧、目标服装图像和文本指令统一 token 化，并加入 N=512 个可学习任务查询，通过自注意力提取紧凑的任务感知潜在表示 \(\mathbf{z}_{\text{task}}\)。
  • Semantic Bridge：使用轻量级多层感知机（MLP）将任务潜在表示投影到生成器的条件空间，解决维度和分布不匹配问题。
  • Video Generation Module：基于 Wan2.1-Fun-Control 的扩散 Transformer（DiT）视频生成器；通过因果视频 VAE 编码源视频和服装，源视频潜变量与噪声潜变量沿通道拼接，服装潜变量沿序列维度追加。
  • 条件注入：每个 DiT 块通过交叉注意力注入任务条件 \(\mathbf{c}_{\text{proj}}\) 和冻结 CLIP 图像编码器提取的服装特征 \(\mathbf{f}_{\text{clip}}\)，实现语义精确编辑与服装保真传输。
  • 训练目标：采用条件流匹配（Conditional Flow Matching）的均方误差损失进行潜在空间优化。
  • 三阶段渐进训练：Stage 1 冻结生成器，训练语义桥并以 LoRA 适配 MLLM；Stage 2 联合端到端优化（LoRA 适配 MLLM 和生成器，完整训练语义桥，基础分辨率 512×384）；Stage 3 冻结 MLLM 和语义桥，仅微调生成器 LoRA，进行 256p–1024p 多分辨率细化。
Card 05 数据集与资源

数据集与资源

  • 训练数据：VITON-HD（11,647 对，768×1024）、DressCode（48,392 对，768×1024）、ViViD（7,759 对，624×832）。
  • 使用 DensePose 条件修补器离线构造训练三元组，但仅用于数据构建，推理时不使用 DensePose。
  • 评估基准：ViViD-S（视频协议，paired/unpaired）、DressCode 和 VITON-HD（标准图像协议）。
  • 模型规模：任务查询数 N=512，LoRA rank=32。
  • 训练资源：8 块 NVIDIA A100 GPU，每 GPU batch size 1，每个训练阶段 30k 步，AdamW 优化器，学习率 1×10⁻⁴。
Card 06 评估与结果

评估与结果

  • 图像指标：FID、KID；paired 设置下额外报告 SSIM、LPIPS。
  • 视频指标：VFID（基于 I3D 和 ResNeXt 骨干，分别记为 VFID_I 和 VFID_R）；paired 视频评估额外报告帧级 SSIM 和 LPIPS。
  • 实验在 ViViD-S 的 paired/unpaired 视频协议以及 DressCode、VITON-HD 的图像协议下进行。
  • 定量实验显示 UniVVT 在多个基准上取得最先进性能，并进行了延迟分析。
  • 消融实验验证了 Scene-Task Perceiver 的必要性以及渐进训练策略的效果，并通过注意力可视化解释模型行为。
