Card 02 论文概述

论文概述

  • 论文聚焦 FPV 无人机模拟视频传输（Analog VTX） 下的多视图几何估计问题，指出模拟传输产生的空间结构化噪声会严重降低 SOTA 几何基础模型 Depth Anything 3 (DA3) 的精度。
  • 提出 AnalogDepth，一种参数高效的训练流水线，通过 学生-教师知识蒸馏 + LoRA 适配 DA3 到模拟 FPV 图像，无需访问原始预训练代码或数据。
  • 构建真实模拟噪声库，并对比真实噪声注入、PSD 匹配高斯合成噪声和 AWGN 三种训练噪声策略，验证了模拟噪声空间结构对域适配的关键作用。
Card 03 核心贡献

核心贡献

  • 提出将视觉几何基础模型 DA3 适配到模拟 FPV 图像的参数高效训练流程，使用 LoRA 注入 DINOv2 骨干，冻结基础权重，仅训练少量适配参数。
  • 对模拟 VTX 噪声进行系统表征，发现其具有低频谱平坦度、能量集中于低频、强垂直条带和 DC 亮度闪烁等非高斯结构特征。
  • 构建真实模拟噪声库（noise bank），并在训练中直接采样注入，与 AWGN 和 PSD 匹配高斯噪声基线进行对比。
  • 提出基于真实 FPV 飞行序列的评估基准，包含 RealSense-DA3 伪地面真值，支持逐帧深度 RMSE 和 3D 重建 Chamfer Distance 两种指标。
  • 公开噪声库、6 段模拟 FPV 飞行序列及训练/评估代码（论文接收后发布）。
Card 04 方法描述

方法描述

  • 采用 学生-教师知识蒸馏 框架：教师 DA3 模型接收干净图像生成深度预测，作为学生模型的监督信号；学生 DA3 接收同一图像序列但添加模拟噪声的版本。
  • 学生模型骨干为 DINOv2，在注意力块中注入 LoRA 低秩适配参数；早期实验表明直接微调骨干会过拟合、仅微调头部无法收敛，LoRA 在保持预训练几何先验的同时实现高效适配。
  • 噪声注入采用三种策略对比：AWGN（方差匹配噪声库）、PSD 匹配高斯噪声（频域滤波白噪声以匹配平均功率谱）、真实噪声库采样（从静态 FPV 录像中提取残差图）。
  • 噪声提取过程：静态拍摄纹理表面，计算每帧与视频中值图像的残差，构造噪声库；训练与验证噪声样本严格分离。
  • 总损失为 DA3 原始深度损失 + 空间梯度正则化，仅优化 LoRA 参数，输入图像序列经过中心裁剪和下采样至 476×476。
Card 05 数据集与资源

数据集与资源

  • 训练数据：TartanAir2 合成数据集中 44 个场景，共 66,078 张图像，含验证划分。
  • 噪声库：6 段静态 FPV 录像提取 11,412 个残差图，严格分为训练和验证部分。
  • 测试集：6 段约 1 分钟的 FPV 飞行视频，来自 3 个室内场景，使用两台 Meteor75 Tiny FPV 无人机（C03 摄像头，128° FOV）和自定义 5.8 GHz FM 接收器，以 30fps 无损编码（FFV1）录制；每 5 帧采样一次。
  • 伪地面真值：RealSense D455 拍摄的 RGB-D 序列，并与 DA3 深度对齐生成 RealSense-DA3 参考。
  • 模型规模：使用 DA3-Small，LoRA 参数仅注入 DINOv2 骨干，基础权重冻结。
  • 训练硬件：单张 GeForce RTX 2080 Ti，batch size 4，序列长度 3，训练约 8 小时。
Card 06 评估与结果

评估与结果

  • 评估协议：逐帧深度 RMSE（尺度对齐）和 3D 重建 Chamfer Distance；深度真值通过 LightGlue 特征匹配 + RANSAC PnP 将 RealSense-DA3 或 RealSense 深度重投影至测试帧。
  • 深度 RMSE（以 RealSense-DA3 为参照，Table I）：噪声库方法在所有 6 段飞行中均优于预训练 DA3、AWGN 和 PSD 匹配噪声，如 garage_west 从 0.399 降至 0.275，plants 从 0.502 降至 0.275，stairs 从 0.631 降至 0.490。
  • 使用原始 RealSense 深度作为参照（Table II）：噪声库方法仍在多数场景最优，但 office 场景因 RealSense 本身噪声过大导致 RMSE 整体偏高。
  • 3D 重建 Chamfer Distance（Table III）：噪声库训练在 5 段序列上优于预训练 DA3，如 garage_south 从 0.407 降至 0.253，plants 从 3.281 降至 2.186，stairs 从 1.112 降至 0.776；仅 office_1 例外（重建重叠少）。
  • 多视图消融（Fig. 6-7）：增加输入视图数（1→10→100）可降低 RMSE，但预训练 DA3 即使 100 视图仍残留水平条带伪影；AnalogDepth 在 10 视图即可恢复结构。推理耗时：单图 0.05s、10 图 0.35s、100 图 7.12s（RTX 2080 Ti）。
  • 结论：真实模拟噪声的空间结构（如垂直条带）无法由 AWGN 或 PSD 匹配高斯噪声复现，噪声库注入训练能显著提升模拟 FPV 场景的深度估计和 3D 重建质量。
