Card 03 核心贡献

核心贡献

  • 首次研究无需重新训练或蒸馏流式骨干的双向到流式视频编辑迁移问题。
  • 提出两条流式兼容迁移原则：骨干特征解耦（backbone feature disentanglement） 和条件帧独立性（conditional frame independence）。
  • 设计 SVEET 架构，采用时间独立的 2D 注意力控制分支，实现因果兼容的条件注入且无需额外 KV 缓存。
  • 引入正交解耦训练（Orthogonal Decoupled Training, ODT），通过 SVD 提取双向到因果模型的特征差异子空间，并将控制更新约束在其正交补空间，从而缓解特征空间失配。
  • 在多个视频编辑任务上实现实时推理（单张 H100 GPU 上达 15 FPS），且编辑质量优于现有基线和受控对照方法。
Card 04 方法描述

方法描述

  • 基于 VACE（Wan-VACE）条件视频扩散架构，控制分支使用时间独立的 2D 空间自注意力，使每帧编码互不依赖，保持流式因果推理兼容。
  • 提出 ODT 方案：利用小型校准集，通过岭回归学习双向特征到因果特征的线性映射，对残差变换做 SVD，保留主要差异方向（保留 80% 累计谱能量）并构建正交投影矩阵，约束控制分支的 LoRA 更新仅发生在正交补空间。
  • 训练时保持双向骨干（Wan2.1-1.3B-VACE）完全冻结，仅优化控制分支和 LoRA 适配器，实现轻量且解耦的适应。
  • 理论分析（Theorem 1 & 2）表明，正交解耦能降低功能间的干扰、提升输出可加性，从而改善零样本迁移的稳定性。
Card 05 数据集与资源

数据集与资源

  • 风格迁移训练数据采样自 Ditto 数据集；视频修复和深度到视频生成数据采样自 VPData 数据集。
  • 深度条件使用 Video-Depth-Anything 提取。
  • 模型规模：基于 Wan2.1-1.3B-VACE 双向骨干，控制分支使用 LoRA（rank=128）。
  • 训练资源：单个 NVIDIA A100 (80GB) GPU，batch size 1，每任务训练 10 epochs，视频分辨率 480×832，81 帧片段。
  • 优化器：AdamW，学习率 1×10⁻⁴，权重衰减 10⁻²。
Card 06 评估与结果

评估与结果

  • 评估任务：视频风格迁移、视频修复、深度到视频生成三个代表性编辑任务。
  • 评估指标：VLM 评分、Text Alignment、VBench 系列指标。
  • 对比基线：SDEdit+CF、StreamDiffusionV2、Daydream+CF、LiveEdit 以及两个受控基线 Full-Attn 和 Channel-Concat Control。
  • 关键结果：SVEET 在三个任务上均取得领先的量化表现，同时保持实时性能（15 FPS on H100）。
  • 实验验证了时间独立注意力设计的有效性；全时空注意力迁移后编辑能力受损，而 2D 注意力变体转移更可靠，证实了两条设计原则。
