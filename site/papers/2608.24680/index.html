Card 02 论文概述

论文概述

  • 论文提出 Game2World Engine (G2WEngine)，一个将互联网游戏实机视频转化为世界模型训练数据的全栈数据引擎，解决原始游戏画面中 HUD 等界面元素对世界模型训练造成干扰的问题

  • 通过受控实验证明：去除 UI 后的游戏画面作为世界模型训练数据，可显著提升视频生成质量（整体 VideoReward 提升 6.83%）
Card 03 核心贡献

核心贡献

  • Pilot 研究：系统隔离游戏 UI 对世界模型训练的影响，使用 5,442 个干净/带 UI 对照片段训练视频生成模型，干净数据使 VideoReward 提升 6.83%、运动质量提升 18.8%、美学质量提升 8.59%
  • 完整任务体系：提出 GameUI-Taxonomy（21 类游戏 HUD 元素），形式化 HUD 定位与去除任务，并设计元素级去除、伪影、背景保持等评估协议
  • 可扩展数据引擎与数据集：G2WEngine 可从真实游戏视频中提取 UI 资源并合成时间连贯的成对数据，构建 Game2World 数据集（96K 合成视频对 + 1,079 个来自 303 款游戏的真实片段 + 5,132 个经验证的 UI 资源）
  • GameCleaner 模型：基于多模态大语言模型与视频扩散 Transformer 的免掩码游戏 UI 去除模型，支持参考图条件与无参考两种模式，在合成与真实基准上均取得最佳去除-保持平衡
Card 04 方法描述

方法描述

  • G2WEngine 四阶段流程：定义 UI 分类体系（GameUI-Taxonomy）、从真实视频提取可复用 UI 资源、构建干净游戏语料库、在干净画面上合成时间连贯的 UI 叠加（含掩码、框、类别标签等完整监督信号）
  • GameCleaner 架构：基于 Kiwi-Edit 架构，使用 MLLM 编码器替代 T5 文本编码器，联合编码采样帧与移除指令，通过可学习查询向量提取语义条件；VAE 潜在特征以时间步相关残差注入扩散 DiT，保留源视频空间与时间结构
  • 训练策略：冻结 MLLM 编码器和连接器，仅对 DiT 使用 LoRA（rank=64）微调，采用 flow-matching 目标；训练中随机丢弃 20% 参考图以增强无参考能力
  • 评估协议：以 2 FPS 采样视频，使用 MLLM 作为裁判，基于元素级边界框报告 AAR、UI、Clean、BG、Uncertain 五个指标
Card 05 数据集与资源

数据集与资源

  • Game2World-S：96K 合成 UI 叠加视频对，720p@30fps，含帧级 UI 掩码、边界框、类别标签与渲染元数据
  • Game2World-W：1,079 个真实 5 秒游戏片段，覆盖 303 款游戏，基于 GPT-5.6 Sol 首帧标注并人工修正动态 UI
  • UI 资产库：5,132 个验证通过的 UI 元素，来自 1,010 个代表性关键帧，覆盖 21 个分类
  • 训练资源：8×H100 GPU，全局 batch size 32，学习率 1×10⁻⁴，共 3,000 步
Card 06 评估与结果

评估与结果

  • 合成基准：GameCleaner 标准版取得最高 AAR 95.36，最强无掩码基线 LoomVideo 仅 40.3% 的相对差距，接近掩码辅助 EffectErase
  • 真实基准：GameCleaner（w. Ref）取得 AAR 80.05、BG 99.80，击败所有基线；无参考版达到 51.60 AAR，同时保持 99.60 BG
  • 总体表现：GameCleaner（w. Ref）总体分 93.34，比最强掩码基线 VACE-1.3B 高 23.97 个百分点，比最强免掩码基线 Kiwi-Edit 高 32.76 个百分点
  • 细粒度质量：合成集 Track-Clean 达 95.47；真实集 Track-Clean 68.12，远超 EffectErase 的 16.12，说明 GameCleaner 能完整干净地移除整个 UI 轨迹而非引入伪影
  • 裁判可靠性：MLLM 裁判与人类标注的 removed F1 为 87.78%，Cohen's κ 为 0.820；多次评分聚合后 ICC(A,5) 达 0.926（AAR）
  • 消融实验：参考图丢弃率 20% 为最佳平衡；训练数据从 60% 增至 100% 时，真实集 AAR 提升 25.09 点（54.96→80.05），合成集仅提升 2.06 点，表明数据多样性对真实泛化至关重要
