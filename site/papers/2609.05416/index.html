WorldSculpt: Generating Compositional Worlds from Grounded Videos

2026-09-04 · 原文 · 翻译 · 2609.05416

论文概述

  • 本文提出 WorldSculpt 框架，用于从带姿态的多视角视频/图像中生成组合式 3D 场景——场景由数百个独立对象网格（mesh）组成，每个对象可单独编辑、移动和仿真。

Card 03 核心贡献

核心贡献

  • 提出 WorldSculpt 框架：将多视角场景观测映射到锚点对齐的规范坐标系，以对齐观测条件化强对象级 3D 生成先验，并通过规范到世界的变换将生成网格置于共享世界坐标系中。
  • 证明仅在规范空间的单对象上微调的生成先验，通过多视角条件注入和定向增强课程，可以泛化到包含数百个密集遮挡对象的大规模场景，无需场景级训练。
  • 引入 UE-MeshyScene 基准：基于 Unreal Engine 渲染的照片级逼真密集杂乱场景，含数百个对象、逐对象标注和真实网格，用于评估复杂遮挡下的组合式 3D 生成。
  • 在单对象、受控多对象及 UE-MeshyScene 等设置中一致优于先前方法，且场景越拥挤、遮挡越严重时性能增益越大。
Card 04 方法描述

方法描述

  • 锚点对齐对象规范化（Anchor-aligned object canonicalization）：为每个对象构造锚点对齐的虚拟规范立方体，选择观测最完整的视角作为锚点决定规范方向，并依据 3D 定位框中心与尺度建立规范到世界的相似变换；通过动态扩大尺度避免裁剪，保持跨视角一致规范坐标系。
  • 多视角条件对象生成（Multi-view conditioned object generation）：以 Pixal3D（基于 TRELLIS.2 structured-latent 骨干）为生成先验，使用其稀疏结构（64³ 粗糙占据）和形状（高分辨率稀疏结构潜在）两个几何阶段；将每视角图像用 DINOv3 编码，通过裁剪感知投影将特征提升到规范体素体积。
  • 置换不变视图聚合（Permutation-invariant view aggregation）：采用 IBR 风格聚合器融合多视角特征，支持可变数量输入，聚合后的 3D 条件通过零初始化投影层注入冻结先验，并配合 LoRA 低秩适配器利用多视角证据。
  • 训练策略：随机视角训练 + 条件视角增强课程，提升对杂乱场景中部分观测和退化观测的鲁棒性；推理时按对象独立生成网格再经规范到世界变换摆放，无跨对象融合或联合形状优化。
Card 05 数据集与资源

数据集与资源

  • UE-MeshyScene：新引入的 Unreal Engine 照片级基准，室内外大规模场景，每场景数百个资产，含真实网格、相机参数、3D 包围框和逐对象标注。
  • Toys4k：受控单对象/多对象测试数据（合成）。
  • Toys4k-Scene：合成多对象场景数据集。
  • HouseCat6D：真实采集的多对象场景数据集。
  • Objaverse/Objaverse-XL：生成先验的预训练基础（背景提及）。
  • 模型基于 Pixal3D（TRELLIS.2 骨干，两阶段流匹配），特征提取使用 DINOv3；具体 GPU 训练资源配置未在摘要/引言中给出。
Card 06 评估与结果

评估与结果

  • 评估设置：规范空间单对象生成（Toys4k 压力测试）、受控多对象场景生成（HouseCat6D、Toys4k-Scene）、UE-MeshyScene 大规模场景生成；并进行多视角融合消融实验。
  • 主要指标：几何精度相关指标（如 IoU、Chamfer 距离等，具体数字见正文），侧重评估遮挡区域几何恢复质量和组合式场景的正确性。
  • 关键结果：WorldSculpt 在所有评估设置中一致优于先前方法，场景越密集、遮挡越严重时优势越明显；多视角融合消融验证了置换不变聚合和条件注入设计的有效性；方法还可将 Marble 和 HY-World 2.0 等 3DGS 世界转换为组合式网格场景，展示广阔应用潜力。
