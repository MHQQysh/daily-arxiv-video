Card 03 核心贡献

核心贡献

  • 提出 VideoEvolve 自进化框架，通过交替式智能体强化学习（Alternating Agentic RL）协同进化记忆构建策略与检索策略，使两种策略都能从下游推理反馈中持续提升。
  • 引入 Bottleneck-Aware Evolution Feedback（BEF），通过对比"仅记忆"与"可回看"两种推理表现，判断当前瓶颈在记忆侧还是检索侧，并将优化资源导向更受限的一方。
  • 引入 Capability-Aware Evolution Feedback（CEF），构建能力感知的自适应训练课程，缓解记忆对固定训练问题的过拟合，将训练重心转向尚未充分发展但可学习的能力。
  • 在 Video-MME、LongVideoBench、LVBench、MLVU、MMVU 等多个长视频理解基准上一致优于所评估的现有开源 SOTA 方法。
Card 04 方法描述

方法描述

  • Memory Evolver（记忆进化器）：采用 Observe–Decide–Augment 流程，从低帧率粗粒度概览构建固定的层次化 Base Memory（Root–Super–Macro 三级节点），并学习选择性增补记忆（Delta），通过更新的构建策略从同一 Base 重建记忆。
  • Retrieval Evolver（检索进化器）：采用 Search–Inspect & Revisit–Reason & Answer 流程，策略可调用层次导航、词汇/语义搜索、时间定位、分页读取、关键帧查看及 view_video 原始视频回看等工具。
  • 交替式 Agentic RL 协同进化：每个循环中冻结检索策略优化记忆构建，再利用更新后的记忆冻结重建并优化检索策略，形成 (C, R, M) 的交替更新链；记忆奖励包含"救援增益"（rescue）、回归惩罚与无效惩罚。
  • BEF 与 CEF 引导机制：BEF 按瓶颈分配训练资源；CEF 按能力诊断调整训练样本分布，支持能力前沿探索与保留，实现从下游推理经验到可迁移能力更新的转化。
