Card 02 论文概述

论文概述

  • 针对CLIP-based文本-视频检索（TVR）缺乏时序建模、将所有帧聚合成单一表示会丢失时序结构和帧级异质性问题，提出TAME（Temporal-Aware Mixture-of-Experts for Text-Video Retrieval）框架

  • 在多个标准TVR基准上验证框架有效性，实现一致性的性能提升
Card 03 核心贡献

核心贡献

  • 提出针对TVR场景定制的稀疏MoE架构，将MoE层整合到CLIP双编码器中，采用帧一致路由策略，在捕捉异构帧级视觉模式的同时保留原始视觉-语言对齐能力
  • 设计轻量级帧-时序（FT）tokens，在不修改空间token结构的前提下聚合跨帧全局上下文信息并反馈给每帧表示，实现长程时序依赖的轻量建模
  • 提出跨时序交互与聚合（CTIA）模块，通过分阶段时序过滤和融合将分散的帧-句子相似度精炼为连贯的视频级检索分数，解决帧级专家路由引入的时序不一致问题
  • 在MSR-VTT、DiDeMo、MSVD、LSMDC、ActivityNet等标准TVR基准上一致优于CLIP-based基线，其中在MSR-VTT数据集上R@1指标比CLIP4Clip提升4.0
Card 04 方法描述

方法描述

  • backbone采用预训练CLIP双编码器，文本编码器输出全局句子表示，视觉编码器为每帧输出帧级[CLS]表示作为帧序列
  • MoE增强CLIP模块：将CLIP双编码器中的部分前馈网络（FFN）替换为稀疏MoE层，文本端按token独立路由，视觉端采用帧一致路由（同一帧的所有patch共享路由权重，保证帧内语义一致性）；专家由预训练CLIP的FFN权重初始化，路由器随机初始化，同时引入负载均衡辅助损失防止路由坍缩，在扩展表示容量的同时保持低激活计算量
  • 帧-时序（FT）tokens模块：在视觉分支中引入轻量时序算子，聚合跨帧全局上下文信息并注入到每帧的表示中，在不破坏局部空间细节的前提下实现跨帧时序信息的共享
  • 跨时序交互与聚合（CTIA）模块：先计算每帧与句子的余弦相似度得到帧级证据，再通过分阶段时序过滤和融合，将帧级证据聚合为视频级检索分数，与 baseline 的全局相似度结合得到最终检索logit
  • 创新点在于帧一致路由解决视觉端patch级路由的噪声问题，FT tokens实现轻量时序建模，CTIA模块解决帧级路由导致的时序不一致问题，全程保留CLIP的预训练跨模态对齐能力
Card 05 数据集与资源

数据集与资源

  • 使用的标准TVR数据集：MSR-VTT、DiDeMo、MSVD、LSMDC、ActivityNet
  • 模型规模：基于预训练CLIP backbone，通过稀疏上cycling替换部分FFN为MoE层，总参数量随专家数量增加，稀疏激活机制下每 token 仅激活top-K专家，推理阶段计算量与原始CLIP相当
  • 训练资源：提供片段中未明确说明具体GPU/TPU配置，基于MoE稀疏激活特性，训练计算量高于原始CLIP但低于同规模dense模型
Card 06 评估与结果

评估与结果

  • 评估环境与基准：在5个主流TVR公开数据集上评估，与CLIP4Clip、CLIP2Video、X-CLIP等CLIP-based基线模型对比
  • 主要评估指标：Recall@K（R@1、R@5、R@10）等文本-视频检索常用排序指标
  • 关键实验结果：TAME在所有测试基准上均优于CLIP-based基线，MSR-VTT数据集上R@1较CLIP4Clip提升4.0；消融实验验证了MoE层、帧一致路由、FT tokens、CTIA模块各自的有效性；帧置换和掩码帧鲁棒性实验证明模型对时序噪声具有更强的鲁棒性；统一规模与计算对比实验表明TAME在性能和计算效率之间取得了更好的平衡
