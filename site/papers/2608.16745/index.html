Card 03 核心贡献

核心贡献

  • 形式化了统一的视觉上下文视频编辑范式，从“描述性指令”转向“感知性示例”，并构建了首个大规模数据集VicEdit-400K（400K样本，三种模态，十种任务）。
  • 提出VicEdit框架，支持异构视觉参考输入，并设计了模态自适应语义蒸馏（MASD），通过模态条件查询自适应提取不同模态下的编辑语义。
  • 提出双上下文注入（DCI）机制，利用视觉上下文校准指令查询，实现视觉与文本信号的协同融合，注入视频DiT生成过程。
  • 建立VicEdit-Bench基准，系统评估三种参考模态下的视觉上下文编辑性能，并在基础文本编辑和视觉上下文编辑任务上取得state-of-the-art结果。
  • 通过大量消融实验验证了MASD和DCI各组件的有效性。
Card 04 方法描述

方法描述

  • 总体架构：采用冻结的MLLM（多模态大语言模型）进行语义理解，结合视频DiT进行生成，两者通过MASD和DCI两个轻量模块连接。
  • 模态自适应语义蒸馏（MASD）：使用共享基础查询 $\mathbf{Q}_{base}$ 加上可学习的模态特定嵌入 $\mathbf{E}_m$，得到模态自适应查询，再通过交叉注意力从MLLM隐藏状态中蒸馏出视觉语义 token $\mathbf{T}_{vis}$。该设计将搜索空间分解为公共编辑流形和模态特定子空间。
  • 双上下文注入（DCI）：利用MASD的视觉查询生成语义偏移向量，通过MLP校准指令查询，得到视觉感知的指令 token $\mathbf{T}_{inst}$，与视觉 token 拼接为 $\mathbf{T}_{dual}$，作为DiT交叉注意力的键和值。
  • 训练策略：三阶段训练——①基础编辑微调（仅更新DiT）；②上下文分支训练（冻结DiT和MLLM，训练MASD、DCI和指令查询）；③联合微调（解冻DiT，整体微调，MLLM保持冻结）。
  • 基础模型：基于Wan-TI2V-5B初始化，继承Kiwi-Edit的预训练权重。
Card 05 数据集与资源

数据集与资源

  • VicEdit-400K：从Señorita-2M和OpenVE-3M中筛选构建，经四阶段流水线（源数据过滤、指令合成、视觉参考生成、语义验证）生成。
  • 数据覆盖三种参考模态（单张图片、图片对、视频对）和十种任务类型，视频长度以30~120帧为主。
  • 视频参考生成采用语义知识图谱和谱聚类，避免生成式编辑的时序伪影。
  • 基准VicEdit-Bench：包含200个代表性实例（每个任务-模态组合10个），严格隔离训练集，用于零样本评估。
  • 模型规模：视频DiT基于Wan-TI2V-5B（约5B参数），训练资源未在摘要中详述。
Card 06 评估与结果

评估与结果

  • 评估基准：基础编辑任务使用扩展的OpenVE-Ext（在OpenVE-Bench上增加3个Señorita任务）；视觉上下文编辑使用VicEdit-Bench。
  • 评估指标：采用MLLM（Qwen3-VL）自动评分，结合VBench的保真度和时间一致性指标，以及IVE-bench指标。
  • 关键结果：在OpenVE-Ext和VicEdit-Bench上，VicEdit在所有参考模态下均取得state-of-the-art性能，显著优于文本驱动基线（如DiTTO、VideoCoF）和参考图方法（如Kiwi-Edit）。
  • 定性结果（图1）显示，VicEdit能精确解决风格漂移（单图）、空间漂移（图片对）和静态动态（视频对）问题，验证了视觉示例的必要性。
