论文概述

Card 03 核心贡献

核心贡献

  • 首次将掩码 Siamese 网络成功扩展到视频，并利用图像分类流程（super image）实现自监督视频表示学习，是 VideoMSN 的核心创新。
  • 提出结合空间块掩码与时间帧掩码的层次化掩码策略：随机视图采用空间 patch 掩码，焦点视图采用时间帧丢弃（fast view ≈ M/2 帧，slow view ≈ M/4 帧）后叠加空间焦点掩码，从而让模型学习不同时间稀疏性的动作动态。
  • 采用无解码器的 encoder-only 设计，可直接利用图像预训练的 ViT（如 DINO-v3、DeiT-v3），显著减少视频自监督预训练所需的轮次，最多可比生成式掩码视频建模方法（如 VideoMAE）减少 160× 预训练轮次。
  • 在多个视频基准（Kinetics-400、UCF101、HMDB51）上达到或超越现有自监督方法，并在低样本分类中展现出良好的表示迁移能力。
Card 04 方法描述

方法描述

  • 将未标注视频 $U^i$ 中等距采样 $M$ 帧，按行优先网格排列成 super image $S^i$。
  • 每个 super image 生成一个未掩码的 target view 和一组 anchor views（包括随机视图和焦点视图）。
  • 随机视图：对 super image 进行空间 patch 掩码，且保证所有帧中同一空间位置的 patch 同时被掩码或保留（时间一致性 tube masking）。
  • 焦点视图：两阶段掩码——先进行时间掩码（丢弃整帧，得到 fast view 和 slow view），再进行空间焦点掩码（保留每个帧中同一空间连续区域，掩码周围 patch），得到多个 temporally masked focal views。
  • 使用 Siamese 架构：anchor view 经过编码器 $f_\theta$，target view 经过 EMA 更新的目标编码器 $f_{\bar\theta}$，两者共享 ViT 结构，取 [CLS] token 作为嵌入。
  • 通过将嵌入与可学习原型（prototypes）计算余弦相似度得到分布，使用交叉熵损失对齐 anchor 预测与 target 预测（target 使用更锐利的温度），并配合熵最大化（如 MSN 中的做法）进行原型驱动的学习。

  • 骨干模型：Vision Transformer (ViT)，基于图像预训练权重初始化，具体包括 DINO-v3 和 DeiT-v3 图像编码器。

Card 06 评估与结果

评估与结果

  • 在 Kinetics-400 上，VideoMSN（DINO-v3 backbone）达到 state-of-the-art 精度，且相比 VideoMAE 和 SMILE 分别只需要 160× 和 60× 的预训练轮次。
  • 在 UCF101 和 HMDB51 上也取得 state-of-the-art 性能，验证了跨数据集的泛化能力。
  • 低样本分类实验中表现优异，证实了所学表示在标签稀缺场景（label-scarce）下的可迁移性。
  • 消融研究验证了时间帧掩码（fast/slow view）相比仅空间 patch 掩码能带来更好的表示学习效果；同时验证了从图像预训练初始化开始进行 VideoMSN 自适应的有效性。
