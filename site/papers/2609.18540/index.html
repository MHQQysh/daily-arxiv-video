SVMemAgent: A Streaming Video Memory Agent for Query-Agnostic Online Frame Selection

Card 03 核心贡献

核心贡献

  • 提出 SVMem 形式化定义，针对未知视频时长、有限记忆容量和无查询信息的严格在线流式设置。
  • 提出 SVMemAgent，采用语义分支和时间分支的双分支架构，以及两阶段动作策略（先决定是否丢弃，再决定替换哪个记忆槽）。
  • 使用 GRPO 结合任务驱动奖励训练代理，并引入 Diversity-Aware Advantage Discounting (DAAD) 正则化，抑制奖励对帧选择不敏感时带来的噪声梯度。
  • 在在线和离线视频基准上，SVMemAgent 一致超越在线帧选择基线，并达到与假设完整视频和查询可用的离线方法竞争的性能。
  • 实验发现代理隐式学习到优先保留含文本信息等非冗余帧的策略，可提升下游 VideoQA 性能。
Card 04 方法描述

方法描述

  • SVMem：固定容量为 K 的帧记忆，每个时间步 t 接收新帧 v_t，系统决定丢弃或替换某个现有记忆槽；查询到达时将最终记忆状态与查询一同交给 VideoLLM（如 InternVL3.5、Qwen3-VL）生成答案。
  • SVMemAgent 双分支架构：

- 语义分支：用图像编码器提取视觉特征，经轻量 Transformer 建模当前帧、K 个记忆槽和流上下文（全局平均特征）的关系，输出语义丢弃分数和替换分数。

- 时间分支：仅使用帧时间戳的归一化位置嵌入，经浅层 Transformer 建模时间覆盖，输出时间丢弃分数和替换分数。

- 最终分数由可学习权重加权融合，动作通过 sigmoid/softmax 得到。

  • 训练两阶段：

- 阶段一：冷启动训练，基于启发式伪标签（语义相关性/新颖性、时间均匀性）分别初始化两个分支。

- 阶段二：GRPO 训练，使用冻结 VideoLLM 计算平均 token 对数概率作为任务驱动奖励，每个视频使用 4 个不同问答对以增强泛化。

  • DAAD：计算最终记忆状态的 Jaccard 多样性，与奖励标准差之比通过 sigmoid 得到折扣系数 α，再缩放 GRPO 优势，当记忆多样但奖励差异小时抑制梯度。

Card 06 评估与结果

评估与结果

  • 对比基线包括离线设置（Uniform、Random、Clustering、StreamChat、AKS、M-LLM Selector）和严格在线设置（FIFO、Reservoir、TimeChat-Online、Flash-VStream、MA-LMM）。
  • SVMemAgent 在严格在线设置下一致优于所有在线帧选择基线。
  • 与离线方法（了解完整视频和查询）相比，SVMemAgent 达到竞争力相当的性能。
  • 消融实验验证了双分支结构、GRPO训练、DAAD 正则化以及多查询奖励的有效性。
  • 分析表明代理学到的策略偏向保留含文本信息等非冗余、信息量高的帧，有利于下游 VideoQA。
