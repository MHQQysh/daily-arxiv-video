Card 03 核心贡献

核心贡献

  • 基于 Cosmos 3 视频扩散模型，在 300 到 30,000 小时的数据阶梯上开展受控缩放实验，首次直接度量智能体保真度与对象交互保真度在数据规模下的不同行为模式。
  • 提出骨架条件化（skeleton conditioning）设计：将投影后的骨骼序列用同一冻结 VAE 编码并加到视频 token 上，仅需 1k 小时数据即可超过标准条件化在 30k 小时下达到的智能体保真度，从而把智能体能力从数据需求中解耦出来。
  • 提出对象中心自适应噪声调度（object-centric adaptive noise scheduling），将训练信号从场景外观转向被操作对象的动态，是唯一能提升对象保真度收敛水平的干预手段。
  • 证明上述增益可迁移到下游人形机器人（humanoid）建模场景，但人形智能体与世界交互的建模仍是瓶颈。
  • 发布完全独立采集的分布外（OOD）评测基准，包含不同拍摄硬件、地点与参与者的 150 段人工精选交互片段。
Card 04 方法描述

方法描述

  • 使用 Cosmos 3 视频扩散模型作为基础架构，以初始 RGB 帧、文本描述和 159 维动作序列（相机位姿、手腕位姿、左右手各 20 个手部关节、肩肘位置）为条件预测未来帧。
  • 动作条件化以整流流匹配（rectified flow matching）训练，条件 token 在去噪过程中保持干净；支持两种动作条件化设计——标准动作 token 与空间对齐的骨架条件化。
  • 骨架条件化将 21 关节手部与肩-肘-腕链投影到图像平面，并用 HSV 颜色编码深度信息（色相标识手指/肢体、明度随距离衰减），以保留 3D 姿态信息。
  • 对象中心自适应噪声调度通过局部化动态区域（基于点轨迹与手部邻近先验）并重加权损失，引导模型容量从大面积场景外观转向被操作对象的动力学。
  • 论文同时测试了现有交互聚焦目标（PhysisForcing）作为对照，发现在大规模第一人称场景下无显著提升。
Card 05 数据集与资源

数据集与资源

  • 训练集为 Mecka 数据集：115 万段第一人称视频片段，共 30,000 小时、32.4 亿帧（30 fps，平均片段时长 94 秒），每帧含标定内参、6-DoF 相机位姿、每手 21 个 3D 手部关键点、腕部位姿、上半身关键点及自由文本活动描述。
  • 数据多样性极高：116 种环境类别（家庭、面包房、花店、农场、修理店等）、1,106 种场景类别、32,051 个任务、来自 14,019 名参与者，单一环境类型占比不超过 8.3%。
  • 模型三个变体：Edge（4B 参数，2B 去噪 Transformer，从头训练）、Nano（16B 参数，8B Transformer）与 Super（64B 参数，32B Transformer），后两者初始化自相同规模的预训练 Qwen3-VL。
  • 训练采用平衡嵌套数据阶梯，预算为 300 / 1k / 3k / 10k / 30k 小时，更大预算共享同一数据前缀并延长训练计算量。
  • 评测集来自独立采集活动，37% 的环境类别（占四分之一片段）在训练中从未出现；150 段人工精选片段均满足非平凡交互、对象可分割、身体关节标注准确三个条件。
Card 06 评估与结果

评估与结果

  • 评估环境为分布外（OOD）基准：不同拍摄平台、操作者和地点，与训练集无地点或参与者重叠。
  • 主要指标为基于分割掩码的结构一致性度量，分别报告智能体（手部区域）保真度与被操作对象保真度；以帧级 SSIM、PSNR、LPIPS、DreamSim 和 FVD 等感知指标作为对照。
  • 关键结果一：数据扩展（300→30k 小时，100×）同时改善智能体与对象保真度，但极不均衡——智能体持续攀升至可用水平，而对象保真度起点更低、提升更慢、收敛上限远低于智能体。
  • 关键结果二：骨架条件化能在 1k 小时数据下超越标准条件化在 30k 小时下的智能体保真度，两者最终收敛到几乎相同的上限；智能体饱和后，对象保真度的独立测量揭示出显著的"智能体-对象差距"。
  • 关键结果三：现有交互聚焦目标（PhysisForcing）在规模上无改善；对象中心自适应噪声调度虽能提升对象保真度的收敛水平，但差距仍然巨大。
  • 关键结果四：在人形机器人微调下游任务中，所提设计与骨架条件化带来的增益超过仅靠 30k 小时第一人称预训练的贡献，但人形智能体与世界互动的建模仍为瓶颈，且存在与人类场景一致的智能体/对象保真度不对称现象。
