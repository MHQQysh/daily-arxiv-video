Card 03 核心贡献

核心贡献

  • 深入分析了现有方法面临的信任困境，提出新视角：对于像素对齐的几何先验，在生成起点直接消费比将其作为条件学习更有效。
  • 提出 Manifold4D，将点云渲染注入 flow matching 起始点，使生成从几何承载噪声出发，同时保持视觉质量与轨迹控制精度。
  • 在 DAVIS-Traj 和 Vista4D 两个基准上所有相机控制指标均排名第一，旋转误差分别降低 25% 和 27%，平移误差最高降低 32%，逼近点云渲染本身的几何参考精度。
  • 用户研究中在轨迹跟随和动态一致性上取得明显优势；在渲染被故意破坏时仍能从源视频恢复正确的动态运动，证明几何先验引导生成而非压制生成。
  • 通过消融实验表明渲染注入不破坏扩散先验，模型经微调后能完全适应偏移后的分布。
Card 04 方法描述

方法描述

  • 基于 Wan2.1-T2V-14B 潜在视频扩散 Transformer，采用 flow matching 训练框架，通过因果 VAE 在潜在空间学习速度场。
  • 使用 VGGT-Omega 估计每帧深度、相机内参和外参，反投影构建全局对齐的 4D 点云；静态点云跨帧累积，动态点云逐帧保留，渲染时按目标帧合成。
  • 使用 Qwen2.5-VL 和 SAM3 分割动态主体，获得运动掩码以分离动态/静态点。
  • 关键创新——几何感知起点：将渲染 latent 注入初始噪声 $\tilde{x}_1 = x_{\text{render}} + \sigma\varepsilon$，再按渲染覆盖率 $\alpha$ 与纯噪声插值；覆盖区域从"渲染+噪声"出发，空洞区域从纯高斯噪声出发，部分覆盖区域线性插值。
  • 源视频经 VAE 编码后 patchify 为 token，与几何感知噪声 token 拼接，作为唯一视觉条件送入 DiT；相机轨迹以 Plücker 嵌入形式通过零初始化线性投影注入注意力层，作为训练期保险。
  • 微调范围仅限 patchify 层、自注意力层、相机编码器和投影器，其余参数全部冻结。
Card 05 数据集与资源

数据集与资源

  • 训练数据混合五个来源：DL3DV、DynPose、OpenVid-HD、MultiCamVideo、HuMMan，共约 36K 个源片段；深度与相机位姿由 VGGT-Omega 提供（HuMMan 自带多相机标定）。
  • 基座模型为 Wan2.1-T2V-14B（14B 参数），微调 patchify、self-attention、相机编码器与投影器。
  • 训练配置：AdamW 优化器，学习率 1×10⁻⁵，全局 batch size 8，训练 30K 步，分辨率 384×672，每片段 49 帧。
Card 06 评估与结果

评估与结果

  • 评测基准：DAVIS-Traj（72 clips）与 Vista4D-Eval（103 clips），另有 Vista4D-Eval raw（110 clips）和用户研究。
  • 评估指标：旋转误差（RotErr↓）、平移误差（TransErr↓）、内在误差（IntrErr↓）、VBench 美学/成像质量、以及用户主观评分。
  • 相机控制精度：Manifold4D 在全部指标上排名第一，旋转误差较最强基线降低 25%（DAVIS-Traj）和 27%（Vista4D），平移误差最高降低 32%，已接近点云渲染本身的几何参考水平。
  • 视频保真度：与最强基线持平，在真实世界新视角光度质量上领先。
  • 消融实验验证：渲染注入起点的策略优于传统条件拼接；移除 Plücker 相机嵌入对精度和画质基本无影响（因渲染已固定视角），但仍保留作为训练期安全机制。
