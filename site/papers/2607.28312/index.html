Card 03 核心贡献

核心贡献

  • 提出 ObjectStream，一个免训练、即插即用的视觉记忆框架，无需修改底层 Video-LLM 架构即可实现高效流式视频理解。
  • 引入 Latent Object-Anchored Memory（潜在对象锚定记忆），利用潜在对象作为持久锚点组织长期视觉证据，无需外部检测器或分割器。
  • 补充 Object-Conditioned Temporal Residuals（对象条件时间残差）和 Recent Visual Grounding Window（近期视觉定位窗口），捕获瞬时对象变化和近期视觉上下文。
  • 在在线流式视频基准和离线长视频基准上均取得显著性能提升，同时大幅降低计算资源消耗。
Card 04 方法描述

方法描述

  • 框架由三个互补的记忆模块组成：Latent Object-Anchored Memory、Object-Conditioned Temporal Residuals 和 Recent Visual Grounding Window。
  • 潜在对象发现分为四个阶段：S1 查询无关 token 显著性估计（基于与帧级上下文向量的余弦差异）、S2 空间聚类发现对象锚点（利用 patch 网格的 4-连通图连通分量）、S3 跨帧关联与有界对象集维护（通过余弦相似度匹配并用 EMA 更新对象特征，按近期性、显著性和时间一致性排序淘汰）、S4 对象中心证据保留（在每对象 token 池内按显著性选择 top-k token）。
  • 创新点在于完全从冻结的 Video-LLM 特征中生成对象级记忆，而不是直接管理原始 token 或 KV 状态，从而保留对象身份、交互和状态变化的细粒度证据。

Card 06 评估与结果

评估与结果

  • 在 OVO-Bench Real-Time Visual Perception 上，相比 Qwen2.5-VL-7B 原始基线提升 10.0 点；在 OVO-Bench Backward Tracing 提升 4.9 点；在 StreamingBench 提升 2.9 点。
  • 峰值 GPU 内存和首 token 时间（TTFT）均降低约 50%。
  • 在离线长视频基准上，超越全 token 基线的同时丢弃 82.5% 的视觉 token，展示了显著的内存效率和 token 效率。
  • 消融实验验证了各记忆组件的有效性，并分析了对象记忆构建与效率的权衡。
