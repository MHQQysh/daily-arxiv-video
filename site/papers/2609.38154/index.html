LongLive-Plug: Once-for-All Distillation for Video Generation

2026-09-29 · 原文 · 翻译 · 2609.38154

论文提出 LongLive-Plug，一个 once-for-all 蒸馏框架，在基础模型上蒸馏可复用的能力为 LoRA（functional LoRAs），并以 training-free 方式即插即用地部署到兼容的下游视频生成模型。 框架涵盖三种核心能力：CFG 蒸馏（将双分支 classifier-free guidance 合并为单次模型评估）、few-step 蒸馏（实现四步采样）、以及长上下文蒸馏（用于自回归推理中的长时间视频错误纠正）。 解决了当前"每个专用模型都要重复蒸馏"的高昂成本问题，将蒸馏从 per-target 模式转变为 per-backbone 的一次性投入。

Card 03 核心贡献

核心贡献

  • 提出 LongLive-Plug once-for-all 蒸馏框架，在 54 个下游模型、3 个骨干家族（Wan2.1-14B、Wan2.2-TI2V-5B、MiniMax-H3）和 8 个任务类别上验证了无训练部署。
  • 提出解耦蒸馏策略：将 CFG 蒸馏与 few-step 蒸馏分别学习为独立 LoRA，避免联合蒸馏中固定引导强度的问题；CFG LoRA 的推理权重可作为引导强度的调节旋钮，实现近似线性控制。
  • 设计可迁移导向的训练方案：通过更高 LoRA rank 和更广泛的 T2V 蒸馏数据提高适配器在下游模型上的迁移质量。
  • 引入长上下文蒸馏：基于 Streaming Long Tuning，在因果 AR 基础模型上通过 DMD 监督训练，学习纠正自回归 rollout 中累积误差的能力，并可直接迁移至支持 AR 推理的下游世界模型。
  • 在 SCOPE 与 Wan2.2-Fun-5B-Control 上定量验证：零下游训练成本下，性能优于 naive four-step 采样，与 per-target distillation 竞争力相当。
Card 04 方法描述

方法描述

  • CFG 蒸馏：固定教师引导权重 $w_{\mathrm{train}}$，仅训练 CFG LoRA 最小化其单次条件输出与教师引导预测之间的平方误差；骨干权重、采样调度和注意力模式均保持冻结。
  • CFG LoRA 权重作为引导拨盘：推理时缩放 CFG LoRA 权重 $\lambda_{\mathrm{cfg}}$ 可在近似线性假设下调整有效引导强度，恢复条件模型（$\lambda=0$）或完整蒸馏适配器（$\lambda=1$），并支持外推。
  • 解耦引导控制：推理时独立合并 few-step LoRA 与 CFG-only LoRA 的权重更新，可在保持 few-step 生成能力的同时独立调节每一下游任务的引导强度。
  • few-step 蒸馏：使用 DMD2 在基础模型上训练，以 CFG 引导教师进行分布匹配蒸馏，实现四步采样。
  • 长上下文蒸馏：在冻结的 causal AR 基础模型上使用 Streaming Long Tuning + DMD 监督，学生从缓存历史生成短片段，教师监督生成质量，历史梯度被 detach 以保证梯度局部性。

Card 06 评估与结果

评估与结果

  • 评估对比候选：native multi-step 推理（SCOPE 30 步 / ControlNet 40 步）、naive four-step 采样、per-target DMD2 蒸馏、以及 LongLive-Plug（零下游训练成本）。
  • 主要指标：SCOPE 使用 JEPA、FVD、LPIPS、Flow、Smoothness、Photo.、Depth；ControlNet 使用 SSIM、F1、si-RMSE、mIoU、DOVER、LPIPS。
  • SCOPE 结果：LongLive-Plug 的 JEPA 0.792 / FVD 478.7 / Photo. 4.246 / Depth 1.230，显著优于 naive 4-step（JEPA 0.732 / FVD 805.5），接近 SCOPE 专用蒸馏的水平（JEPA 0.782 / FVD 502.1）。
  • ControlNet 结果：LongLive-Plug 以四步推理、禁用 CFG 的条件下取得与 naive 4-step 相近或更优的控制保真度，且 zero-shot 无需下游重训。
  • CFG 可控性：独立 CFG-only LoRA 可通过权重调节有效引导强度；全局缩放联合 LoRA 会破坏 few-step 行为并导致崩溃。
  • 迁移设计消融：较高 LoRA rank 和更广泛的蒸馏数据覆盖均能显著提升下游迁移质量；仅关注 base-model 拟合不足以决定迁移容量。
  • 长上下文迁移：将 long-context LoRA 迁移到 ReWorld 与 Matrix-Game 3.0 世界模型，在长自回归 rollout 中提升了视频质量，证实误差纠正能力的可复用性。
