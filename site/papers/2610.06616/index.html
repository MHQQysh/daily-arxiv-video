Card 03 核心贡献

核心贡献

  • 形式化问题分解：将紧凑视频编码拆分为逐帧表示、跨帧 token 分配和时间交互三个独立操作，并推导出条件预测误差分解（Proposition 1）与选择-交互恒等式（Proposition 2），区分“缺失证据”与“预测误差”
  • 提出 image-first 路径：由冻结的图像编码器逐帧编码生成候选，问题感知选择器在固定预算内协调分配 token，轻量级时间细化器在选后补充上下文且不增加输出 token
  • 保持源对齐的固定预算输出：选择器输出的锚点保留源位置和中间特征流，保证 B→B 输出维度，不影响语言模型的接口兼容性
  • 大规模实验验证：在 13 个视频理解基准 和 3 个视觉-语言骨干 上验证，匹配全图像聚合性能的同时仅使用 约 28%–35% 的视觉 token
Card 04 方法描述

方法描述

  • 冻结的逐帧图像编码器：对每帧独立计算特征 Z_t，不涉及跨帧计算，保留帧特定候选的可选择性
  • 问题感知的协调选择器：基于问题相关性、多样性（DPP 核）和相邻帧对应关系分配固定预算 B，通过贪心求解器完成选择
  • 轻量级时间细化器：读取邻居帧上下文，仅对已保留的锚点写入残差更新，输出仍为 B 个 token；位置流和中间特征流保持不变
  • 关键创新点：选择与交互解耦——选择发生在时间混合之前，时间上下文可以在选择后按需补充，且不占用额外的语言模型输入 token
Card 05 数据集与资源

数据集与资源

  • 实验覆盖 13 个视频理解基准，包括视频问答与时刻检索等任务
  • 骨干模型采用 Qwen3-VL-8B 与 Qwen3-VL-32B 等视觉-语言模型，共 3 个骨干
  • 视觉 token 预算设置：完整图像路径为 4,424 tokens，原生 Conv3D 为 2,212 tokens，所提路径仅为 1,535 tokens
Card 06 评估与结果

评估与结果

  • Qwen3-VL-8B：13 基准宏平均 62.75（1,535 tokens），优于全图像路径 62.58（4,424 tokens）和原生 Conv3D 59.49（2,212 tokens）
  • Qwen3-VL-32B：宏平均 66.28，优于全图像路径 66.09，同时提供 2.16× 端到端推理加速
  • 效率优势：在约 1/3 视觉 token 预算下，匹配或超越全图像聚合性能，显著降低视觉 token 传输与语言模型计算成本
  • 消融分析：验证了选择器组件（相关性、多样性、帧间对应）、细化器目标（上下文读取方式）以及多预算精度-延迟权衡的作用
