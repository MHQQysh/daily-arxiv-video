SQuad: Sub-Quadratic Attention Distillation for Efficient Video Generation

2026-08-17 · 原文 · 翻译 · 2608.16585

Card 02 论文概述

论文概述

  • 提出 SQuad（Sub-Quadratic Attention Distillation） 框架，用于高效视频生成，解决视频 Diffusion Transformer（DiT）中 softmax 自注意力计算量随 token 数二次增长的问题。
  • 核心思路是将完整 softmax 自注意力分解为“局部 + 全局”两次注意力传递，在保持真实 softmax 的前提下将复杂度从 O(n²) 降至 O(n√n)。
  • 通过将预训练的全 softmax 注意力 DiT 蒸馏为 SQuad-Attention 版本，避免从零训练昂贵的大模型，同时显著降低推理延迟和 FLOPs。
Card 03 核心贡献

核心贡献

  • 提出 SQuad-Attention：一种固定结构、子二次复杂度的注意力算子，由局部窗口内注意力和跨窗口全局注意力组合而成，并保持完整感受野。
  • 设计两阶段蒸馏流程：先进行 Flow-Matching 监督微调（SFT），再使用改进的 DMD2 分布匹配蒸馏，同时恢复模型能力并减少采样步数。
  • 在 Wan 2.2 5B 文本生成视频模型上，SQuad 在 VBench 上匹配原始二次注意力教师模型（83.20 vs 83.08）。
  • 实现显著的效率提升：注意力 FLOPs 降低约 67×，注意力延迟降低约 11×，端到端 DiT 延迟降低约 2×。
  • 在 Wan 2.1 1.3B 上同样验证了方法的可扩展性与泛化性。
Card 04 方法描述

方法描述

  • SQuad 将 n 个视频 token 组织为若干大小为 O(√n) 的窗口，先执行局部注意力（窗口内 token 混合），再执行全局注意力（各窗口相同位置的 token 跨窗口混合）。
  • 两次传递均使用真正的 softmax，不引入线性核或低秩替代，避免了传统高效注意力方法的质量损失。
  • 相比数据依赖的稀疏掩码方法（如 VSA、Radial Attention），SQuad 使用固定结构化通信模式，无需复杂 token 选择步骤。
  • 蒸馏过程：第一阶段用 flow-matching SFT 适配新注意力结构；第二阶段用 DMD2 进一步做分布匹配蒸馏，使学生模型可以用更少 NFE 生成视频。
  • 交叉注意力和前馈网络保持不变，只替换自注意力模块，因此易于移植到现有视频 DiT 架构。

数据集与资源

  • 模型规模：Wan 2.2 5B 和 Wan 2.1 1.3B 文本生成视频模型。

Card 06 评估与结果

评估与结果

  • 评估环境：视频生成质量使用 VBench，效率使用注意力 FLOPs、注意力延迟和端到端 DiT 延迟。
  • 质量结果：SQuad 蒸馏模型在 VBench 上获得 83.20，原始二次注意力教师为 83.08，几乎无质量损失。
  • 效率结果：注意力 FLOPs 减少约 67×，注意力延迟减少约 11×，端到端 DiT 延迟减少约 2×。
  • 采样效率：仅需 6 个 NFEs 即可生成视频，而基线需要 100 个 NFEs。
  • 消融实验表明：SFT 和 DMD2 两个训练阶段均必要；局部/全局两次传递的顺序和窗口大小对最终性能有重要影响。
