VETO: Video Efficient Token Optimization for Vision Language Models

2026-10-01 · 原文 · 翻译 · 2610.01785

提出 VETO（Video Efficient Token Optimization），一种训练可选（training-optional）的即插即用模块，用于解决 Vision-Language Models（VLMs）处理长视频时因视觉 token 数量庞大导致的二次方注意力计算瓶颈。 核心思路是通过双轴压缩——帧内（intra-frame）语义 token 合并 + 帧间（inter-frame）时间冗余帧合并——在保持语义信息的同时大幅降低送入 LLM 的 token 数量。 关键设计是层次化顺序：先做空间压缩，再做时间匹配，从而突破单轴压缩方法（仅空间或仅时间）难以规避的效率和延迟瓶颈。

Card 02 论文概述

论文概述

  • 提出 VETO（Video Efficient Token Optimization），一种训练可选（training-optional）的即插即用模块，用于解决 Vision-Language Models（VLMs）处理长视频时因视觉 token 数量庞大导致的二次方注意力计算瓶颈。
  • 核心思路是通过双轴压缩——帧内（intra-frame）语义 token 合并 + 帧间（inter-frame）时间冗余帧合并——在保持语义信息的同时大幅降低送入 LLM 的 token 数量。
  • 关键设计是层次化顺序：先做空间压缩，再做时间匹配，从而突破单轴压缩方法（仅空间或仅时间）难以规避的效率和延迟瓶颈。
Card 03 核心贡献

核心贡献

  • 硬件无关的双轴压缩方法：提出“先帧内、后帧间”的层次化压缩顺序，将有效注意力复杂度从 O((TN)²) 降至 O(TN²/k + T²C)（C ≪ N），打破单轴压缩的效率下限，且在现代融合注意力基础设施上优势更加明显。
  • 通用且训练可选的即插即用插件：无需修改模型架构、无需自定义 CUDA kernel、无需重训练，即可直接集成到 LLaVA-OneVision、InternVL-2.5、LongVA 等多种冻结 VLM 中。
  • 极端 token 预算下的鲁棒性：在仅保留 10% token 的极端条件下，VETO 达到 55.7% 准确率，超过 VFlowOpt（54.9%）、VisionZip（52.6%）和 FastV（47.9%），且零样本精度在各类模型上保持或提升。
  • 系统级贡献：作为纯张量变换模块，完全兼容标准注意力实现（如 FlashAttention），提供真实的端到端延迟评测（视觉编码器 + token 压缩 + LLM 推理）。
Card 04 方法描述

方法描述

  • 帧内压缩器（Intra-Frame Compressor）：对每个帧内的 token 采用最优传输启发的 k-way 划分，将 token 分为“源”和“锚点”，通过余弦相似度匹配，将语义相近的源 token 合并到最近锚点，使用大小加权平均形成新 token，将空间 token 数从 N 减至约 N/k。
  • 帧间压缩器（Inter-Frame Compressor）：在帧内压缩后的空间维度上，通过空间均值池化得到帧表示，计算帧间余弦相似度矩阵，用贪心算法选择最相似的非重叠帧对进行合并，直到达到目标帧数 T′。
  • 创新点：先空间后时间的层次化顺序大幅降低了全局时间相似度匹配的计算成本，解决了单轴方法必须对“完全未压缩”token 做相似度计算而导致延迟过高的问题。
  • 位置信息处理：利用 ViT 编码器已注入的绝对位置信息，合并后由 LLM 按顺序索引，位置漂移有界且经消融验证无显著影响。
Card 05 数据集与资源

数据集与资源

  • 实验在 LLaVA-OneVision（0.5B、7B）、InternVL-2.5（1B）、LongVA（7B）等多个 VLM 家族上进行。
  • 评测基准涵盖视频理解基准、长时推理与图像基准、长叙事理解（long-form narrative）和程序性动作识别（procedural action recognition），涉及 VideoMME、EgoSchema、UCF-101 等数据集。
  • 模型规模：0.5B 至 7B 参数不等。
  • 训练资源：由于是 training-optional 方法，主要依赖推理阶段的计算；论文未指定具体 GPU 型号，但强调端到端延迟测量基于真实部署环境。
Card 06 评估与结果

评估与结果

  • 推理加速：在 LLaVA-OneVision-7B 上实现最高 45% 的推理加速，同时保持或提升准确率。
  • 极端 token 预算：在 10% token 保留条件下，VETO 的准确率为 55.7%，优于 VFlowOpt（54.9%）、VisionZip（52.6%）和 FastV（47.9%）。
  • 全监督设置：在长叙事理解基准上取得最先进结果，在程序性动作识别上也具有竞争力。
  • 通用性验证：在 LLaVA-OneVision、InternVL-2.5 和 LongVA 上均保持或提升零样本准确率，证明方法的跨模型通用性。
  • 消融研究：验证了 token 合并策略、帧内压缩比、帧间压缩比以及极端 token 饥饿下的鲁棒性；实验表明准确率在 k∈{2,3,4,5} 范围内保持稳定，未出现明显的空间信息坍缩。
