Card 02 论文概述

论文概述

  • 论文提出 GeoLAM 框架，用于从无动作标注的人类视频中学习“几何接地”（geometry-grounded）的潜在动作表示（latent action），并用于机器人操作控制
  • 核心问题：纯视觉重建容易将操作相关运动与外观变化、相机运动相纠缠，导致潜在动作表征语义模糊；且显式手部姿态/轨迹重建受遮挡影响大、计算成本高
  • 解决方案：结合冻结几何基础模型特征层级的未来帧重建，与训练专用的4D 几何教师（teacher）运动监督，在不依赖显式手部标注的前提下保留几何运动信息
Card 03 核心贡献

核心贡献

  • 提出 GeoLAM，一种从无标注人类视频中学习连续、几何接地潜在动作的自监督框架，预训练规模约 20,000 小时人类视频，全程无需动作标签
  • 通过冻结几何基础模型（Depth Anything 3 骨架 + GLD 多级重建解码器）提供结构先验，将转移建模置于几何感知的特征空间中
  • 引入训练专用的 4D 几何教师（基于 D4RT），构建包含 3D 位移、残差图像平面运动、表面朝向变化的几何运动目标，并通过可见性/置信度加权空间池化抑制不可靠估计与静态背景
  • 设计世界动作模型（World-Action Model）联合去噪框架：将 GeoLAM 潜在动作与可执行动作块进行联合条件流匹配去噪，未来视频预测仅作为辅助训练任务，部署时无需几何教师和未来视频生成
  • 在 LARYBench 潜在动作基准、LIBERO、RoboTwin 及真实世界机器人操作任务中验证了方法的强性能
Card 04 方法描述

方法描述

  • 使用 逆动力学模型（IDM） 将两端点帧的状态差异压缩为连续潜在动作 token（32 维确定性瓶颈，4 个 token），前向动力学模型（FDM） 以当前状态和潜在动作为条件预测未来特征并重建 RGB 图像
  • 视觉状态建立在冻结 GFM 的浅层特征层级上，深层 GFM 与 RGB 解码器提供像素级重建目标，光栅重建使得模型无需深度标签和相机参数
  • 4D 几何教师 D4RT 对均匀采样的视频片段进行时空查询，输出 3D/2D 位置、表面法线、可见性和置信度，构建可解释的运动描述子（3D 位移、残差 2D 运动、表面朝向变化、运动幅度）
  • 两个训练阶段：第一阶段在人类视频上预训练潜在动作编码器（像素重建 + 几何监督的两项损失）；第二阶段在动作标注的机器人示范上训练下游策略，冻结的编码器提供转移目标并联合去噪
  • 推理阶段仅需要当前观测的一次锚定前向传播和缓存的键值特征，即可通过流匹配从高斯噪声联合积分出动作块，效率高且无需未来信息
Card 05 数据集与资源

数据集与资源

  • 预训练数据：约 20,000 小时无动作标注的人类 RGB 视频
  • 评估基准：LARYBench（潜在动作基准）、LIBERO、RoboTwin 机器人操作基准，以及真实世界机器人实验
  • 训练硬件：64 块 NVIDIA A800 GPU，分布式数据并行，bfloat16 混合精度
  • 训练配置：200,000 步，AdamW 优化器，学习率 1e-4，每 GPU 批大小 32（全局 2,048）；RGB 输入分辨率 224×224，D4RT 教师处理四帧 256×256
  • WAM 视频分支初始化自 Wan2.2-5B，使用 9 帧片段，动作专家隐藏宽度 1,024，动作块长度 H=32
Card 06 评估与结果

评估与结果

  • 在 LARYBench 潜在动作基准上评估所学习表示的质量（动作预测与转移一致性）
  • 在 LIBERO 与 RoboTwin 基准上验证下游机器人操作成功率，与现有潜在动作模型（如 LAPA 等）对比
  • 开展了真实世界机器人操作实验，验证从人类视频预训练到真实机器人控制的可迁移性
  • 进行消融研究，分别验证几何教师监督、可见性/置信度加权池化、几何损失权重递进安排等设计的影响；结果显示 GeoLAM 在各基准上均取得强性能，并确认未来视频预测在部署时可安全移除
